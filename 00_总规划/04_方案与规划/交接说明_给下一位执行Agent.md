- **提示后正确≠无提示正确**：提示依赖分四级显示（无提示/一级/二级/三级或答案展示），防止提示后答对计为独立掌握。
- **迁移失败单独记录**：新增 `transfer_correct`，识别"记住答案但不会迁移"；错题用原题1次＋同构变式（不无限重复原题）。
- **高置信错误**：仅重点题采集confidence（单元诊断/真题/Exit Ticket/重点语法/延迟复测/教师标记题）；用"显式反驳"结构（你的答案/为何看起来合理/与规则冲突/正确结构/立即重答/变式/跨日复测）；必须安排跨日复测。
- **错因**：`error_code_auto / error_reason_self / error_code_final` 三级，周报只显示 final；AI/系统不得自动标"粗心/不认真/理解能力差"。
- **M14错题池**：错误分五类（E1首次提取/E2形式拼写/E3规则概念/E4迁移/E5延迟复测）；最小Schema含 `error_event_id/error_stage/confidence/hint_level/error_code_final/immediate_retest_correct/transfer_retest_correct/delayed_retest_correct/next_review_at/status/teacher_override`；优先级算法保留分项原因（如 迁移4＋高置信3＋用时1）；教师覆盖记 `override_by/override_at/override_reason`。
- **M4延迟复测失败**：保留历史M4证据，当前状态标 `M4_REVIEW_REQUIRED`，是否正式降M3由08规范决定。
- **数据字段**：现有飞书表新增 `independent_correct / transfer_correct / delayed_retest_correct / priority_score / priority_reasons / recommendation_status / teacher_override`，不新增大量新表。
- **AI建议**：统一"建议＋证据＋动作＋用时"卡片；用数据充分性（低/中/高）而非虚假精确百分比；每周最多3发现+3建议+1-2待确认；每条60-120中文字；附触发数据；可接受/编辑/拒绝（记 recommend 状态）；AI只处理教师端已导出字段，不嵌入学生HTML、不放密钥。
- **AI不得自动完成**：判粗心/态度、贴能力标签、改长期课程规划、改锁定exam_spec、改M0—M4最终状态、定开放写作终评、删错题、降学生层级、自动发家长报告、替教师决定返讲。
- **技术排错指标**（IndexedDB写失败/CSV导出失败/sync_status=failed/JS异常/页面加载失败/音频失败/Canvas未初始化/重复event_id/异常长停留）只进系统健康视图，不进学生学习报告。
- **不建议采集**：hover/滚动距离/动画次数/卡片轨迹/触屏坐标/鼠标移动/每个点击/登录次数/无任务边界总停留时间——立即停止扩张。
- **用时解释**：不用原始response_time_ms判掌握；只算个人同类题中位数＋异常倍数（<0.25×可能猜测、>2.5×可能犹豫/中断，项目实验参数）；用时不得单独触发降级。

> 注意：本报告含"中期实施"（高置信错误采集）与"收集数据后再改"（优先级权重/复测节奏/用时倍数/退出阈值/AI条数/教师接受率等）项，执行前须逐条区分"立即实施"与"待验证"，并经教师确认。
