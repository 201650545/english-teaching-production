## §1 M14 错题反馈闭环

**数据流**：教师批改配套练习 → 录入 `feedback.json` → 下一课复习导入自动复现对应错型 → 滚动复习（L+1/L+3/L+7）→ 错题本按类归档。

**`feedback.json` 契约（每生一份，存 `学生姓名/feedback.json`）**
```json
{
  "student": "许颖嘉",
  "records": [
    {"lesson": 5, "question_id": "Q12", "error_class": "语法-祈使句-否定",
     "wrong": "Don't to run.", "correct": "Don't run.", "date": "2026-08-09"}
  ]
}
```

**error_class 词表（装配器可解析）**：
- `语法-<考点id>-<子类>`（如 语法-名词复数-es）
- `词汇-词义` / `词汇-拼写` / `词汇-搭配`
- `阅读-细节` / `阅读-推断` / `阅读-五选四` / `完形` / `选词`
- `拼读-<组合>`

**复现规则**：
1. **下一课复习导入**（8 张翻牌）＝上节词汇语法常规复习 4 张＋**错型加权** 3 张＋滚动到期错题 1 张；
2. **滚动复现**：错题入池后在 L+1、L+3、L+7 课复习段各复现一次，连对 2 次出池；
3. **巩固词源**：`词汇-*` 错词自动进入该生 `review_words` 池（与新词配比仍守学生规划）；
4. **语法诊断**：`语法-<考点>` 错型计入练习卷第四部分的考点配比微调（仍守 4/3/3 框架）；
5. **错题本**：按考点三类自动归档（`学生姓名/错题本.md`），每周生成一页回看清单。

**验收**：录入 L5 批改 3 条（祈使句否定×1、词汇拼写×2）→ L6 复习导入含祈使句否定翻牌 ≥1、错词入巩固池；错题本出现对应归档条目。

## §2 M15 听力材料生成

**触发条件**：学生画像 `listening=true`（李民宪默认 true），或单次生成练习前教师确认「含听力」。
**闸门**：与 P2-M9 同一标志位——无人工确认不生成。

**产出物**（每课一套）：
| 物 | 规格 |
|---|---|
| 听力稿 | 按 exam_spec 听力模块：句子×5／对话×10（短5+长5）／短文×5；话题取自当课主题；词汇语法不超学生上限；**允许原创命题**（听力稿不在「四类语篇真题母本」红线内，但须题材真实、长度达标） |
| 音频 | TTS 合成 mp3：双声部（对话）；语速 基础 0.9×／中等 1.0×／培优 1.0×；每题读两遍、题间停 5 秒；文件名 `第X课时_听力_Q{n}.mp3` |
| 课件听力页 | 播放按钮＋题目＋`checkOpt` 判定＋答案解析 |
| DOCX 听力部分 | 置于卷首（第一部分），题号 1–20，总分 20；含听力时全卷 120 分 |

**验收**：李民宪任一课 → 120 分卷结构正确、音频可播放、题文一致、答案分布均衡。

## §3 M16 多学生并行接入

**新生接入流程**：
```
教师填 4 行简报 → AI 定级建议＋理由 → 实例化《学生规划》（层②）→ 教师审签
→ 建立该生独立资产：used_vocab 注册表 / feedback.json / 错题本 / 组件去重 registry / 进度看板
→ 接入 build_all（按学生维度增量构建）
```

**资产隔离与共享**：
| 资产 | 范围 |
|---|---|
| 语法库 / 拼读库 / 真题母本库 / 组件库 | **全局共享**（只读） |
| 词汇注册表 / 巩固词池 / 错题池 / 组件去重 registry / 进度 | **每生独立** |
| 语篇选取 | 共享库内按该生 tier 窗口与去重状态选取 |

**已登记学生**：
| 学生 | 简报 | lesson_map | 词汇配置 | 听力 | 特殊项 |
|---|---|---|---|---|---|
| 许颖嘉 | ✅ 已审（待签） | 40 课大纲 V2.0（已数据化） | 20 新＋0 巩固 | 默认否 | 语法上限八上 U2 |
| 李民宪 | 待填 | **需新建**：人教版 2024 七下＋省卷拔高（执行 Agent 先出草案，教师审定） | 10 新＋20 巩固＝30 | 默认是（20 分） | 语法上限不受限；完形 10 空 |
| 邓兴华 | 待填 | 待定 | 待定 | 待定 | 简报后 AI 定级 |

**李民宪 lesson_map 派生规则**：以其教材单元为主线＋省卷五大题型渗透；语法点覆盖七下全册后转综合；阶段测试每 5 课一次；**出草案后必须经教师审定才入 `lesson_map_李民宪.json`**。

**验收**：许颖嘉 L5 与李民宪 L1 同机构建 → 四件套各自落盘、注册表互不串词、组件去重各自独立。
