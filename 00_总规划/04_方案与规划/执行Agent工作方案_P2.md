# 执行 Agent 工作方案 · P2 引擎层（M5–M13）

> **本方案是执行 Agent 的唯一施工依据。** 前置：P1 四模块已验收（M1 派生/M2 词库/M3 平衡/M4 校验）。
> 目标里程碑：**L5 端到端贯通**——输入仅简报 4 行，输出 `许颖嘉/第05课时/` 四件套，校验全过（验收细则见《执行落地清单》§4）。
> 版本 v1.0 ｜ 2026-08-02

## §1 模块任务卡

### M5 语法库 `grammar_bank.json`
- **结构**（每考点 10 字段）：`id / title / stage / ceiling_tag / usage / examples[6] / errors[5组错→对] / mnemonic / cards[6] / exam_note / quiz[2]`
- **cards 六色键固定**：用法/构成/易错/例句/注意/口诀（映射 COLORKEY 六色，禁自造标签）
- **覆盖**：L1–L20 × 3＝60 考点（清单取自 `lesson_map.json` 的 grammar 字段）；test 课不设新条目
- **防越级**：`ceiling_tag` 标注所属教材上限；装配器只取 ≤ 学生 ceiling 的条目
- **验收**：60 考点齐备；抽 10% 人工审六段式质量；L1–L4 条目与已交付课件内容一致（以课件为准回填）

### M6 真题母本语篇库 `passage_bank.json`
- **结构**（每篇 12 字段）：`id(年份-地区-考试-题号) / genre(记叙|说明|应用) / difficulty / theme / word_count / text / questions[{q, options, answer, 解析, 依据句}] / vocab_rate / tense / source_verified(人工核源bool) / adapt_note`
- **硬规则**：仅真题改编、禁整卷复制、禁编造模板文；每篇 `source_verified=true` 才允许入库
- **选篇算法（装配器调用）**：按 theme 匹配 → A/B/C 文体互异 → 生词率落入 tier 窗口（15/17/20%）→ L14–L21 课时自动将过去时语篇转现/将时并记 `adapt_note`
- **生词率算法**：(不在「当课词表+已学注册表+基础视觉词表」的词数) ÷ 总词数
- **种子与缺口**：`old_lessons.json` 可用篇（L1/L2/L3/L4(sa,key)/L6/L8/L13/L14/L15/L16）；**缺口＝L5/L7 阅读＋各课五选四**→列入采集任务（联网搜真实中考真题，登记溯源 ID）
- **验收**：每课可选齐 A/B/C＋五选四；溯源 ID 100% 登记；生词率可自动复算

### M7 拼读库 `phonics_bank.json`
- **结构**：`combo / phonetic / rule / example_words[4-6] / word_families / song / drills[8]`
- **指派**：按 `lesson_map.json` 的 phonics 字段逐课映射（L1 短元音→L18 -ing/双写）
- **验收**：L1–L20 每课一条，词族≥5 组、儿歌 1 首

### M8 通用装配器 `courseware_engine.py`（核心）
- **输入**：课程卡（M1）＋各库（M2/M5/M6/M7）＋创意组件库（M12）
- **输出**：45 页单文件 HTML，verify_v2 硬规则全过
- **页面模板注册表**（31 种页型，对应大纲模板 §6）：cover/goal/recall/warm/vocab_cards/vocab_group/cloze/vdiff/vdict/grammar_a(构成+例句)/grammar_b(易错+口诀+色卡)/grammar_c(中考小测)/matrix/gsum/zhenti/pfill/quiz_page/drill/fill/errd/reading_passage/reading_q/w5_passage/w5_q/sop/rmore/phonics_main/phonics_drill/phonics_song/cross/listen/summary/err_review/preview
- **装配算法**：
  1. 读卡 → 取语法条目×3（M5）→ 选词（M2：新词 X+巩固 Y）→ 选篇（M6 算法）→ 组题库（考点 quiz＋随堂 28→M3 平衡）→ 选创意组件（M12：组件数＝新知识点数，复习段必配 1 个）
  2. 按八段式渲染；页数动态分配＝ceil(X/10)+ceil(Y/10)，差额在段④/⑦调节，恒定 40–45
  3. 自检 verify_v2 → 失败进 M10 修复环
- **验收**：L5 卡 → HTML 一次通过 verify_v2 全部硬规则；与《课件制作大纲》§6 逐页对应

### M9 练习 DOCX 引擎 `docx_engine.py`
- **输入**：课程卡＋`exam_spec_v2026_1.json`（locked 后禁改）＋语篇库＋题库
- **听力闸门**：引擎**只接受人工确认的 listening 标志**；未确认一律按不含听力生成并在卷头注明
- **输出**：DOCX＝卷头→四部分正文（题号全卷连续）→答题卡→答案解析页→命题双向细目表；结构与 exam_spec 逐行一致
- **验收**：抽 L5 卷与 exam_spec §2 对照零偏差；答案分布均衡；细目表 100% 登记溯源 ID

### M10 自动修复环
- **策略表**：体积不足→扩内容块（例句/解析/词族）；页数越界→段④/⑦增减题量；分布偏斜→M3 重排；六色不足→补齐六色键；残留→重新命名；3 轮未过→输出具体失败原因交人工
- **验收**：人为注入 3 类故障（体积/页数/分布）均能自动修复或准确定位

### M11 增量构建＋CI 门 `build_all.py`
- **规则**：对（课程卡＋涉及库切片＋模板版本）哈希，变更才重建；输出「课 × 规则」PASS/FAIL 表；任一 FAIL 退出码非零
- **验收**：改 1 课只重建 1 课；全量构建输出完整 PASS 表

### M12 创意组件库 `components/`
- **10 个起步组件**（规格，不含实现代码）：翻牌记忆｜快选（计时）｜打地鼠｜投篮分类｜转盘问答｜消消乐｜表情投票｜连线配对｜闯关地图｜听音选词
- **每组件 8 字段规格**：name/触发词(NL 映射)/绑定知识类型/数据接口/音效/动效/实现要点/跨课去重 registry 键
- **NL 映射**：教师白话（“翻牌/闯关/转盘…”）→ 组件键；未命中→按主题自动选
- **验收**：组件数＝新知识点数；同一组件不跨课重样（registry 强制）

### M13 大纲渲染器 `outline_renderer.py`
- **映射**：课程卡＋装配结果 → 《第X课时_课件制作大纲.md》《第X课时_配套练习生成大纲.md》，与两模板 §1–§9 逐节对应
- **验收**：渲染产物通过模板完整性自检（节数/变量清零/溯源 ID 在位）

M12 组件库 ───────────────────┘            │
