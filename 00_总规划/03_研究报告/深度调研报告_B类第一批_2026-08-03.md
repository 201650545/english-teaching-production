# 一、执行摘要

## 1. 最重要的三项结论

### 结论一：间隔复习有效，但目前没有证据支持一套唯一的"最佳天数"

课堂应用研究的 Meta 分析显示，分散练习相较集中练习具有中等优势；但间隔效果受最终保留时间、学习内容、复习次数和学习者年龄影响。儿童 EFL 课堂中，1 天和 8 天间隔在 4 周后测中未出现显著差异，说明不能把成人实验得出的精细间隔直接写成初中英语硬规则。

因此，项目应采用：

```text
有证据支持的原则
+
保守初始参数
+
基于真实答题数据动态调整
```

而不是声称：

```text
第1天、第3天、第7天是科学证明的唯一最佳答案
```

### 结论二：游戏化可能提高动机，但并非"越多奖励越好"

2024 年 Meta 分析纳入 35 项干预、约 2500 名参与者，游戏化对内在动机的总体效果显著但较小；对自主感和关系感的影响较大，对胜任感的影响较小。研究还发现，公开排名靠后的学习者容易产生不适，缺少自主选择和持续失败会削弱效果。

因此，本项目应优先保留：明确目标、可见进度、适度挑战、即时反馈、自主选择、失败后可恢复、掌握成长。

应限制：每题积分、公开排行榜、连胜惩罚、重复徽章、纯装饰奖励、与学习目标无关的竞争。

### 结论三：低风险词汇和语法练习应以即时纠错为主，但不应一错就直接展示完整答案

大规模反馈 Meta 分析显示，反馈总体具有中等学习效果，但效果高度取决于反馈中包含什么信息，而不是只有"立即或延迟"这一维度。数字反馈研究中，立即和延迟反馈都能有效；但一项直接针对 145 名七年级 EFL 学生英语过去时的研究发现，即时纠正比延迟纠正更有利于二语发展。

因此，GM-V02 宜采用：

```text
首次无提示提取
→ 判断正误
→ 逐级提示
→ 再次提取
→ 必要时显示答案
→ 遮住答案再提取
→ 后续迁移题
→ 进入复习池
```

# 二、B1：初中英语词汇间隔复习

## 2.1 证据结论

### B1-01：必须分散复习，禁止把全部重复压在同一节课内
**结论**：同样的复习次数分散在不同时间，通常优于集中在一次学习中完成。
**依据**：Cepeda 等 2006 分散练习 Meta（184 篇、317 实验、839 比较）；Mawson 等 2025 课堂应用 Meta（22 报告、3000+ 学习者）；二语词汇训练综述 2019。
**证据等级**：一级。
**项目落地**：一节课内可完成首次学习＋一次短间隔复测；后续至少一次复习必须跨日期；M4 不得仅靠同一节课内连续答对获得。
**实施级别**：立即实施。

### B1-02：不能把 1 天或 8 天规定为所有学生的唯一最佳间隔
香港儿童 EFL 课堂研究（66 名学生学习 20 词，比较 1 天与 8 天间隔，4 周后测无显著差异）——成人实验室精细间隔未必推广到儿童课堂。
**实施级别**：立即采用原则；具体天数中期验证。

## 2.2 保守可靠版复习参数（项目初始参数，非唯一最佳天数）

初始学习日记为 D0：

| 阶段 | 建议时间 | 主要目标 | 推荐题型 |
| ---- | ---- | ---- | ---- |
| 首次学习 | D0 | 建立词形—词义联系 | 图义匹配、例句理解 |
| 课内复测 | D0，间隔 10—20 分钟 | 确认是否初步记住 | 无提示义→词或词→义 |
| 第一次跨日复习 | D1—D2 | 防止快速遗忘 | 主动提取 |
| 第二次复习 | D3—D5 | 检查拼写和词形 | 拼写、词形变化 |
| 第三次复习 | D7—D10 | 延迟保持 | 搭配、句子填空 |
| 第四次复习 | D21—D28 | 长期保持和迁移 | 新语境使用 |

实施级别：中期验证。

## 2.3 动态参数
- A 首次错误：D0 立即反馈 → 当页提示后重试 → 10—20 分钟后再测 → D1 再次进入复习池。不能因提示后答对直接升级。
- B 首次正确但用时过长（>个人中位 1.8 倍等）：保持较短间隔；用时仅辅助信号，不单独判"未掌握"。
- C 使用提示后答对：`is_correct=true, independent_correct=false, hint_used=true`，掌握判断以 `independent_correct` 为主。
- D 连续两次跨日无提示答对：延长间隔（7→14→28 天）。
- E 延迟复测失败：缩短间隔，回退到更低生成要求（新语境失败→回到提取/拼写→1—3 天再测）。

## 2.4 实验版参数（收集数据用，不进硬规范）
- 弱词路径：D0→D1→D3→D7→D14
- 稳定词路径：D0→D3→D10→D21→D42
- A/B 验证：方案 A（D1/D3/D7/D21）vs 方案 B（D2/D7/D14/D28）；观察 8—12 周、100+ 词项、首次正确率、跨日无提示正确率、28 天保持率、提示使用率。

## 2.5 M0—M4 题型映射（补充操作口径）

| 等级 | 有效证据 | 不足以升级的表现 | 推荐下一题型 |
| ---- | ---- | ---- | ---- |
| UNASSESSED | 尚无有效作答 | 看过页面 | 识别题 |
| M0 | 识别仍错或无法完成 | 看到答案后说"会了" | 词义识别 |
| M1 | 能识别词义或词形 | 四选一猜对一次 | 主动提取 |
| M2 | 无提示主动提取正确 | 首字母提示后答对 | 拼写、词形 |
| M3 | 无提示拼写/词形/搭配正确 | 抄写正确 | 新句、新语境 |
| M4 | 跨日期、无提示、新语境正确 | 同一原句重复答对 | 延迟抽查 |

M4 维持现有阈值（≥7 天、≥2 不同日期、无提示、≥1 主动提取/拼写、≥1 新语境），但注为**项目操作阈值**而非普遍科学定律。

## 2.6 B1 规范建议
MUST：跨日期复习；首次答案保留；提示后答对≠无提示答对；M4 含延迟和新语境；复习从识别转向产出。
SHOULD：弱词短间隔；稳定词扩间隔；用时辅助；每次复习改题型/语境；间隔动态调整。
MUST NOT：同课连续答对即判 M4；抄写当主动提取；提示后仍计首次正确；所有学生同间隔；把 D1/D3/D7 写为唯一科学答案。

# 三、B2：游戏化与内在动机

## 3.1 证据结论
- B2-01 游戏化平均动机效果较小（2024 Meta，35 干预、2500 人），自主感/关系感作用大于胜任感；"如何设计"比"是否游戏化"重要。
- B2-02 短期新鲜感≠长期效果；新奇效应、外部奖励随时间回落。每课相同积分/徽章/动画会快速失去新鲜感；形式轮换不能只换皮肤。
- B2-03 积分、徽章、排行榜、竞争是负面结果最常报告的机制（无效、表现下降、动机问题、焦虑、作弊）；公开排行榜使排名靠后学生不适。

项目决议：公开学生排名=不推荐；个人历史进步=推荐；个人掌握地图=推荐；班级匿名合作目标=有条件使用。

## 3.2 游戏机制分级

**高证据、建议保留**：明确目标、即时反馈、适度挑战、失败可恢复（提示/重试/修正/迁移）、掌握进度（反映知识掌握与个人进步）、自主选择（如先拼写或先搭配，但核心任务必须完成）。

**有条件使用**：
- 积分：仅小游戏内部反馈，不进长期能力标签、不公开排名；绑定有效提取/修正错误/完成迁移；不绑点击次数/答题速度/连续猜中。
- 徽章：只授予有真实学习意义的里程碑（跨日复测成功、首次独立拼写、新语境正确、完成错误修正）。
- 连胜：可显示"连续 3 题独立完成"，不因一个错误清零、不逼选简单题、不惩罚焦虑。
- 叙事：适合短模块（错句医生/单词修复站/阅读侦探），必须短、不淹没题目。

**仅用于短时调节**：30—90 秒限时配对、课堂中段快速分类、课末抽签挑战、简单角色动画、局部庆祝。目的=恢复注意而非证明掌握；结束后回到"练了什么/哪里不稳/下一步"。

**不推荐作为常规机制**：公开排行榜、班级末位显示、每题金币、连胜失败全清零、随机宝箱、强制角色养成、重复抽卡、每课同一奖励体系、以速度为主要分数、无知识目标的跑酷/射击外壳。

## 3.3 对现有 29 种游戏的审核办法（量表）

| 审核项 | 0分 | 1分 | 2分 |
| ---- | ---- | ---- | ---- |
| 学习目标 | 无明确目标 | 目标模糊 | 对应知识点 |
| 提取强度 | 只看/点 | 有部分回忆 | 必须主动提取 |
| 反馈质量 | 只报正误 | 给答案 | 给依据与修正 |
| 迁移 | 原题重复 | 轻微变化 | 新语境 |
| 数据价值 | 只记分数 | 记正误 | 记首次、提示和错因 |
| 情绪风险 | 强竞争 | 中性 | 支持恢复 |
| 触屏操作 | 不适配 | 勉强可用 | 有点击替代 |

总分：12—14 核心保留 / 9—11 条件保留 / 6—8 改造后使用 / 0—5 删除或仅短时调节。

> 注：本轮附件未含 29 种游戏完整名称/规则，未逐个判定；须对实际 `07_词汇教学与复习游戏规范.md` 逐项按量表审核。

## 3.4 B2 规范建议
MUST：游戏对应明确知识点；游戏结果回到学习总结；记录首次答案与提示使用；奖励绑掌握/努力/修正；失败后可恢复。
SHOULD：适度选择；个人进步替代同伴比较；同外壳不高频重复；短游戏与安静任务交替；竞争用个人最佳或匿名合作目标。
MUST NOT：公开排行榜；每题固定积分；错一题清空进度；速度替代正确与理解；游戏分数等同能力等级；奖励与知识无关。

# 四、B3：即时反馈和 GM-V02 提示梯

## 4.1 反馈不是越多越好，而是信息必须有用
435 项研究、61000+ 学习者反馈 Meta：反馈总体中等效果，最重要调节因素=反馈所传递的信息内容。只告诉"错了"不如告诉差距和下一步。有效反馈至少回答：结果是什么？错误在哪里？下一步做什么？

## 4.2 即时还是延迟
- 七年级 EFL 过去时：即时纠正组优于延迟组（145 名）。
- 数字反馈 Meta：即时与延迟均有效，延迟总体略优（不存在唯一时机）。
- 项目决议（题目级纠错即时，模式级总结延迟）：
  - 词义/拼写/词形/单项语法/选择题正误/阅读证据：立即
  - 完整写作：先完成再集中反馈
  - 口语流利表达：任务后反馈，不频繁打断
  - 课次共性错因：课末总结；阶段趋势：周报反馈

## 4.3 答错后是否直接给答案
不建议首次错误立即完整显示答案。成功且需要努力的检索更有利，但检索须有合理成功概率。正确流程：判断错误 → 给可操作提示 → 再次提取；不允许无限猜测。

## 4.4 GM-V02 正式流程

- **状态0 无提示首次提取**：显示中文义/语境/图片/输入框；不显示首字母/选项/长度/答案词块。记录 first_answer、first_response_time_ms、confidence。
- **状态1 首次正确**：反馈"提取正确。把它放进这个句子试一次。"进入搭配/句填/延迟复测。记录 is_correct=true, independent_correct=true, hint_level=0。
- **状态2 首次错误**：措辞"还没有提取出来。先看一个提示，再试一次。"不使用"错！/你不会/巨大红叉/刺耳音效"。记录首次错误不覆盖。
- **一级提示（语义/语境）**：如"它表示'某个不确定的地点'，常用于肯定句。"不直接给字母。适合词义混淆/概念未激活/搭配线索。
- **二级提示（首字母+长度）**：如"首字母：s 共9个字母"。
- **三级提示（词块或部分形式）**：如"some + _____"或"s o m e _ _ _ _ _"。仍应要求学生输入，不自动完成。
- **显示答案**：触发条件=三级提示仍错/连续两次无意义猜测/总时长超限/学生主动选择"查看答案"。展示词形+音形分块+搭配+短例句。显示后不能直接判正确、不能升级、不能结束任务。
- **遮盖后再次提取**：答案显示 3—6 秒后隐藏，要求学生重新输入。记录 post_reveal_retrieval。答对只说明完成即时修正，不代表跨日掌握。
- **迁移题**：不同句子新语境，单独记录 transfer_correct。测试效应 Meta：检索能迁移但迁移效果小于原题保持。
- **进入复习池**：首次错误/用任何提示/显示答案/迁移错/用时异常长/高置信错误。优先级：显示答案 > 三级提示 > 二级 > 一级 > 无提示但用时长（项目初始权重）。

## 4.5 不同题型反馈策略
- 拼写：首次错→标错误位置数量→再试→给首字母/词块→显示答案→遮盖再拼；不一开始逐字标完整正确形式。
- 语法填空：首次错→提醒规则类别→标需检查位置→再试→解释规则→迁移题。
- 单项选择：最多 1 次正式作答＋1 次带依据修正；不允许反复点击猜中。
- 阅读理解：答错后先在原文选证据句，再展示解析。
- 开放写作：不适合逐字打断；完成后按时态/目标词/句子完整/连接集中反馈。

## 4.6 提示后如何计入 M0—M4
四选一识别正确=最多 M1 证据；一级提示后提取正确=暂不升 M2；无提示提取正确=M2；首字母提示后拼写正确=暂不升 M3；无提示拼写正确=M3；原句重复正确≠M4；跨日新语境无提示正确=M4。
掌握汇总须区分：correct / independent_correct / hinted_correct / revealed_then_correct / transfer_correct。只存一个 is_correct 不足以支持准确 M0—M4。

## 4.7 GM-V02 事件字段（最低字段）
```json
{
  "event_id": "stu001_L02_V07_A1",
  "student_id": "stu001", "lesson_id": "stu001_L02", "question_id": "L02_V07",
  "knowledge_id": "VOC_U1_SOMEWHERE",
  "first_answer": "somewere", "final_answer": "somewhere",
  "is_first_correct": false, "is_final_correct": true,
  "independent_correct": false, "attempt_no": 3,
  "hint_used": true, "max_hint_level": 2, "answer_revealed": false,

```

## 4.8 GM-V02 界面措辞
首次错误："还没提取出来。看一个提示，再试一次。"
一级提示后："方向对了吗？现在再回忆完整单词。"
二级提示后："已经有首字母线索，请尽量自己完成。"
显示答案前："先看清词形。稍后答案会隐藏，你需要重新拼写。"
遮盖后答对："这次已经修正。它会在后面再次出现，确认是否真正记住。"
迁移错误："词形记住了，但新语境还不稳定。已加入复习池。"
