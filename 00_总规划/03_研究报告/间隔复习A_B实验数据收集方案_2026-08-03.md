# 间隔复习 A/B 实验数据收集方案与模板

> 编写：执行 Agent · 2026-08-03 · 依据：《深度调研报告_B类第一批_2026-08-03.md》§2.4 与「七、收集数据后再改」第 1 条
> 数据模型对齐：`08_学习数据闭环规范.md` §13.2/§13.3 与 GM-V02 事件字段（GMEventsDB）
> 用途：按 B 类收尾任务③，产出 8—12 周间隔复习 A/B 实验的收集方案、指标定义与数据模板

---

## 一、实验目标

比较两种间隔复习方案对初中英语词汇长时保持（28 天）的影响，用真实课堂数据回答「哪种间隔更优」，而非照搬成人实验的固定天数。

| 方案 | 首次(课内) | 第1次跨日 | 第2次 | 第3次 | 第4次(保持) |
|------|:--:|:--:|:--:|:--:|:--:|
| **方案 A** | D0（10—20min） | D1 | D3 | D7 | D21 |
| **方案 B** | D0（10—20min） | D2 | D7 | D14 | D28 |

**观察周期**：8—12 周；**样本量**：≥100 词项（每方案 ≥50 词项）；**核心指标**：首次正确率、跨日无提示正确率、28 天保持率、提示使用率。

---

## 二、实验设计

### 2.1 设计类型：被试内随机（within-subject，推荐）

- 每课 20 个新词，随机平均分入方案 A、方案 B（各 10 词），同一学生同时经历两套间隔。
- 优点：控制学生个体差异（基础、记忆、动机），同一学生既是 A 组又是 B 组，样本效率高、统计检验力强。
- 混合课堂（不同学段）亦适用：分层随机即可，不必改变设计。

### 2.2 样本量规划

| 参数 | 数值 | 说明 |
|------|:--:|------|
| 每周课次 | 1 课 | 每课 20 新词 |
| 每课每方案 | 10 词 | 20 词随机对半分 |
| 8 周累计 | 160 词 / 每方案 80 词 | 满足 ≥100 词项 |
| 12 周累计 | 240 词 / 每方案 120 词 | 更充分 |

> 若每课不足 20 词或每周多课，按「每方案累计 ≥50 词」折算，总词项 ≥100 即达标。

### 2.3 随机分配规则

- 每课 20 词编号 1—20，用固定随机种子（记录在案，便于复现）随机打乱，前 10 词→方案 A，后 10 词→方案 B。
- 同一课的词语义相关时，尽量拆开分入两方案（避免搭配/语义聚类污染）。
- 分配表在每课开课前生成并固化，全程不因学生表现更改。

## 三、数据字段（与 GMEventsDB 对齐）

每次复习作答记录一条事件，字段如下（B 类报告 4.7 与 08 规范 §13.3 最低字段）：

| 字段 | 类型 | 说明 |
|------|------|------|
| `event_id` | 主键 | `{student_id}_{session_id}_{question_id}_{attempt_no}` |
| `student_id` | 文本 | 学生编号，如 `stu_001`（不用真实姓名） |
| `session_id` | 文本 | 课次/会话标识，如 `SESSION_L03` |
| `question_id` | 文本 | 稳定唯一定义，如 `CMP_V02_ancient` |
| `knowledge_id` | 文本 | 知识点/词项，如 `VOC_ancient` |
| `scheme` | 文本 | **A / B（实验分组，新增）** |
| `scheduled_day` | 文本 | 计划复习日，如 `D0/D1/D2/D3/D7/D14/D21/D28` |
| `actual_day` | 文本 | 实际作答日（如延迟/提前补测，记录真实间隔） |
| `review_round` | 整数 | 第几次复习（1–4） |
| `first_answer` | 文本 | 首次作答原文 |
| `final_answer` | 文本 | 最终作答原文 |
| `is_first_correct` | 布尔 | 首次无提示是否正确 |
| `is_final_correct` | 布尔 | 最终是否正确 |
| `independent_correct` | 布尔 | 无提示独立正确（主判据） |
| `hinted_correct` | 布尔 | 提示后答对（不直接升级） |
| `revealed_then_correct` | 布尔 | 显示答案后遮盖重拼答对（即时修正） |
| `transfer_correct` | 布尔 | 迁移题（新语境）是否正确 |
| `attempt_no` | 整数 | 作答次数 |
| `hint_used` | 布尔 | 是否使用过提示 |
| `max_hint_level` | 整数 | 最高用到第几级提示（1/2/3） |
| `answer_revealed` | 布尔 | 是否显示过答案 |
| `post_reveal_retrieval` | 文本 | 遮盖重拼结果 `correct / wrong` |
| `response_time_ms` | 整数 | 用时（辅助信号，不单独判掌握） |
| `sync_status` | 文本 | `pending / synced` |
| `timestamp` | 时间 | 作答时间 |

## 四、数据收集机制

### 4.1 采集端（已就绪）

- GM-V02 组件已实现 `hlLogEvent()`：每次作答写入 IndexedDB `GMEventsDB / gmEvents`，并调用 `saveAnswer()` 存基础记录。
- 只需在生成每课课件时把 `scheme` 与 `scheduled_day` 写入作答逻辑（在 `hlLogEvent` 的 `ev` 对象中追加两字段即可），分配表随课件下发。

### 4.2 导出流向（对齐 08 规范 §5.4 先 CSV 后同步）

1. 每课结束，从浏览器 IndexedDB 导出 `gmEvents` 为 CSV（小工具：`export_events.js` 或手工 DevTools 导出，见 §8 模板）。
2. CSV 按字段核对后导入飞书多维表格（或 Excel）`复习实验_事件表`。
3. 每周末由脚本汇总周报（指标见 §五），供人工与教师核对。
4. 第 8—12 周后做最终 28 天保持率分析。

### 4.3 复习触发方式

- 方案 A：D1/D3/D7/D21 各触达一次；方案 B：D2/D7/D14/D28 各触达一次。
- 触达形式：课内跨课复习游戏 / 教师布置 / 课件内「复习池」页。**每次复习必须为主动提取（无提示先作答）**，题目形式随次数变化（识别→提取→拼写→搭配→新语境），不重复原题。

## 五、指标定义与计算

| 指标 | 定义 | 计算 | 分组 |
|------|------|------|------|
| 首次正确率 | 各复习点首次无提示作答正确比例 | `Σ is_first_correct / Σ 词项` | 按方案、按复习轮次 |
| 跨日无提示正确率 | 跨日复习（D1+）中独立正确比例 | `Σ independent_correct / Σ 跨日作答` | 按方案 |
| 28 天保持率 | D21/D28 保持点无提示正确比例 | `Σ 保持点 independent_correct / Σ 词项` | 按方案（主指标） |
| 提示使用率 | 需提示才能完成的词项比例 | `Σ hint_used / Σ 词项` | 按方案 |

**辅助信号**：`response_time_ms`（仅辅助，不单独判掌握）；`transfer_correct`（新语境迁移率，可作 28 天保持的补充）。

## 六、分析口径

- **主对比**：28 天保持率 A vs B，用配对样本（同一学生两方案）差分检验（Wilcoxon 符号秩或配对 t 检验，视分布）。
- **次级对比**：首次正确率、跨日无提示正确率、提示使用率按方案描述 + 差异检验。
- **分层**：按学生水平（基础/中等/培优）分层描述，观察间隔效果是否随水平变化。
- **排除规则**：未按要求触达（actual_day 偏离计划 >3 天且未补测）的词项单列，不混入主分析；提示后答对不视为独立正确。
- **忠实记录**：不因结果美化而改判；28 天前中途失访的词项计入分母（按「未保持=未答对」保守处理）。

## 八、实施步骤（交接用）

1. 在 `components.py` 的 `hlLogEvent` 事件对象中追加 `scheme`、`scheduled_day` 两字段（一带，很小）。
2. 每课生成前用固定随机种子产出分配表（§7.1），固化为课堂文件。
3. 课件内置复习池按方案/计划日触达复习；每次复习先无提示主动提取。
4. 每课导出 CSV（§7.2）→ 导入飞书/Excel → 每周末生成周报（§7.3）。
5. 第 8—12 周后按 §六 分析，产出期末对比表（§7.4）与结论。
6. 结论供后续调整 08 规范 §13.2 间隔参数使用；**结论未出前不把 A 或 B 写为唯一科学答案**。

## 九、红线（遵守 08 规范 §13）

- 提示后答对不得直接升级；显示答案后答对只算即时修正，不算独立掌握。
- 不把 D1/D3/D7 或 D2/D7/D14/D28 写成绝对科学定律；实验结论仅作参数参考。
- 同一课连续答对不得判 M4；M4 须跨日期、无提示、新语境。
- 学生使用编号，不用真实姓名；中途失访词项保守计入分母。
- 数据忠实记录，不因结果美化而改判。
