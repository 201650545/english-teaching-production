## 一、项目一句话

中国初中英语**离线单文件 HTML 互动课件**自动化流水线：为三名学生（许颖嘉·基础/七年级、邓兴华·中等/初二、李民宪·培优/七升八）批量生成「课件 HTML + 配套练习 DOCX + 契约大纲」，由 `00_工具\` 统一引擎（M1–M15）驱动。课件离线运行、触屏优先、答题数据 IndexedDB 本地采集 → CSV/JSON 导出 → 教师导入飞书多维表格汇总。

## 三、核心对象定位卡

### 3.1 代码边界（任务书 2.3 的落地含义）
- **底座（禁改）**：`courseware_core.py` 内的 `CORE_CSS`、`CORE_JS` 常量，提供页面/词汇卡/导航/IndexedDB 采集/音效。
- **可注入路径**：`CSS_EXTRA`（追加 CSS 覆盖）、`js_extra`（追加 JS 增强）、生成器模板更新。所有前端建议必须走这三条，禁止改底座。

### 3.2 课件契约（两类并存）
- **page-id 契约（新）**：`<div class="page" id="pageN">` + `checkOpt(this)`；**40–45 页、体积 ≥150KB 为硬线**。
- **slide 契约（旧/冻结）**：`<div class="slide" data-page="N">` + `checkQuiz`；25–60 页软性范围，部分旧件体积 <150KB（教师已批准放宽）。
- 六色要点卡：六色 `rc-zhug/bin/xing/ming/warn/qita`（用法/构成/易错/例句/注意/口诀），verify 要求 6/6。

### 3.3 verify_v2 校验器
- 硬规则：体积 ≥150KB（page-id）/ 页数 / div 开合平衡 / 答案分布**每选项 ≤40%** / JS `node --check` / 六色卡 6/6 / 防越级（`will`/`be going to`/完成时/被动等词表）。
- 软规则：可加警告不阻塞。任务书要求只提**软检查建议**，不碰硬校验。

### 3.4 词汇掌握等级 M0–M4（08 §3.6）
| 等级 | 定义 |
|---|---|
| M0 | 未掌握（从未接触或反复错误） |
| M1 | 能识别（听力/阅读中辨认） |
| M2 | 主动提取（见义出词/见词起义） |
| M3 | 拼写（正确拼写/词形） |
| M4 | 语境使用（新语境中正确运用） |

M4 硬性阈值示例：已 M3＋间隔 ≥7 天＋≥2 个不同日期成功＋无提示＋≥1 次主动提取/拼写＋≥1 次新语境。（精确定义见 08 §3.6，B1 调研须围绕 M0–M4 输出。）

### 3.5 组件库（M12 / C3 第一批）
- `components.py` + `nl_map.json`：13 组件 + 白话映射。**C3 第一批 3 个已实现**：GM-V02 主动提取提示梯、GM-G03 错句医生、GM-R06 阅读证据连线（各为独立 HTML/CSS/JS、离线、触屏替代、IndexedDB 事件、重置、无动画降级）。
- B3 要给「GM-V02 提示梯」制定正式规则（无提示→一级→二级→三级→显示答案→迁移题→复习池）。

### 3.6 词汇复习游戏规范（07）
- 三层体系：T1 词级 / T2 句级 / T3 篇章级，共 **29 种游戏**（T1×10 + T2×9 + T3×10），每课 3 个（课内 2 + 跨课 1），相邻 5 课不复用。
- 提示梯度 8 级（L1 图片+首字母+选项 → L8 新情境使用）；分级起始/终止：基础 L1→L5、中等 L2→L6、培优 L3→L8。
- B2 调研须对照这 29 种做取舍，不是泛泛谈游戏化。

### 3.7 学习数据闭环（08）
- 双层架构：答案先写 IndexedDB → 即时反馈 → 课后同步飞书。
- 飞书多维表格 **7 表**：学生 / 课程课次 / 词汇主表 / 题目主表 / 答题明细 / 词汇掌握 / 课次总结。同步三阶段（CSV 人工导入 → 本地同步工具 → 云函数实时）。
- D 类调研（教师周报/错题闭环/AI 建议）必须落到这 7 表 + M14（错题反馈闭环模块）上。

### 3.8 分级参数（04）
- 基础/中等/培优 23 项参数：生词率 15%/17%/20%、提示梯度起止、游戏层级配比、Exit Ticket 题量等。C4 调研不得把经验比例当科学结论，需与 `04_分级差异化参数表.md` 对齐。

### 3.9 语法体系
- `00_总规划\01_66语法考点全景图.md`（邓兴华权威映射）：66 个考点 G01–G66 按课分布；许颖嘉基础层语法上限=八上 U2；李民宪=人教版 2024 七下＋省卷拔高。
- 学生材料不提入学分数。

### 3.10 教学结构口径
- 项目存在「8段式」「9环节」**两种口径**（任务书已规定：不统一、不擅自改页数环节契约，只评价顺序与功能）。9环节见 `01_课件格式规范.md` §3.10 来源注。

### 3.11 卷面与规范状态
- `exam_spec_v2026_2.json` **locked=true**（官方 100 分模型，听力 20 独立分列）；配套练习按此对齐。

## 四、给调研 Agent 的工作约定（建议遵循）

1. **报告落盘**：`00_总规划\深度调研报告_2026-08-XX.md`，完成后登记 `00_格式规范\更新记录.md`。
2. **分阶段交付**：建议 A 类（P0 前端）→ B 类（教学心理）→ C/D 类（测评与数据）三批，每批可独立验收；A1 需要抓 Awwwards/CSSDA/Land-book/Godly 的 2026 案例。
3. **引用规范时**：写明对应文件与章节号（如 `08 §3.6`），让执行 Agent 能定位。
4. **遇到无法确认的项目对象**：用「⚠️ 需执行 Agent 确认」占位标注，不要猜默认值。
5. 证据等级（一级/二级/三级）与实施级别（立即实施/中期验证/不推荐/保留观察）必须逐条标注，三级证据（设计站案例）不得单独作为"提高学习效果"的依据。
