# D类研究报告

## D1教师周报最小指标、D2错题闭环、D3 AI教学建议边界

> **研究日期**：2026-08-04
> **适用对象**：12—15岁中国初中英语学习者
> **项目对象**：08学习数据闭环、飞书7表、M0—M4、M14错题反馈闭环、教师周报
> **教师时间预算**：每周查看和调整不超过30分钟
> **项目边界**：学生HTML继续离线运行；AI不得嵌入学生端核心流程，不在HTML中保存密钥

现有项目的数据路径是"IndexedDB本地采集→CSV/JSON导出→飞书7表汇总"，D类建议必须在该结构内实施。

# 一、执行摘要

## 1. 最重要的五项结论

### 结论一：仪表盘的价值不在于显示更多数据，而在于支持教师采取下一步行动

教师仪表盘研究普遍提醒，许多系统只展示表现和活动数据，却没有帮助教师完成"发现问题—解释问题—采取行动—检查结果"的闭环。2023年针对教师仪表盘的系统综述纳入50项研究，强调需要教师参与设计、明确教学目的、保护隐私并评价仪表盘是否产生实际教学行动；2024年K—12综述则指出，学校仪表盘的真实课堂实施和效果评价仍然不足。

因此，周报不能只显示：

```text
正确率
用时
点击数
页面停留
```

而必须显示：

```text
发现了什么
涉及哪个知识点
建议下一课做什么
建议占用几分钟
如何确认问题已解决
```

---

### 结论二：决定下一课的核心指标只需约6—8项

教师确实可能从进度、正确率、错误和任务行为中获得帮助，但教师将数据转化为教学行动的能力和使用方式存在明显差异；只有提供清晰解释、情境和行动入口，数据才更可能被实际采用。

本项目周报核心指标建议限制为：

1. 首次独立正确率；
2. 跨日复测结果；
3. 提示使用情况；
4. 同知识点连续错误；
5. 迁移题失败；
6. 高置信错误；
7. 最终确认错因；
8. 当前M0—M4及下次复习日期。

---

### 结论三：高置信错误值得重点处理，但不能只改一次就结束

高置信错误得到明确纠正后，往往比低置信错误更容易被立即修正，这一现象在儿童和课堂情境中均有观察；但部分错误会在一周后重新出现。研究还发现，在纠正反馈后立即进行一次提取测试，有助于降低错误重新出现的风险。

因此，高置信错误应触发：

```text
立即解释
→ 当场遮盖后重答
→ 同结构变式题
→ 跨日复测
```

而不是只显示一次正确答案。

---

### 结论四：错题闭环应优先使用变式题，而不是无限重复原题

2025年错误示例系统综述指出，从错误中学习的效果取决于先备知识、提示和反馈质量；低基础学习者面对复杂错误示例时，可能从正确示范和较强支架中获益更多。早期实验也发现，错误示例更可能帮助先备知识较好的学习者，而对基础较弱者，正确例题可能更有效。

因此：

* 原题用于确认和解释；
* 第二次测试优先使用同构变式；
* 基础学生先看正确结构再修错；
* 中等和培优学生可以先找错、解释错、再迁移。

---

### 结论五：AI建议只有在可解释、节省时间并保留教师决定权时才更可能被采用

2025年一项包含41名在职教师的研究发现，建议的可理解性、信任和接受度显著相关；基于学科知识的解释优于纯数据驱动解释。教师是否采纳还受到教学观念和是否真正减少工作量影响。其他2025年研究也把信息可信度、制度支持、自我效能等列为教师采用AI的重要因素。

UNESCO的教师AI能力框架强调以人为本、教师能动性、伦理和教师责任，AI应增强而不是替代教师判断。

# 二、D1：教师周报最小有效指标

## D1-01：核心必看指标

### 1. 首次独立正确率

定义：

```text
首次无提示正确题数
÷
首次有效作答题数
```

不得使用最终正确率代替。

用途：

* 判断知识是否真正能够独立提取；
* 区分"第一次就会"和"反复尝试后改对"；
* 决定下课是否需要返讲。

数据来源：

```text
答题明细表
is_first
is_correct
hint_used
```

**实施级别：立即实施。**

---

### 2. 跨日复测成功率

定义：

```text
不同日期、无提示、同知识点有效正确次数
```

用途：

* 区分当堂短期记忆和长期保持；
* 决定M3是否可以进入M4；
* 判断复习间隔是否合适。

数据来源：

```text
答题明细
＋
词汇掌握表
```

**实施级别：立即实施。**

---

### 3. 提示依赖

建议显示：

```text
无提示正确
一级提示正确
二级提示正确
三级提示或答案展示后正确
```

不要只显示"提示使用次数"。

用途：

* 判断学生当前需要哪一层支架；
* 防止提示后答对被错误计为独立掌握；
* 为下节课生成不同难度题型。

**实施级别：立即实施。**

---

### 4. 同知识点连续错误

定义：

```text
同一knowledge_id
连续两个有效任务均首次错误
```

有效任务应尽量来自：

* 不同题目；
* 不同句子；
* 不同日期；
* 或不同题型。

用途：

* 识别规则性问题；
* 区分单题失误与知识点不稳；
* 触发M14重点处理。

**实施级别：立即实施。**

---

### 5. 迁移题失败

定义：

```text
原题经反馈后正确
但新语境或同构变式仍错误
```

用途：

* 发现"记住答案但不会迁移"；
* 防止最终正确率制造假掌握；
* 决定是否回到规则、示范或更低支架。

**实施级别：立即实施。**

---

### 6. 高置信错误

定义：

```text
首次错误
＋
学生答前或答后确定度较高
```

不需要每道题都采集confidence。

建议只在以下题目采集：

* 单元诊断；
* 真题；
* Exit Ticket；
* 重点语法；
* 延迟复测；
* 教师标记题。

高置信错误在得到反馈后可能较容易立即修正，但也存在延迟后错误回归，因此必须安排后测。

**实施级别：中期实施。**

---

### 7. 最终确认错因

推荐字段：

```text
error_code_auto
error_reason_self
error_code_final
```

周报只显示：

```text
error_code_final
```

如教师尚未确认，显示：

```text
待确认
```

AI或系统不得自动把学生标记为"粗心""不认真"或"理解能力差"。

**实施级别：立即实施。**

---

### 8. 当前掌握状态及下一复习日期

显示：

```text
knowledge_id
当前M级
上次有效证据
下一复习日期
```

一页周报无需展示所有历史作答，只显示状态变化：

```text
M2 → M3
M3保持
M3 → 待复测
M4复测失败
```

**实施级别：立即实施。**

## D1-03：只用于技术排错的指标

以下数据不应进入教学周报：

* IndexedDB写入失败；
* CSV导出失败；
* `sync_status=failed`；
* JS异常；
* 页面加载失败；
* 音频播放失败；
* Canvas未初始化；
* 重复event_id；
* 异常长的页面停留时间。

这些数据进入：

```text
系统健康视图
```

不进入：

```text
学生学习报告
```

**实施级别：立即实施。**

## D1-04：不建议采集的数据

除非用于明确的界面实验，否则不建议长期采集：

* hover次数；
* 普通滚动距离；
* 动画播放次数；
* 卡片移动轨迹；
* 每次触屏坐标；
* 鼠标移动；
* 页面中每一个点击；
* 单纯登录次数；
* 无任务边界的总停留时间。

教师仪表盘研究目前仍存在"收集大量数据，却缺少现实课堂行动和效果评价"的问题，因此新增指标应先回答它会触发什么教学决策。

**实施级别：立即停止扩张。**

## D1-05：用时如何解释

原始`response_time_ms`不能直接表示掌握程度，因为它可能受到：

* 阅读速度；
* 输入法；
* 触屏误操作；
* 教师讲解；
* 学生离开座位；
* 页面切换；
* 网络或设备卡顿；

影响。

建议只计算：

```text
个人同类题中位数
+
异常倍数
```

项目初始规则：

```text
小于个人同类题中位数的0.25倍
→ 可能快速猜测

大于个人同类题中位数的2.5倍
→ 可能犹豫或发生中断
```

这两个阈值属于项目实验参数，不是科研统一标准。

用时不得单独触发降级，必须与正误、提示和题型联合判断。

## D1-06：一页教师周报

### 区域一：本周最需要处理的3个问题

| 知识点         | 证据          | 严重程度 |
| ----------- | ----------- | ---- |
| did后动词原形    | 3次首次错误＋迁移失败 | 高    |
| somewhere拼写 | 二级提示后正确     | 中    |
| 阅读事实定位      | 用时长但正确      | 观察   |

### 区域二：下节课3项动作

```text
1. did后原形：正确示范1题＋错句医生2题，预计6分钟
2. somewhere：无提示拼写＋新句，预计3分钟
3. 阅读定位：证据连线1题，预计4分钟
```

### 区域三：趋势

只显示：

* 首次独立正确率；
* 跨日复测成功数；
* 高优先级知识点数量；
* 提示依赖变化。

### 区域四：教师确认

```text
接受建议
编辑建议
暂不处理
错因需要确认
```

### 每周时间预算

项目初始预算：

```text
5分钟：阅读3条发现
10分钟：检查高优先级证据
10分钟：确认或编辑下节课动作
5分钟：补充教师判断
```

总计不超过30分钟。

## D1-07：指标触发教学行动

| 触发条件       | 建议动作           |
| ---------- | -------------- |
| 首次独立正确率低   | 增加规则示范和支架      |
| 最终正确但首次错误多 | 减少"最终正确率"权重    |
| 提示等级高      | 下节保留提示梯，不直接升级  |
| 同知识点连续错误   | 返讲或正确例题        |
| 迁移失败       | 增加同构变式         |
| 跨日失败       | 缩短复习间隔         |
| 高置信错误      | 显式反驳＋即时重测＋跨日复测 |
| 正确但长期用时高   | 保持等级，增加自动化练习   |
| 多题异常短时作答   | 检查猜测或界面问题      |

# 三、D2：M14错题闭环最小设计

## D2-01：不是所有错误都进入同一错题本

建议将错误分为五类：

```text
E1 首次提取失败
E2 形式或拼写错误
E3 规则或概念错误
E4 迁移失败
E5 延迟复测失败
```

辅助标签：

```text
高置信
使用提示
连续错误
异常用时
学生自评错因
```

错误类型决定处理方法，而不是简单按"错题次数"排序。

## D2-03：优先级算法

以下为项目初始算法，不是研究直接提供的固定权重。

```text
延迟复测失败              +5
迁移题失败                +4
高置信错误                +3
同知识点连续首次错误       +3
显示答案后才完成           +2
使用二级或三级提示         +2
首次错误但当场迁移正确     +1
异常长用时                 +1
```

建议分级：

```text
0—3  低
4—7  中
8及以上 高
```

算法必须保留每项构成，不能只保存总分。

例如：

```text
priority_score = 8
原因 = 迁移失败4＋高置信3＋用时异常1
```

这样教师才能理解为什么系统给出高优先级。

---

## D2-04：不同错误的处理方式

### E1：首次提取失败

```text
立即给提示
→ 再次提取
→ 同课稍后复测
→ 次日复习
```

适用于：

* 单词想不起来；
* 规则回忆失败；
* 阅读事实未定位。

---

### E2：形式或拼写错误

```text
标出错误位置
→ 学生修正
→ 遮盖答案再写
→ 1—3天后无提示复测
```

不要只让学生抄写正确形式。

---

### E3：规则或概念错误

基础学生：

```text
正确示范
→ 规则解释
→ 半完成例题
→ 独立题
```

中等或培优学生：

```text
找错
→ 解释为什么错
→ 修正
→ 变式迁移
```

错误示例研究显示，错误材料是否有效受到先备知识和提示质量影响；对低先备知识学习者，直接提供正确示范可能比要求自行诊断复杂错误更合适。

---

### E4：迁移失败

```text
回到结构
→ 更接近原题的变式
→ 新语境题
→ 跨日再测
```

迁移失败不应通过重复原题解决。

---

### E5：延迟复测失败

```text
掌握状态回退或标记不稳定
→ 缩短间隔
→ 换题型
→ 再次建立独立提取
```

如果学生原来达到M4但延迟复测失败，应保留历史M4证据，同时将当前状态标为：

```text
M4_REVIEW_REQUIRED
```

是否正式降为M3，应由08规范最终决定。

---

## D2-05：高置信错误闭环

高置信错误建议采用"显式反驳"结构：

```text
你原来的答案：
为什么它看起来合理：
它与规则冲突的地方：
正确结构：
立即重答：
变式题：
跨日复测：
```

八年级学生研究发现，明确指出并反驳错误观念的文本，比只陈述正确知识更有利于纠正高置信错误。

### 项目页面示例

```text
你的答案：didn't went

为什么容易选它：
句子讲的是过去，容易保留went。

关键冲突：
didn't已经承担过去时，后面的动词必须恢复原形。

正确形式：
didn't go
```

---

## D2-06：原题和变式题的使用

### 原题

只用于：

* 展示首次答案；
* 解释错误；
* 当场确认是否看懂；
* 一次遮盖后重答。

### 变式题

用于：

* 检验规则是否真正掌握；
* 避免记住位置或答案；
* 跨日复测；
* M3—M4升级。

推荐比例：

```text
原题重答1次
+
至少1道同构变式
```

该比例是项目初始规则。

## D2-07：复习排期

### 高优先级

```text
当场纠正
→ 同节课变式
→ D1
→ D3—D5
→ D7—D14
```

### 中优先级

```text
当场纠正
→ D2—D3
→ D7—D10
```

### 低优先级

```text
当场确认
→ 下一正常复习周期
```

如果跨日失败，重新进入高优先级。

## D2-08：退出错题池的条件

知识点退出主动错题池，建议同时满足：

1. 最近一次无提示正确；
2. 至少一次同构变式正确；
3. 至少一次跨日期复测正确；
4. 没有答案展示；
5. 最近两次没有连续同类错误；
6. 当前等级达到对应目标；
7. 教师未手动锁定。

M4知识点建议继续保留低频抽查，不从长期数据中删除。

---

## D2-09：教师覆盖机制

教师可以：

```text
提高优先级
降低优先级
修改错因
推迟复习
提前复习
标记设备问题
标记题目有误
标记本次数据无效
```

所有覆盖应记录：

```text
override_by
override_at
override_reason
```

不得删除原始系统判断。

# 四、D3：AI生成教学建议的边界

## D3-01：AI最适合生成的建议

教师更可能采纳以下建议：

### 1. 数据明确、范围很小

例如：

```text
did后动词原形在3道不同题中首次错误，
其中1道迁移失败。
建议下节安排6分钟：
正确示范1题＋错句医生2题＋迁移1题。
```

### 2. 能说明数据来源

每条建议必须附：

```text
涉及题目
知识点
日期
首次答案
提示使用
迁移结果
```

### 3. 教师可以立即编辑

建议应允许：

```text
接受
修改题量
修改预计时间
换组件
推迟
拒绝
```

### 4. 明确节省什么工作

例如：

* 自动整理高优先知识点；
* 自动生成复习池；
* 自动起草周报；
* 自动推荐现有组件；
* 自动提供备选题型。

教师采纳AI工具的重要因素包括可理解性、可信度、教学契合度和减轻工作量；学科化解释比纯技术或纯统计解释更容易得到信任。

**实施级别：立即实施。**

---

## D3-02：AI不应自动完成的任务

AI不得直接：

* 判断学生"粗心"；
* 判断学生态度；
* 给学生贴能力标签；
* 自动修改长期课程规划；
* 自动修改锁定的`exam_spec`；
* 自动修改M0—M4最终状态；
* 自动给开放写作定最终成绩；
* 自动删除错题；
* 自动降低学生层级；
* 自动向学生或家长发送报告；
* 自动替教师决定是否返讲。

UNESCO强调以人为本、教师能动性和人类责任，教育AI应保留教师的专业自主权。

**实施级别：明确禁止。**

---

## D3-03：AI建议卡片格式

```text
建议：
下节课安排6分钟复习did后动词原形。

触发数据：
最近2课共3次首次错误；
1次高置信错误；
反馈后原题正确，但迁移题错误。

涉及知识点：
GR_L02_DID_BASE

建议动作：
正确示范1题；
错句医生2题；
新语境迁移1题。

预计用时：
6分钟

建议理由：
错误跨题重复，且已经出现迁移失败。

数据充分性：
中

需教师确认：
是
```

---

## D3-04：数据充分性，不使用模糊"AI置信度"

AI不应仅显示：

```text
置信度92%
```

除非该百分比经过可靠校准。

建议改为可解释的数据充分性：

### 低

```text
只有1次作答
或
只出现于同一道题
```

### 中

```text
至少2道不同题
或
至少2个有效时间点
```

### 高

```text
不同题型
＋
不同日期
＋
错误模式一致
```

以上是项目操作分级，不是统计学概率。

---

## D3-05：AI建议的触发门槛

### 可自动生成草稿

* 同知识点连续错误；
* 延迟复测失败；
* 迁移失败；
* 高置信错误；
* 提示依赖明显；
* 多个知识点到期复习；
* 周报生成。

### 必须教师确认

* 返讲建议；
* 调整课程难度；
* 更改学生层级；
* M等级降级；
* 错因最终确认；
* 开放写作评价；
* 面向家长的报告；
* 任何涉及情绪、态度或能力的解释。

---

## D3-06：AI建议长度限制

每周最多：

```text
本周发现：3条
下节课建议：3条
需教师确认：1—2条
```

每条建议正文建议控制为：

```text
60—120个中文字
```

再提供"展开证据"。

该字数属于项目界面参数，不是研究阈值。

仪表盘研究强调信息必须支持下一行动，而不是只增加数据展示；教师参与、行动性和情境适配是采用的关键。

---

## D3-07：接受、编辑、拒绝流程

### 接受

记录：

```text
recommendation_status = accepted
```

并加入下一课设计卡。

### 编辑

保存：

```text
original_recommendation
teacher_revision
```

AI可以从修改中总结项目规则，但不得私自更改历史记录。

### 拒绝

教师选择理由：

```text
数据不足
题目本身有问题
本周时间不足
已经口头处理
学生状态特殊
建议不适合
其他
```

拒绝理由用于改进建议规则，不用于评价教师。

---

## D3-08：AI建议生成位置

由于学生端必须保持离线、无后端、无密钥，AI建议不进入学生HTML核心代码。项目的离线和数据导出边界已经明确。

推荐流程：

```text
学生HTML离线答题
→ IndexedDB
→ CSV/JSON
→ 飞书7表或教师端本地工具
→ 生成建议草稿
→ 教师审核
→ 写入下一课设计卡
```

AI只处理教师端已经导出的必要字段。

---

## D3-09：隐私与最少数据

AI建议输入优先使用：

```text
student_id
knowledge_id
题型
首次正误
提示等级
迁移结果
延迟复测
教师确认错因
```

原则上不需要：

* 学生完整姓名；
* 住址；
* 联系方式；
* 学校班级敏感信息；
* 无关聊天记录；
* 完整录音；
* 入学分数；
* 家庭信息。

UNESCO的GenAI教育指导强调数据保护、隐私、人类能动性及对系统进行监测和验证。

# 六、立即实施条款

## MUST

1. 周报首页只展示能触发教学行动的指标；
2. 首次正确与最终正确分开；
3. 提示后正确与无提示正确分开；
4. 迁移失败单独记录；
5. 高置信错误必须安排跨日复测；
6. 错题闭环使用变式题；
7. 错因最终值由教师确认；
8. AI建议必须附触发数据；
9. AI建议必须允许接受、编辑、拒绝；
10. AI不得直接修改课程、等级或正式成绩；
11. 学生HTML不得放AI密钥；
12. 周报阅读和处理总时间不超过30分钟。

## SHOULD

1. 周报只显示3条重点发现；
2. 每条发现配一个具体动作；
3. 错题优先级保留分项原因；
4. 高优先错题采用当场、跨日和延迟三层复测；
5. AI建议使用数据充分性而不是虚假精确百分比；
6. 复习池退出需要无提示、变式和跨日证据。

## MUST NOT

1. 长期采集hover、鼠标轨迹和动画次数；
2. 用页面停留时间判断学生认真程度；
3. 用最终正确率代替掌握；
4. 无限重复同一道错题；
5. 用AI自动判断粗心或学习态度；
6. 自动给家长发送AI报告；
7. 自动降低学生层级；
8. 自动修改`exam_spec`；
9. 输出没有证据的长篇教学建议；
10. 将AI建议写成必须执行的命令。
