# 一、执行摘要

## 1. 七项核心结论

### 结论一：不存在有力证据支持"每页最多X字"的统一科学红线

多媒体认知负荷研究支持删减无关内容、突出结构、空间邻近、分段和减少冗余，但相关研究大量来自高等教育和STEM材料，不能据此推出适用于中国初中英语的统一字数上限。

因此，页面密度应按以下对象控制：

```text
任务数量
视觉焦点数量
信息组块数量
是否需要来回搜索
而不是单纯统计字数
```

### 结论二：视觉线索有效，但必须指向教学内容

涉及103项研究、12,201名学习者的Meta分析发现，标色、箭头、标题层级等信号能够改善保持和迁移，并降低认知负荷；另一项2026年Meta分析也整合了40项实验或准实验研究。但颜色、动画或高亮只有在指向重要内容时才是教学信号。

### 结论三：答错反馈必须清楚、可操作，不应评价学生人格或总体能力

面向10—16岁学生的2025年系统综述整合96项实证研究，发现个性化、清楚且可执行的反馈更有利于成绩、动机和参与；含糊、批评性或消极反馈可能引起回避和失去动机。

### 结论四：现有教学结构不应改成单一BOPPPS、PPP或TBLT

语法显性教学、形式聚焦和任务教学各有适用条件。直接以中国中学生为对象的研究表明，任务型和任务支持型教学都可能促进语法学习；但TBLT在课时有限的外语环境中可能缺少足够形式练习，因此更适合采用混合结构。

### 结论五：干扰项质量比选项数量更重要

多项实证研究发现，教师很难写出三个真正有效的干扰项；只保留两个高质量干扰项往往不会损害测量质量。但本项目正式试卷已经锁定，不能据此擅自把四选一全部改成三选一。

### 结论六：产出通常比单纯阅读更有记忆优势，但必须有支架

生成效应Meta分析显示，学习者自己产生信息通常比被动阅读具有记忆优势，但效果受任务限制程度影响；任务过于开放或学生基础不足时，产出可能失败或形成错误。

### 结论七：没有证据支持固定的"基础70%、中等20%、难题10%"作为普遍科学比例

分层教学和适应性难度总体可能产生小到中等正效应，但研究实现方式差异很大；掌握学习研究也存在支持与质疑并存的情况。因此，难度应根据首次正确、提示使用和迁移表现动态调整。

# 二、B4：认知负荷与页面密度

## B4-01：一个页面只设一个主任务

**结论**：

普通教学页面只应要求学生完成一个主要动作，例如：

* 阅读；
* 选择；
* 输入；
* 拖拽；
* 查看解析；
* 总结。

同一页可有多个信息块，但不能同时要求学生完成多个互相竞争的动作。

**证据**：

多媒体学习中的一致性、信号、冗余和空间邻近原则共同指向：学习者应能快速识别有关信息，避免把有限认知资源用于搜索、过滤和整合无关材料。

**实施级别**：立即实施。

---

## B4-02：删除"有趣但无教学作用"的装饰

无关趣味文字、插图或动画可能吸引学生花时间处理，却不能帮助建立目标知识结构。2023年实验显示，诱惑性细节即使没有明显打断内容整合，也可能通过分散注意损害回忆表现。

### 应删除

* 与课文无关的动画人物；
* 背景持续漂浮的词语；
* 阅读页上的装饰故事；
* 与知识点无关的冷知识；
* 只为增加页面体积的插图；
* 每题成功后的大规模庆祝。

### 可以保留

* 帮助理解词义的图片；
* 标记时态时间轴的图形；
* 阅读证据高亮；
* 对比语法结构的颜色；
* 指示当前任务步骤的图标。

**实施级别**：立即实施。

---

## B4-03：页面信息组块项目初始参数

以下不是科学定律，而是依据认知负荷原则制定的**项目初始参数**。

### 普通新授页

```text
1个主标题
1句任务说明
1—3个信息组块
1个主操作
```

### 语法精讲页

```text
1条核心规则
1个结构公式
1—2个对比例句
1个立即检查
```

如果必须讲三个语法考点，应拆成多个页面，而不是把三个考点的全部规则放在同一页。

### 选择题页

* 真题和诊断题：一题一屏；
* 同一知识点的短练习：每页2—4题；
* 需要详细反馈的题：不超过2题；
* 选项较长或含阅读证据：一题一屏。

### 词汇卡页

* 同时可见词卡建议4—6张；
* 触屏点击目标不低于约44px；
* 不应同时显示完整词义、音标、词形、搭配、例句、图片和动画；
* 首屏展示当前学习目标需要的信息，其余内容按点击展开。

### 阅读页

阅读属于例外：

* 保留完整语篇上下文；
* 不为追求一题一屏而反复切断文章；
* 使用左文右题或上文下题；
* 当前题对应证据应在文章中可定位；
* 解析默认折叠。

**实施级别**：中期验证后写入模板规范。

---

## B4-04：一题一屏不是所有场景都更好

### 适合一题一屏

* 首次诊断；
* 真题；
* Exit Ticket；
* 高置信错误；
* 需要提示梯；
* 需要详细错误分析；
* 阅读证据题。

### 不适合一题一屏

* 同一词义的三道快速识别；
* 简短搭配分类；
* 需要同时比较的句子；
* 成套的词形变化；
* 需要查看上下文的阅读；
* 思维导图。

分段原则支持由学习者控制复杂材料的节奏，但如果拆分页破坏比较关系或上下文，则会引入新的搜索负担。

**实施级别**：立即实施。

---

## B4-05：页面节奏不使用固定翻页速度

没有直接证据证明初中英语课件必须每隔固定秒数换页。

建议使用任务类型估时：

| 任务    |  项目初始时间 |
| ----- | ------: |
| 快速识别  |  20—40秒 |
| 主动提取  |  30—60秒 |
| 单项语法题 |  40—75秒 |
| 提示梯任务 | 60—120秒 |
| 真题＋解析 |   2—4分钟 |
| 短阅读题  |   2—4分钟 |
| 语篇精读  |  8—15分钟 |
| 句子输出  |   2—5分钟 |

这些是排课初始参数，不是学习心理硬阈值。

### 40分钟课堂建议

不要按页面平均分配时间。40—45页课件在40分钟内不可能逐页充分完成，应继续通过CORE、EXTEND、HOME决定实际课堂范围。

**实施级别**：立即明确为运行规则。

---

## B4-06：视觉焦点限制

### 项目初始规则

每页：

* 1个主焦点；
* 最多2个辅助强调；
* 同时自动运动的区域不超过1个；
* 阅读页自动运动区域为0；
* 正确反馈动画结束后恢复静态。

信号原则支持用视觉线索指向重要内容，但如果所有元素都高亮，就不存在信号。

**实施级别**：立即实施。

---

## B4-07：`verify_v2`页面密度软检查

建议增加：

| 检查     | 初始警告条件              |
| ------ | ------------------- |
| 卡片过多   | 单页`.card`超过8个       |
| 自动动画过多 | 当前页无限动画超过1个         |
| 主按钮过多  | 主要按钮超过3个            |
| 强调色过多  | 页面定义超过3种高饱和背景       |
| 超长说明   | 单段连续文本超过8行          |
| 解析未折叠  | 题目和长解析同时默认显示        |
| 阅读干扰   | 阅读页存在无限动画或Canvas背景  |
| 重复信息   | 同一句中英文内容以3种以上形式同时显示 |

这些只能作为警告，不能成为硬校验。

# 三、B5：答错后的情绪设计

## B5-01：反馈针对任务，不针对学生

应使用：

```text
这一步的动词形式还需要调整。
```

不使用：

```text
你没有掌握一般过去时。
```

面向10—16岁学生的系统综述表明，清楚、个性化、可执行的反馈更容易被使用；批评、含糊或不受信任的反馈可能引发压力、回避和失去动机。

**实施级别**：立即实施。

---

## B5-02：推荐错误反馈结构

```text
中性状态
→ 错误位置
→ 可执行提示
→ 再试机会
→ 必要时解释
→ 后续迁移
```

### 推荐措辞

#### 词汇

```text
词义方向正确，再检查拼写。
```

#### 语法

```text
助动词已经出现，请检查后面的动词形式。
```

#### 阅读

```text
这个选项与原文有一处不一致，请先找证据句。
```

#### 连续错误

```text
这个知识点暂时还不稳定，先看规则，再完成一道变式题。
```

#### 高置信错误

```text
你刚才很确定，但答案与规则不一致。这类错误值得重点复查。
```

---

## B5-03：红叉、颜色和音效

### 红色叉号

可使用小型错误图标，但不能：

* 全屏出现；
* 持续闪烁；
* 与失败音效同时强烈播放；
* 停留到下一题；
* 覆盖学生答案。

建议：

```text
小型"!"图标
＋
红橙色边框
＋
文字说明
```

### 失败音效

默认不播放，或仅使用很轻的中性提示音。

**不推荐**：

* 蜂鸣；
* 警报；
* 嘲笑；
* 游戏角色哭泣；
* 连续错误音阶下降。

### 正确音效

可以有短音效，但应允许关闭，并避免每个微小点击都播放。

**实施级别**：立即实施。

---

## B5-04：何时显示正确率

### 不建议

* 每答错一题立即刷新总正确率；
* 连续错误时显示巨大百分比；
* 显示历史最低分；
* 显示"低于平均"；
* 显示同伴排名。

青少年对评价和社会比较较为敏感，因此公开排名和明显的同伴比较具有额外情绪风险。

### 建议显示

#### 题目进行中

```text
已完成 4 / 8
```

#### 模块结束

```text
首次独立正确：5题
提示后修正：2题
需要复习：1题
```

#### 课次总结

```text
本节已稳定：
正在建立：
下节优先复习：
```

#### 阶段报告

显示趋势，而不是单次最低成绩：

```text
最近5课首次正确率趋势
提示使用趋势
跨日复测成功数
新语境使用情况
```

**实施级别**：立即实施。

---

## B5-05：成绩不等于能力标签

禁止根据一次作答生成：

* "英语基础差"；
* "记忆力弱"；
* "不认真"；
* "粗心型学生"；
* "阅读能力低"。

系统只能记录可观察行为：

```text
首次错误
用时较长
使用提示
证据选择错误
同类题连续错误
```

"粗心""紧张""不理解规则"等原因必须由学生自评或教师确认。

**实施级别**：立即实施。

---

## B5-06：错误后的情绪反馈不宜过度拟人化

一项在线形成性评价实验发现，情绪性反馈可以提高参与度，但加入教学代理并未提高迁移，甚至可能形成干扰。

因此不建议每次答错都出现动画角色安慰。

推荐：

* 一句中性支持语言；
* 一个明确下一步；
* 保留学生控制权。

**实施级别**：立即实施。

# 四、B6：课堂节奏模型

## B6-01：BOPPPS不能作为唯一权威结构

BOPPPS的六个环节具有良好的计划逻辑，但本轮没有找到足以证明其在中国初中英语中整体优于其他模型的高质量Meta分析。

因此：

* 可以用于检查课程是否有目标、参与、评价和总结；
* 不应要求把现有九环节改造成六环节；
* 不应因名称不同重复创建页面。

**实施级别**：保留为教师备课检查工具。

---

## B6-02：PPP适合作为语法微循环

PPP可解释为：

```text
Presentation
→ Practice
→ Production
```

适合：

* 新语法；
* 形式规则；
* 基础和中等学生；
* 短时、明确的语言结构。

下列中学生研究支持形式教学的价值：

* 981名荷兰中学生的研究发现，不同类型语法教学总体均优于没有语法干预；
* 显性和形式聚焦教学能够促进语法学习，但不同形式和学习者特征会影响结果。

### 项目映射

```text
语法精讲 = Presentation
随堂演练 = Practice
阅读/真题/输出 = Production或Transfer
```

PPP不应扩展成整节课只有：

```text
教师讲规则
→ 大量机械题
→ 最后一句造句
```

**实施级别**：立即作为语法段内部结构。

---

## B6-03：TBLT适合输出和迁移，不宜取代全部形式练习

TBLT强调以有意义任务为中心，但研究者也指出，在时间有限的外语课堂中，纯任务教学可能无法保证充分的高频语言输入和语法形式练习。

直接以150名中国中学生为对象的实验比较了任务型与任务支持型教学；另一项八年级EFL研究发现，任务前简短显性教学不一定全面提高任务表现，甚至可能对流利度或复杂度产生代价。这说明"先讲规则再做任务"不是所有任务的固定最佳顺序。

### 适合TBLT的环节

* 角色对话；
* 写旅行经历；
* 阅读后解决问题；
* 信息差；
* 复述；
* 根据证据完成结论；
* 真实情境迁移。

### 不适合完全任务化

* 初次拼写；
* 不规则过去式；
* 易错助动词规则；
* 首次自然拼读；
* 中考固定题型讲评。

**实施级别**：中期验证，但任务活动本身可以立即使用。

---

## B6-04：推荐混合模型

```text
检索复习
→ 明确目标
→ 简短输入或规则
→ 有支架练习
→ 阅读/真题
→ 有意义任务或迁移
→ 反馈修正
→ Exit Ticket
→ 思维导图总结
```

对应现有结构：

| 现有环节 | 教学功能                |
| ---- | ------------------- |
| 复习导入 | 检索、诊断、建立联系          |
| 新词学习 | 输入、识别、初次提取          |
| 语法精讲 | 显性教学、结构理解           |
| 随堂演练 | 有支架练习               |
| 阅读理解 | 输入、证据、语境            |
| 自然拼读 | 形式—语音联系             |
| 课堂游戏 | 综合提取或短时调节           |
| 课堂总结 | 反馈、模式归纳、Exit Ticket |
| 思维导图 | 结构化总结和复习导航          |

**实施级别**：立即实施，不改变页面契约。

---

## B6-05：复习不应只放在导入

建议分布：

```text
导入：旧知识无提示提取
新授后：短间隔复测
真题中：旧知识迁移
课末：Exit Ticket
后续课：跨日复习
```

**实施级别**：立即实施。

---

## B6-06：真题位置

### 语法型真题

放在：

```text
简短规则
→ 有支架练习
→ 真题
→ 错因
→ 迁移
```

### 阅读型真题

放在：

```text
阅读策略提示
→ 完整语篇
→ 真题
→ 证据
→ 干扰项分析
```

不要求所有真题集中到一个固定页面段，只要保留独立真题标识和完整闭环。

---

## B6-07：课堂游戏的位置

现有"课堂游戏"环节继续保留，但游戏机制可以分布于其他环节：

* 词汇段：主动提取；
* 语法段：错句医生；
* 阅读段：证据连线；
* 第⑦段：综合性游戏或跨课复习。

这样既不改现有环节，又避免把所有互动都堆到课末。

**实施级别**：立即实施。

---

## B6-08：思维导图定位

思维导图主要承担：

* 结构化总结；
* 关系展示；
* 复习导航；
* 下次检索线索。

不应在思维导图页首次讲授大量新知识。

**实施级别**：立即实施。

---

# 五、C1：干扰项和答案分布

## C1-01：正确位置不需要机械绝对平均，但必须避免系统偏差

大样本国家考试实验显示，正确答案及强干扰项的位置会对作答产生小但系统性的影响；其他研究也发现学生和命题者可能偏好中间位置。

### 项目结论

现有：

```text
每个选项位置不超过40%
```

可以继续保留，作为防止明显失衡的工程规则。

但应明确：

* 40%不是研究证明的唯一最佳阈值；
* 不要求每份小测精确25%；
* 题量很小时允许自然波动；
* 不能为了平衡位置破坏题目质量。

**实施级别**：保持现状。

---

## C1-02：增加答案序列软检查

建议警告：

* 同一位置连续出现3次；
* 末10题某位置超过50%；
* 中间选项长期显著偏高；
* 答案形成明显ABCD循环；
* 正确选项长期比干扰项更长；
* 正确选项长期具有更完整语法结构。

系统综述指出，选项位置指南需要结合实证结果，而不是仅依靠命题传统。

**实施级别**：立即增加软检查。

---

## C1-03：干扰项必须来自真实错误机制

高质量干扰项应满足：

1. 明确错误；
2. 在当前语境中具有表面合理性；
3. 与正确答案属于同一语法或语义层级；
4. 不存在第二个可辩护答案；
5. 能对应常见错误或错误推理。

### 语法题

例如目标：

```text
did后动词原形
```

可用干扰项：

```text
went
goes
going
```

因为分别代表：

* 过去式未还原；
* 三单形式误用；
* 非谓语形式误用。

### 阅读题

干扰项类型：

* 原文有词但答非所问；
* 范围扩大；
* 主体偷换；
* 因果倒置；
* 时间地点混淆；
* 合理但原文未提及。

---

## C1-04：干扰项数量不应凌驾于质量

514道四选一题的分析中，只有约一半干扰项真正有效，很多题只有1—2个有效干扰项；大型研究也显示，一个高质量干扰项可能比多个低质量干扰项更有测量价值。

### 项目处理

* 正式试卷：继续遵守锁定题型；
* 非正式HTML练习：允许三选一；
* 不能为了"四选一"硬编明显错误选项；
* 如果只能写出两个合理干扰项，教学练习可以采用三选一。

**实施级别**：

* 正式卷：不改；
* 课堂练习：中期实施。

---

## C1-05：非功能干扰项数据检查

有历史数据后，将以下选项标为待审：

```text
选择率 < 5%
```

或：

```text
高水平学生比低水平学生更常选择错误项
```

非功能干扰项的修正或删除能够改善题目区分表现，但5%来自测量研究的常用操作定义，不应在样本很小的一对一数据中机械应用。

### 小样本项目处理

单个学生不能计算干扰项功能。

需要汇总：

* 多名学生；
* 多次课；
* 同题或同构题；
* 至少约30次有效作答后再进行初步判断。

该30次是项目最低观察量，不是正式心理测量标准。

---

## C1-06：干扰项质量软检查

| 检查      | 警告                  |
| ------- | ------------------- |
| 选项重复    | 两个选项语义等价            |
| 长度泄露    | 正确项明显最长             |
| 语法泄露    | 只有正确项与题干语法衔接        |
| 类别不一致   | 三个词同类，一个异类          |
| 绝对词     | 只有错误项使用always/never |
| 原文复刻    | 正确项机械复制原文，干扰项全部改写   |
| 否定混乱    | 题干和选项双重否定           |
| 无功能干扰项  | 有足够数据后选择率<5%        |
| 错误答案可辩护 | 可能存在两个答案            |
| 错因缺失    | 干扰项不能映射任何错误机制       |

# 六、C2：生成效应与产出题型

## C2-01：主动生成通常优于被动阅读

生成效应Meta分析发现，自己生成目标信息相较直接阅读具有约中等记忆优势；后续更大规模综述确认，生成限制程度是重要调节因素。

### 项目解释

有价值的产出包括：

* 见义写词；
* 拼写；
* 补全；
* 变形；
* 造句；
* 找证据；
* 改错；
* 自我解释；
* 摘要。

以下不算真正生成：

* 抄写答案；
* 翻开卡片后朗读；
* 反复点选直到正确；
* 看着完整单词拼一次；
* 拖动唯一可能选项。

---

## C2-02：产出难度必须可控

生成效应不是"越开放越好"。

基础不足时要求直接写完整句子，可能导致：

* 提取失败；
* 依赖翻译；
* 形成错误；
* 大量时间花在非目标问题；
* 失去动机。

### 支架梯度

```text
识别
→ 选择词块
→ 补全
→ 有提示产出
→ 无提示产出
→ 新语境产出
```

**实施级别**：立即实施。

---

## C2-03：项目题型配比

目前没有证据支持适用于所有初中英语课的固定比例。以下是**项目初始参数**。

### 课堂HTML

| 层级 | 识别/选择 | 有支架产出 | 独立产出 |
| -- | ----: | ----: | ---: |
| 基础 |   55% |   30% |  15% |
| 中等 |   40% |   35% |  25% |
| 培优 |   25% |   35% |  40% |

### 配套练习

| 层级 | 识别/选择 | 有支架产出 | 独立产出 |
| -- | ----: | ----: | ---: |
| 基础 |   45% |   35% |  20% |
| 中等 |   30% |   40% |  30% |
| 培优 |   20% |   35% |  45% |

这些比例应按学生数据调整，不进入硬校验。

---

## C2-04：为什么HTML和练习卷比例不同

HTML适合：

* 即时反馈；
* 提示梯；
* 短提取；
* 错误修正；
* 一题一屏。

练习卷适合：

* 连续书写；
* 完整句子；
* 段落；
* 无提示完成；
* 更真实的考试环境。

因此练习卷可安排更多独立产出。

---

## C2-05：提示后的产出如何计分

建议记录：

| 表现       | 学习记分 | 掌握证据 |
| -------- | ---: | ---- |
| 首次无提示正确  |  1.0 | 完整   |
| 一级提示后正确  |  0.7 | 部分   |
| 二级提示后正确  |  0.5 | 较弱   |
| 三级提示后正确  |  0.3 | 很弱   |
| 显示答案后重写  |  0.1 | 仅修正  |
| 新语境无提示正确 |  1.0 | 迁移证据 |

分值是项目分析权重，不是考试分数，也不是文献提供的标准。

---

## C2-06：自由产出如何判分

自由输出不宜只判"全对/全错"。

采用分析性指标：

```text
目标结构是否正确
目标词是否正确
句子是否完整
意义是否可理解
是否满足任务
```

不在当前目标中的小错误可以记录，但不应导致整题零分。

**实施级别**：立即实施。

# 七、C3：词汇巩固形式排序

不存在对所有目标都适用的统一排名。

## C3-01：初次认识

推荐顺序：

```text
词形—词义明确配对
→ 简短语境
→ L1释义或图片
→ 识别检查
```

阅读中的词汇注释总体能够提高学习，Meta分析发现母语注释通常优于目标语注释，多项选择式注释在所纳入研究中效果较好。

### 高证据

* L1简洁释义；
* 词形—词义配对；
* 语境例句；
* 注释阅读。

### 较低价值

* 只播放动画；
* 只展示图片但不确认词义；
* 只朗读不检查理解。

---

## C3-02：主动提取

推荐顺序：

```text
见词说义
→ 见义说词
→ 语境中提取
→ 延迟再次提取
```

技术辅助词汇学习Meta分析显示，接受性和产出性知识都能获益，但产出性学习通常更难，材料设计也更容易偏向识别。

### 高证据

* 主动回忆；
* 间隔检索；
* 反馈；
* 不同语境重复。

---

## C3-03：拼写

推荐：

```text
听或见义
→ 无提示拼写
→ 标出错误位置
→ 再拼
→ 延迟复测
```

次选：

* 字母重组；
* 首字母提示；
* 缺字母补全。

较弱：

* 抄写；
* 从唯一选项中选择；
* 完整词形一直可见。

---

## C3-04：词形变化

推荐：

```text
规则识别
→ 句中选择词形
→ 无提示变形
→ 解释变化原因
→ 新句应用
```

例如：

```text
interest
→ interesting / interested
→ 句中判断
→ 自己造句
```

不能只用词族树展示而不要求产出。

---

## C3-05：搭配和语块

推荐顺序：

```text
搭配识别
→ 词块配对
→ 句中cloze
→ 无提示补全
→ 句子生成
```

Cloze的价值取决于空格是否真正要求提取目标搭配。

低质量cloze：

```text
唯一语法可能答案
但不需要理解词义
```

高质量cloze：

```text
必须结合语义和搭配选择
```

---

## C3-06：长期保持

优先级：

```text
跨日期检索
>
同日重复检索
>
重新阅读
>
抄写
```

同一节课增加重复次数可能提高成绩，但控制学习时间后收益会减弱，说明单纯重复次数不是唯一关键。

长期保持必须结合：

* 间隔；
* 无提示提取；
* 变式；
* 反馈；
* 新语境。

---

## C3-07：语境迁移

推荐顺序：

```text
句中cloze
→ 句子改写
→ 句子生成
→ 阅读复现
→ 口头或书面任务
```

附带词汇学习通过阅读、听力或读听结合确实能产生学习，但平均只学习材料中一部分目标词，不能替代有意教学和检索。

---

## C3-08：按目标排序总表

| 目标   | 第一选择    | 第二选择  | 第三选择 |
| ---- | ------- | ---- | ---- |
| 初次认识 | 词义配对＋语境 | 注释阅读  | 图片匹配 |
| 主动提取 | 见义出词    | 语境提取  | 口头提取 |
| 拼写   | 无提示拼写   | 听写    | 字母重组 |
| 词形   | 句中变形    | 规则解释  | 词族分类 |
| 搭配   | cloze   | 词块配对  | 句子生成 |
| 长期保持 | 间隔检索    | 变式题   | 阅读复现 |
| 语境迁移 | 句子生成    | 阅读/写作 | 口头任务 |

---

## C3-09：与07游戏规范的关系

每种游戏应标注其主要学习机制：

```text
recognition
meaning_recall
form_recall
spelling
morphology
collocation
context_use
transfer
```

如果两个游戏只有视觉外壳不同、学习机制相同，不应同时算作两种独立的高价值复习形式。

**实施级别**：立即增加元数据；逐项审核需要07全文。

# 八、C4：三级难度梯度

## C4-01：难度不等于题目外表复杂

难度至少包括：

1. 知识是否学过；
2. 提示多少；
3. 是否需要主动提取；
4. 语言长度；
5. 干扰项相似度；
6. 语境新颖度；
7. 是否跨知识点；
8. 是否需要解释或迁移。

因此：

```text
长题 ≠ 一定难
选择题 ≠ 一定简单
开放题 ≠ 一定高质量
```

---

## C4-02：不采用固定70/20/10作为科学定律

掌握学习Meta分析有正面结果，但也有研究指出其在标准化成绩和长期保持方面的证据有限。

因此，04分级表中的比例可以继续作为项目参数，但必须标记：

```text
工程初始参数
不是普遍科学比例
```

---

## C4-03：按成功区间动态调整

### 项目初始规则

以最近两个有效任务组计算：

#### 升级

同时满足：

```text
首次独立正确率 ≥ 85%
提示使用率 ≤ 15%
迁移题正确
用时未明显异常
```

下一组：

* 减少提示；
* 增加语境变化；
* 增加一项产出；
* 不必增加生词量。

#### 保持

```text
首次独立正确率 65%—84%
```

维持当前难度，针对错误提供变式。

#### 降低或增加支架

```text
首次独立正确率 < 65%
或
提示使用率 > 50%
```

处理：

* 缩短句子；
* 去掉一个干扰变量；
* 回到相关规则；
* 改为有支架产出；
* 不必立即降低知识目标。

这些数值是项目初始阈值，需用实际学生数据验证。

---

## C4-04：基础学生仍必须接触高阶任务

基础层不能永远停留在识别题。

每个知识点至少经过：

```text
识别
→ 有支架提取
→ 独立提取
→ 简单语境
```

难度可以通过支架降低，而不是删除迁移目标。

**实施级别**：立即实施。

---

## C4-05：培优学生仍需要基础题

培优层保留基础题的用途：

* 快速诊断；
* 检查自动化；
* 建立信心；
* 确认前置知识；
* 形成对照。

但基础题应：

* 数量少；
* 速度快；
* 答对后快速跳过；
* 不占据主要课堂时间。

---

## C4-06：难度由学生表现而不是标签决定

"基础、中等、培优"用于初始参数，不应成为永久上限。

例如基础学生连续稳定完成某知识点后，应在该知识点获得中等难度任务；培优学生在新知识点上也可能需要基础支架。

适应性学习研究显示，学校中的自适应通常主要依据表现数据调整导航、支持和难度，但该领域在学科和实现方式上仍不均衡。

**实施级别**：中期实现。

---

## C4-07：难度配置建议

以下是项目初始参数，不是科研固定比例。

### 基础

```text
基础巩固 55%
有支架迁移 30%
独立挑战 15%
```

### 中等

```text
基础巩固 35%
有支架迁移 40%
独立挑战 25%
```

### 培优

```text
基础巩固 20%
有支架迁移 35%
独立挑战 45%
```

关键不是比例本身，而是每课必须包含：

* 可成功部分；
* 需要努力部分；
* 至少一个迁移部分。

---

## C4-08：难度调整数据字段

最低需要：

```text
is_first_correct
independent_correct
hint_level
response_time_ms
transfer_correct
knowledge_id
difficulty_before
difficulty_after
```

不能只用最终正确率自动调难度。

# 九、立即实施条款

## MUST

1. 每页只有一个主任务；
2. 阅读页不得有持续装饰动画；
3. 解析默认折叠；
4. 反馈必须说明下一步；
5. 不公开排名和历史最低分；
6. 思维导图不首次讲授大量新知识；
7. 干扰项必须映射真实错误机制；
8. 首次答案与提示后答案分开记录；
9. 每个知识点必须包含至少一次产出；
10. 基础学生也必须接触有支架迁移题；
11. 培优学生仍保留快速基础诊断；
12. 难度调整不得只看最终正确率。

## SHOULD

1. 普通页面控制在1—3个信息组块；
2. 真题和详细诊断采用一题一屏；
3. 三个语法考点分页面讲解；
4. 游戏机制分散到对应环节；
5. 课堂练习可在干扰项不足时使用三选一；
6. 每种游戏标注学习机制；
7. 自由输出采用分析性评分；
8. 按首次正确、提示和迁移动态调难度。

## MUST NOT

1. 规定没有依据的统一每页字数；
2. 用强失败音效；
3. 每次错误都刷新巨大正确率；
4. 根据一次错误给学生贴能力标签；
5. 为凑四选一写明显错误的干扰项；
6. 把固定70/20/10称为科学定律；
7. 把抄写计为独立产出；
8. 把同一游戏换皮当作不同学习机制。
