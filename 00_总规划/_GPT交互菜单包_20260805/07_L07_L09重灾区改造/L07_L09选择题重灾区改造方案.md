# L07/L09选择题重灾区改造方案

> 重要：本方案根据此前审计记录重建。执行前必须重新读取真实HTML，确认页码、知识点和题目数量；不得盲目按页号覆盖内容。

## 一、目标

邓兴华中等层启动验收：

```text
全课选择题占比 ≤ 45%
语法/词汇/综合诊断热区选择题 ≤ 35%
纯识别题 ≤ 50%
全课主动作 ≥ 4种
连续选择主导页 ≤ 2页
语法/词汇普通页选择题 ≤ 2道
```

比例按题目容器计数，不按A/B/C/D按钮数计数。

## 二、不改内容

- 不改变知识点、题干事实、正确答案和阅读原文；
- 正式中考阅读单选保留；
- 不改`CORE_CSS`、`CORE_JS`、`courseware_core.py`；
- 不新增第三方拖拽库或第二数据库；
- 不为追求动作数量使用不适合知识目标的组件。

## 三、L07重点

### p14综合错题/诊断过密

目标结构：

```text
1道正式选择诊断
+ 1组错句定位
+ 1道无提示修正输入
+ 1道同构迁移
```

### p28—p40 EXTEND连续热区

将连续选择页改造成动作轮换。建议动作序列：

| 页 | 首选动作 | 候选模板 | 约束 |
|---|---|---|---|
| p28 | 点 | C-POINT-DIAGNOSE / G-POINT-ERROR | 最多1—2道正式选择 |
| p29 | 写 | G-WRITE-FORM / C-WRITE-SCENARIO | 无提示产出 |
| p30 | 拖 | G-DRAG-CLASSIFY / C-DRAG-DECISION | 必须有点选替代 |
| p31 | 排 | G-ORDER-SENTENCE | 语序或词块适用时使用 |
| p32 | 连 | G-LINK-RELATION / C-LINK-EVIDENCE | 关系或依据必须真实 |
| p33 | 写 | V-WRITE-RECALL / C-WRITE-SCENARIO | 目标词/形式唯一 |
| p34 | 点 | G-POINT-ERROR / C-POINT-DIAGNOSE | 不连续超过2页选择主导 |
| p35 | 拖 | V-DRAG-CATEGORY / C-DRAG-DECISION | 不以换皮代替认知变化 |
| p36 | 排 | C-ORDER-DIALOGUE / G-ORDER-SENTENCE | 对话/句序适用 |
| p37 | 连 | V-LINK-COLLOCATION / C-LINK-EVIDENCE | 记录配对证据 |
| p38 | 写 | G-WRITE-FORM / V-WRITE-RECALL | 首答与终答分开 |
| p39 | 点 | 正式选择＋理由层 | 只保留必要干扰项 |
| p40 | 应用 | C-WRITE-SCENARIO / C-ORDER-DIALOGUE | 新语境迁移 |

如果真实内容不适合某动作，应从同认知层级候选中替换，并在报告中说明。

## 四、L09重点

此前标记的高密度页：`p22/p24/p26/p29/p34/p35/p37`。

| 页 | 目标改造 | 首选模板 |
|---|---|---|
| p22 | 1选择诊断＋1无提示生成 | C-POINT-DIAGNOSE + G-WRITE-FORM |
| p24 | 句序/答语关系 | G-ORDER-SENTENCE / G-LINK-RELATION |
| p26 | 分类后输入 | G-DRAG-CLASSIFY + G-WRITE-FORM |
| p29 | 正式题＋证据/理由 | C-POINT-DIAGNOSE + C-LINK-EVIDENCE |
| p34 | 情境补全 | C-WRITE-SCENARIO |
| p35 | 搭配/规则关系 | V-LINK-COLLOCATION / G-LINK-RELATION |
| p37 | 听后回应；无音频时教师朗读 | C-LISTEN-RESPOND；备用C-WRITE-SCENARIO |

每页原则：

```text
最多2道选择
+ 1组操作/证据
+ 1—2道生成或应用
```

## 五、阅读保留规则

- 正式阅读单选原题保留；
- 每3道单选至少配1个证据定位，或每篇至少1道短答/摘要；
- 阅读选择仍计入全课选择比例；
- 只有明确`lesson_mode=exam_simulation`的模拟课可例外。
