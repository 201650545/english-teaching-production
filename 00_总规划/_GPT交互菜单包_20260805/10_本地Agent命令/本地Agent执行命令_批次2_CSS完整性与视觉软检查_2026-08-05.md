### 9.1 必需选择器生成原则

实际合同应来自：

1. 新page-id课件共同使用的核心结构；
2. HTML实际出现的组件；
3. 组件注册或生成器能够确认的CSS合同；
4. 六色卡、选择题、阅读、解析、思维导图等实际类名。

不得要求“本课未使用的组件选择器”存在。

推荐按使用触发：

```text
HTML出现触发class
→ 该组件合同中的required selector必须存在
```

### 9.2 allowlist

只加入确实不承担视觉的类，例如：

- `js-`开头的JS钩子；
- 数据或语义标记；
- 浏览器/库自动状态；
- 经原文确认只由父级继承、不需独立规则的类。

每个allowlist项写注释或在旁表说明理由。

不得把大量未定义class批量加入allowlist来消除警告。

## 十一、完整性ERROR

以下属于视觉资产损坏，可使新合同课件验证失败。

### CSS-I001 必需视觉标记缺失

适用：

```text
page-id
+
CW-VISUAL-CONTRACT:1
```

判定：

- 合同要求的CSS_EXTRA开始/结束标记缺失；
- 必需SECTION标记缺失；
- SECTION开合不成对。

### CSS-I002 当前使用组件的必需选择器缺失

判定：

```text
HTML触发某组件
+
该组件合同中的required selector未在CSS中定义
```

输出：

- 触发class；
- 缺失selector；
- 首次使用页面；
- 合同来源。

### CSS-I003 视觉层疑似整体删除

满足任一：

- 新合同课件的CSS_EXTRA正文为空；
- CSS_EXTRA选择器数为0；
- 相对可信基线选择器数下降超过30%；
- 相对可信基线CSS_EXTRA字节数下降超过30%；
- 实际使用的必需选择器缺失比例达到合同设定的高风险条件。

基线不足时：

- 不凭空制造ERROR阈值；
- 输出WARN“尚无可信基线”；
- 仍可根据空CSS、0选择器和必需选择器缺失产生ERROR。

### CSS-I004 style或CSS块明显损坏

判定：

- `<style>`开合数量异常；
- CSS花括号忽略字符串和注释后不平衡；
- CSS_EXTRA开始标记存在但结束标记缺失；
- SECTION开合不平衡。

不要把合法的复杂CSS误判为ERROR；无法确认时降为WARN。

### CSS-I005 核心组件裸样式

仅当：

- 组件确实出现在HTML；
- 合同明确该组件必须有选择器；
- CSS中不存在任何合同selector；
- 不在allowlist；

才输出ERROR。

普通class无同名selector仍是WARN。

## 十二、视觉WARN V1.0

实现时使用稳定编号。至少包含以下项目。

### A. CSS治理

#### CSS-W001 HTML class无静态选择器

```text
HTML静态class
- CSS class selector
- JS动态class
- allowlist
```

剩余项逐项WARN。

#### CSS-W002 CSS孤儿选择器

CSS class在HTML和静态可识别JS动态class中均未出现。

阈值：

```text
孤儿选择器占比 > 25%
```

注意共享组件可能误报。

#### CSS-W003 重复选择器

相同完整selector标准化后出现≥2次。

高风险信息：

- 是否位于同一SECTION；
- 是否重复设置相同属性；
- 属性交集。

不要自动删除重复定义。

#### CSS-W004 主题层越权

theme SECTION出现以下结构属性时WARN：

```text
display
position
grid-template-*
width
height
overflow
z-index
font-size
padding
margin
```

输出selector、属性和行号近似。

#### CSS-W005 `!important`治理

- 总数>5：WARN；
- 总数>10：HIGH-WARN；
- 没有`IMPORTANT-ALLOW`注释：逐项WARN。

允许标记示例：

```css
/* IMPORTANT-ALLOW: A11Y-REDUCED-MOTION; owner=verify; */
```

#### CSS-W006 选择器特异性偏高

满足任一：

- 使用ID selector；
- class/属性/pseudo-class总数>4；
- 后代层级>4。

#### CSS-W007 直接颜色过多

CSS_EXTRA不同hex/rgb/hsl字面量>18时WARN。

#### CSS-W008 圆角或阴影值过多

- 不同`border-radius`字面值>6；
- 不同`box-shadow`字面值>8。

#### CSS-W009 自定义属性缺少fallback

关键`var(--cw-*)`没有fallback且该变量在CSS中未定义时WARN。

只对`--cw-*`项目变量执行，避免噪音。

---

### B. 字体和层级

#### VIS-W101 小字号

- 显式字号<18px：WARN；
- 教学可见文字<16px：HIGH-WARN。

隐藏辅助文本、纯图标或明确allowlist除外。

#### VIS-W102 页面无标题

`.page`内没有：

- `h1/h2`；
- 或项目确认的标题class。

封面、纯游戏过渡页可allowlist。

#### VIS-W103 层级差不足

当标题、正文、注释均能静态解析时：

- 标题字号≤正文字号；或
- 最大最小字号差<4px。

低置信度WARN。

#### VIS-W104 长文居中

可见文本>120字符或≥3句，且容器命中居中规则。

静态不能确认computed style时，输出低置信度WARN。

#### VIS-W105 行距过紧

正文候选选择器显式`line-height < 1.4`。

#### VIS-W106 例词长串

单文本节点出现≥6个由中英文逗号或分号分隔的英文词。

使用近似正则：

```regex
\b[A-Za-z][A-Za-z'-]*\b(?:\s*[,，;；]\s*\b[A-Za-z][A-Za-z'-]*\b){5,}
```

---

### C. 页面密度和布局

#### VIS-W201 普通页卡片过多

- 普通页含`card`可见块>8；
- 规则或新授页>6。

#### VIS-W202 题目过多

尽可能根据实际题目容器而非option节点数判断：

- 普通选择题>4道/页；
- 输入、改错、拖拽或排序任务>2道/页；
- 完整解析>2份/页。

若只能统计option节点，使用独立编号标记为“节点密度”，不要冒充题目数。

#### VIS-W203 文本与卡片双高

- 可见文本>1400字符且卡片>4；
- 或可见文本>900字符且交互控件>12。

#### VIS-W204 疑似空页

可见文字<20字符，且没有：

```text
img svg canvas input button audio video iframe
```

#### VIS-W205 疑似过稀

文字20—60字符，只有1个小卡片，且无主视觉或任务控件。

章节过渡页allowlist。

#### VIS-W206 超宽阅读容器

静态满足任一：

- reading/passage/article容器无`max-width`；
- 显式宽度>1000px；
- 显式`max-width`>90ch。

该项WARN，运行时再确认。

#### VIS-W207 固定高度加隐藏溢出

同一规则同时包含：

```text
固定height
+
overflow:hidden
```

且作用于教学内容容器。

#### VIS-W208 横向溢出风险

- `width > 100vw`；
- 固定宽度>1280px；
- 长字符串容器无换行；
- flex子项大固定宽度且父容器无wrap。

---

### D. 交互、解析和状态

#### VIS-W301 长解析默认展开

解释容器默认可见，且：

- 文本>400字符；或
- 段落/换行≥6。

#### VIS-W302 正误只靠颜色

correct/error相关规则只设置颜色、背景或边框色，没有：

- 图标；
- 伪元素`content`；
- 文本标签；
- aria状态；
- 非颜色形状变化。

#### VIS-W303 缺少焦点或按压状态

存在按钮、选项或自定义tabindex元素，但：

- 无`:focus-visible`；
- 触屏选项无`:active`或状态class。

#### VIS-W304 触屏目标风险

仅检查显式尺寸：

- <24px：高风险；
- 主按钮/选项<44px：项目WARN。

没有显式尺寸时输出INFO或运行时检查建议，不能静态断言实际过小。

#### VIS-W305 Hover依赖

`:hover`改变`display/visibility/opacity`来显示重要内容，但没有对应focus、click或touch状态。

#### VIS-W306 无限猜测风险

JS中选择题允许反复改选，但没有：

- 首次答案保存；
- attempt限制；
- 锁定或正式提交阶段。

此项静态置信度低，输出WARN并附证据片段。

---

### E. 动画与装饰

#### VIS-W401 缺少减弱动画

存在`animation`或`transition`，但CSS中无`prefers-reduced-motion`。

#### VIS-W402 无限动画过多

- `infinite`动画>2处；
- 阅读、规则、解析或错误页出现任意无限动画。

#### VIS-W403 装饰干扰

reading/passage/rule/error页面含：

- Canvas背景；
- 粒子容器；
- 持续漂浮；
- 闪烁动画。

#### VIS-W404 大面积模糊

- `backdrop-filter`出现>2处；
- 页面根容器使用blur/backdrop-filter。

#### VIS-W405 高风险动画属性

keyframe或transition动画化：

```text
width height top left
```

仅WARN。

---

### F. 色彩与一致性

#### VIS-W501 单页背景色过多

能解析页面专属CSS时，不同背景字面量>6。

无法解析页面归属时只做全局趋势警告。

#### VIS-W502 高饱和颜色过多

将可解析hex/rgb转HSL：

- 饱和度>75%；
- 亮度35%—70%；
- 同页超过3种。

透明色、渐变和变量导致无法准确判断时不强判。

#### VIS-W503 组件视觉不一致

同类组件出现：

- >3种padding；
- >3种radius；
- >4种shadow。

## 十三、`verify_v2.py`集成

### 13.1 保持现有行为

不得改变既有：

- 命令行参数；
- PASS/FAIL文字；
- 结构硬检查；
- 页数检查；
- 体积检查；
- 答案分布；
- JS检查；
- 六色卡；
- 防越级。

### 13.2 集成方式

在现有HTML读取完成、结构识别完成之后调用视觉检查。

建议：

```python
from verify_visual_v1 import inspect_visual_html, load_visual_contract
```

输出分组：

```text
[CSS INTEGRITY ERROR]
[VISUAL HIGH WARN]
[VISUAL WARN]
[VISUAL INFO]
```

总结：

```text
visual_errors=N
visual_warnings=N
```

退出规则：

```text
既有硬检查失败
或
新合同page-id存在CSS完整性ERROR
→ FAIL / 非零退出

仅有视觉WARN
→ 仍可PASS，但必须打印警告
```

### 13.3 异常降级

视觉模块自身解析异常时：

- 打印`VIS-CHECK-ERROR`；
- 新合同课件若无法判断必需合同，按项目安全原则失败；
- legacy slide或无合同历史page-id只警告；
- 不影响输出完整的原有检查结果。
