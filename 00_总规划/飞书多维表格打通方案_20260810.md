## 一、定位原则

- **本地 markdown/JSON = 规范真源**（命令、红线、exam_spec、课表、汇报全留本地，不动）。
- **飞书多维表格 = 状态看板**（只放进度/任务流/汇报归集，不承载规范内容）。
- **单向同步为主**：本地 → 飞书。飞书不改数据，避免双源冲突。
- 复用现有 lark-cli（已绑定），**不需要**教师再建自建应用/拿凭据。

## 二、数据模型设计（新建 1 个 Base「英语教学流水线」）

### 表1 · 课程进度看板（核心，必做）
| 字段 | 类型 | 说明 |
|---|---|---|
| 学生 | 单选 | 许颖嘉/邓兴华/李民宪 |
| 课时 | 数字 | 如 21 |
| 课名/语法点 | 文本 | 从课表/命令解析 |
| 课型 | 单选 | 授课课/测试课/讲评课 |
| 状态 | 单选 | 已交付/已备未学/缺练习/待复核/已复核 |
| 蓝图/课件/练习/契约 | 勾选×4 | 四件套完成度 |
| 汇报文件 | 文本 | `05_交付与审核记录\xxx.md` 路径 |
| 复核结论 | 单选 | 通过/退回/待复核 |
| 已知偏差 | 文本 | 汇报 §4 摘录 |
