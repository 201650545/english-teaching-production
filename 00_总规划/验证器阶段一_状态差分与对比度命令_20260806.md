## 一、护栏分级原则（先定口径）

采用 GPT 报告 Q1.1 三态：

```text
PASS          明确满足
FAIL          已确认违反规则
INCONCLUSIVE  自动化无法可靠判断 → WARN / 人工复核
```

退出码映射：
- FAIL 且属**底线规则**（不可读/不可操作/交互造假/数据失真/判题错误）→ **ERROR 阻止交付**
- FAIL 且属**风格治理规则**（与声明风格有偏差、与近期相似）→ WARN
- INCONCLUSIVE → WARN，不自动判失败

> 目的：避免为减少漏检而误伤视觉创新（对齐 09 V2.0「验证器不审审美」边界）。

## 二、检查 1：状态差分（反换皮核心 · ERROR 级）

### 原理
真实交互后必须出现**合同要求的有效状态变化**；只有动画类名变化/时间戳变化/hover 过渡不算有效差分。

### 四层快照

```text
A. DOM/语义   selected、checked、aria-*、文本、顺序、容器关系
B. 业务状态   当前答案、得分、完成状态、尝试次数
C. 页面反馈   正误提示、按钮状态、进度状态
D. 数据状态   IndexedDB 新增或更新记录
```

### 题型判定要求

| 题型 | 必须出现的有效差分 |
|---|---|
| 单选/多选 | selected 变化 + 判题结果变化 + 数据记录变化 |
| 填空 | 输入值变化 + 判题结果 + 数据记录 |
| 排序 | DOM 顺序或顺序数组变化 + 判题状态 + 数据记录 |
| 连线 | 关系集合变化 + 可见连线/语义状态 + 数据记录 |
| 拖拽 | 目标容器归属变化 + 判题 + 数据记录 |

### ERROR 条件（任一无变化即 ERROR）
1. 合同要求的变化字段在操作后无任何有效变化；
2. 页面反馈变了但 IndexedDB 仍记录旧答案（判定写死）；
3. 仅靠 `nth-child` / 预设 `.correct` 类 / 位置判定（配合答案置换测试，见阶段二）。

### INCONCLUSIVE
- 无合同声明的题型 / 无法枚举操作脚本的交互 → WARN，不假装已验证。

### 实现建议
- 用浏览器自动化（Playwright）驱动：操作前快照 → 执行标准操作序列 → 操作后快照 → 对比合同要求。
- 复用现有 `CW-INTERACTION-CONTRACT:1` 门控：有合同才做差分检查，无合同降级 WARN。

## 三、检查 2：基础对比度（可读底线 · 部分 ERROR）

### 阈值（WCAG 2.2）

```text
普通文字   ratio < 4.5 → ERROR
大文字     ratio < 3.0 → ERROR
必要控件   ratio < 3.0 → ERROR
```

- **不四舍五入**：4.49 ≠ 4.5，判定用精确计算值。
- 例外豁免：装饰文字、非活动控件、标志文字、隐藏元素、纯背景照片/复杂渐变（这些 WARN/INCONCLUSIVE 交人工）。

### ERROR 条件（全部满足才 ERROR）
1. 元素承担正文/标题/提示/答案反馈/控件标签功能；
2. 元素当前可见；
3. 能确定最终文字颜色；
4. 能确定文字后实际背景颜色（无半透明多层叠加/照片/复杂渐变）；
5. 非标志/装饰/隐藏/非活动；
6. 计算值低于对应门槛。

### WARN / INCONCLUSIVE
- 背景为照片、复杂渐变、半透明多层叠加；
- canvas/SVG 无法稳定定位文字区域；
- 无法判断图形是否属理解内容必需。
→ 生成截图 + 元素定位，交人工复核。

### 实现建议
- 先接入 axe-core 或等价规则（纯色文字背景、控件名角色、重复 ID、明确对比度违规）。
- 状态色与正文色必须保持语义区分（成功/错误不能只靠明度差）。

## 四、豁免机制（防误伤）

禁止全局 `skip_visual=true`。豁免为**规则级、元素级、限时、可追踪**：

```json
{
  "validator_exceptions": [
    {
      "rule_id": "VIS-TARGET-024",
      "scope": { "page_id": "cover", "selector": "[data-action='inline-help']" },
      "exception_type": "inline",
      "reason": "控件位于正文句内，尺寸由行高限制",
      "evidence": "同页存在满足尺寸要求的等价帮助按钮",
      "expires": "2026-12-31",
      "approved_by": "teacher-review"
    }
  ]
}
```

约束：
- 禁止 `selector:"*"`、禁止整课件跳过规则；
- selector 必须实际命中；必须指定标准允许的例外类型；
- 必须有到期时间，到期后自动升 WARN/ERROR；
- 每条豁免进报告。

**不允许任意豁免的规则**：核心交互无法完成、判题错误、数据未记录、JS 阻塞异常、键盘陷阱、危险闪烁、颜色作为正误唯一信息。

## 五、交互目标识别（减少误判）

只把以下视为交互目标（封面装饰圆点/线条/图片/标题不查可点区）：
- `button` / `a[href]` / `input` / `select` / `textarea`
- `role=button/checkbox/radio/option` 等
- `tabindex>=0` 且存在操作处理
- 带项目交互合同标记的元素
