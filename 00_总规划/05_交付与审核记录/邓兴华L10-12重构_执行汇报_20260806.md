## 四、放行项及理由

| 放行项 | 理由 |
|---|---|
| CSS-I001（必需视觉标记缺失） | 本课件为独立 HTML 非引擎产物，不使用 CW-CSS-EXTRA/CW-SECTION 标记 |
| VIS-W101（字号过小 50-60个） | 均为导航栏/标签/辅助文字（11-15px），正文≥16px，不影响阅读 |
| CSS-W005（!important >5） | L09 修复翻页闪烁时引入的 !important，确保 .page display 正确 |
| CSS-W007（颜色字面量 >18） | 主题色已通过 :root 变量定义，少量硬编码为组件特定配色 |
| CSS-W008（border-radius/box-shadow 值过多） | 课件视觉创新导致多种圆角/阴影，不影响功能 |
| L11 六色卡 5/6（缺 rc-ming） | 课件内容无"明"类知识点，不强制使用全部六色 |
| 防越级命中 will（L10×1, L11×5, L12×1） | 均为阅读原文中的 will 用法（如 "will help you study better"），非语法教学越级 |
