## 一、修复要求（按缺陷类型，逐课落实）

### 1. 词汇快闪 → 真召回（L10 p2 / L11 p2 / L12 p2）
- **目标行为**：默认只显示英文（`mf-word`），中文（`mf-cn`）默认隐藏；点击卡片翻转显示中文；再点翻回英文。体现「看英文→回忆中文→点击确认」召回链。
- **L10 p2**：给 20 张 `.mini-flash-item` 补 `onclick="flipCard(this)"` + `flip-card` 样式（或等效隐藏/显示 `.mf-cn`），并补全局 `flipCard(card)` 函数：点此卡时 toggle 显示该卡中文。
- **L11/L12 p2**：重写 `flipCard(card)` —— 从「只做 scale(1.05) 缩放」改为「toggle 隐藏/显示该卡 `.mf-cn`（或翻转动画）」，中文初始隐藏。
- **校验**：浏览器打开页面，首屏看不到任何中文释义；逐卡点击，中文出现/隐藏交替；20 卡全部可点。

### 2. 拖拽分类 → 真判定（L10 p4 / L11 p4 / L12 p4+p23）
- **现状 bug 根因**：卡片 `onclick="sortCard(this,'分类名')"` 里传入的分类=卡片自身 `data-cat`，导致 `isCorrect = data-cat === category` 恒真；学生点两次卡自动入正确箱，**没有选择过程**。
- **修法**：改为「点词卡选中 → 点分类箱判定」两段式。
  - 卡片：`onclick="pickCard(this)"`，仅选中高亮（不立即入箱），样式 `.selected`。
  - 箱子：`onclick="dropCard(this,'箱子分类')"`，从待选卡取 `data-cat` 与箱子分类比较：相等→入箱+`correct`+音效；不等→标 `wrong`+错误音效+**双击撤销**（答错后双击卡片回到词池，符合 §3.8.2）。
  - 保留现有 `dd-bin` id（`bin-school`/`bin-rules`/`bin-food` 等）与词池结构。
- **L12 p23 介词时间箱**（`sortCard2`）：同样改为两段式，对齐上述模式。
- **校验**：浏览器把 school 类词拖进 action 箱必须标错并给撤销机会；正确入箱才计分；8+ 词全部有判定路径。

### 3. 连线配对错位（仅 L10 p10）
- 重排 `data-pair` 使正确配对唯一且与提示一致：
  - study↔**geography**（1），answer↔**the question**（2），complete↔**the exercise**（3），understand↔**the problem**（4），practice↔**the reason**（5）。
- 校验：按此连全部判对；若学生按旧顺序连（study↔the question）必须判错。**L10 p22（G27 连线）核对后已对齐则不动。**

### 4. 五选四答案泄漏（L10 / L15）
- 删除/隐藏 tip-box 中直接写答案的行（L10：「答案：1-B 2-D…」；L15：「正确答案：①B ②E ③D ④A（C为干扰项）」）。保留题目与选项，答案只保留在 `data-correct` 判定里。
- 校验：页面加载后源码中不再出现 `答案：` / `正确答案：` 字样（除解析反馈与数据属性）。

### 5. Exit Ticket 补齐（六课，规范 §3.7.4）
- **L10 p40**：现有 4 题（EX-01..04）补为 **5 题**，覆盖四类：REC（再认选择）、RET（主动提取/补全）、EXP（表达/翻译/造句）、学生自评（自我评估滑块/勾选「我已掌握___/还需复习___」）。
- **L11–L15**：各新建 **Exit Ticket 页**（末尾、`class="page"` 自增 id），5 题同上结构；题面用本课知识点（L11 情态/不规则复数/时间介词；L12 冠词/量词/some-any；L13 would like/how much-many/价格；L14 be-have/why-because/形容词；L15 天气/Could-Would/It 指代），**不超本课语法上限、不引入下阶段语法**。
- 每页带 `data-question-id="LNN-EX-01..05"`、答题即判、答错双击撤销、数据采集（IndexedDB）对齐现网。
- 校验：六课末尾各 1 页 Exit Ticket，5 题含自评；`verify_v2.py --force` 硬规则 0 ERROR。

### 6. 页码 + 环节流程标签（L11–L15，规范 §3.1 硬性要求）
- **目标行为**：每页右上/顶部可见「页码 `X / 总页数`」卡；顶部 54px 导航居中显示 8-Pill 环节标签（`①导入` `②新词20` `③语法精讲` `④随堂演练` `⑤阅读理解` `⑥自然拼读` `⑦综合提升` `⑧总结`），当前环节高亮、可点击跳转。
- **L11/L12（元素存在但不可见）**：`.nav-top`/`.nav-bottom`（含 `pageInfo`）当前被嵌套进**非活动 `.page`**（父级 `display:none` → rect 全 0）。修法：把两元素从 `.page` 内移出，挂到 `body`（或 `#presentation` 外）直接子级，保持 `position:fixed`；校验翻页时 `pageInfo` 随 `currentPage` 更新、8-Pill 当前环节高亮切换。
- **L13/L14/L15（结构缺失）**：HTML 中无 `nav-top`/`pageInfo`/`nav-bottom`。修法：补建与 L11 同款顶部 8-Pill 导航 + 底部 HUD 页码卡（`id="pageInfo"`），挂 `body` 直接子级，`position:fixed`；接 `showPage()` 里页码更新与环节高亮。8 个环节名对齐各课实际段（L13 购物/L14 外貌描述/L15 天气，若某环节无对应页则标为不可点灰态但保留占位）。
- **校验**：浏览器翻页，页码始终可见且数字随页变；顶部 8 环节标签始终可见、当前环节高亮、点击跳转对应首段页；`pageInfo`/`nav-top` rect 高度 >0。
