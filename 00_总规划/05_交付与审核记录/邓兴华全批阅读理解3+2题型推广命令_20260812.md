## 二、改造要求（同 §3.18，与上轮一致）

### 1. 题型配额（§3.18.1）
- 每篇 5 题，默认 3 无选项（fill-input）+ 2 有选项（quiz-opt）
- 必要时可降为 2+3，**必须标注「2+3 弹性」**
- 禁用 4+1 / 5+0 / 0+5

### 2. 按答案开放度分配（§3.18.2，MUST）
- 无选项→答案边界清楚的题（细节/时间/因果/指代）
- 有选项→开放度高的题（主旨/作者意图/复杂推断）
- 推断题默认有选项，禁为凑 3+2 强行制造坏开放题

### 3. data-answers 多答案判分（§3.18.3，MUST）
- 无选项题从 `data-correct` 升级为 `data-answers` JSON 数组
- 规范化判分（忽略大小写/空格/标点），禁止「包含关键词即判对」

### 4. 最低可接受答案防越级（§3.18.4，MUST）
- 每道无选项题记录六字段：`question` / `canonical_answer` / `minimum_acceptable_answer` / `accepted_answers` / `required_vocab` / `required_grammar`
- QA 硬检查：`required_vocab` ⊆ 本课词汇池，`required_grammar` ≤ 本课语法上限

### 5. placeholder 全局禁泄漏（§3.18.5，MUST）
- placeholder 不得含任何答案/同义答案/首字母提示

### 6. 交互实现（§3.18.8）
- 无选项：`fill-input` + `data-answers` 判定 + 双击撤销容错
- 有选项：`quiz-opt` + `checkOpt` 判定，保留 §3.17 选项方框等高轮转
