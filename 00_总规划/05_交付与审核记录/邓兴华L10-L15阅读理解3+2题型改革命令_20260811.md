## 二、题型结构改造要求（逐篇 5 题 → 3 无 + 2 有）

### 1. 题型配额（§3.18.1）
- 每篇 5 题，**默认 3 道无选项（fill-input）+ 2 道有选项（quiz-opt）**；3+2 是篇级默认配额，不固定 Q1–Q5 题号。
- 某篇无法产生 3 道合格开放题时可降为 **2 无 + 3 有**，但必须在题目区显式标注「2+3 弹性」。
- **禁用 4+1 / 5+0 / 0+5**。

### 2. 按答案开放度分配（§3.18.2，MUST）
- **无选项**给答案边界清楚的题：明确细节、人物/地点/时间、明确因果、简单指代、可直接从原文提取的信息。
- **有选项**给开放度高的题：主旨大意、作者意图、复杂推断、开放性词义判断、抽象概括。
- **推断/推理题默认有选项**（开放度最高，措辞差异大）；除非答案可从原文直接提取，否则不得设为无选项。
- **禁止为凑 3+2 强行制造坏开放题**——找不到第 3 道合格开放题就降 2+3，不硬凑。

### 3. 无选项题判分 · data-answers 多答案（§3.18.3，MUST）
- 数据契约：无选项题答案从单一 `data-correct` 升级为 **`data-answers`（JSON 数组）**，覆盖常见合理表达与语法变体。
  - 示例：标准答案 `school uniform` → `data-answers='["school uniform","a school uniform","their school uniform"]'`；`data-correct` 可保留作主答案锚点。
- **规范化判分**：忽略大小写、首尾空格、连续多空格、句末无意义标点后匹配。
- **禁止「包含关键词即判对」**：如关键词 `late`，`He wasn't late.` 含 `late` 但不等价 `He was late.`。
- 无法判定的答案：显示参考答案或交教师课堂判定，**不得用粗糙关键词硬判**。

### 4. 防越级 · 最低可接受答案（§3.18.4，MUST）
- 每道无选项题必须记录六字段：`question` / `canonical_answer` / `minimum_acceptable_answer` / `accepted_answers` / `required_vocab` / `required_grammar`。
  - 建议落在该篇阅读页 `<script>` 的题目数据对象中，或该课 `契约\` 下新建 `阅读题库_3+2.json` 统一存档（二选一，便于 QA 与后续 verify 软检查读取即可）。
- **QA 硬检查**：`minimum_acceptable_answer` 所需词汇 ⊆ 本课词汇池；所需语法 ≤ 本课语法上限。
  - L10 语法上限见 L10 契约；L11 = G28 情态动词 / G29 不规则复数 / G30 时间介词；L12/L13/L14/L15 各见本课契约 §三。
- **最低可接受答案原则**：允许短答案（如原文 `Students must wear school uniforms...` → 最低答案 `school uniforms`），不要求完整句；考阅读理解非造句。
- 若某题只有通过超纲结构才能自然表达，三选一：**改问法 / 允许原文摘录 / 改为选择题**。
- 核心原则：**允许学生「读得比写得难」，不得要求学生「写得比当前教学上限难」。**

### 5. 答案隐藏 · placeholder 全局禁泄漏（§3.18.5，MUST）
- **`placeholder` 属性禁止包含任何答案、同义答案、首字母或明显提示**。
- L11 A 篇历史曾发生 `placeholder="输入答案（如 school uniform）"` 真实泄漏——本轮新增的所有 fill-input 必须逐个核查；placeholder 一律写「输入答案」或「在此填写」等中性提示，**不得出现该题答案或同义表达**。
- 此条为全局 QA 规则，适用于本轮所有新增/改造输入框。
