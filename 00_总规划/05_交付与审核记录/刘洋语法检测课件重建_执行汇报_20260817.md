## 一、检测发现的问题（原版 v1.0）

**A. 题目数据致命 Bug（无法正常使用）**

| 题 | 原问题 | 性质 |
|----|--------|------|
| 第3题 for/since | 句子只挖1空，选项却是双词组合 `since / for`，第二空不存在 | 数据错误 |
| 第7题 stop doing/to do | `stopped to have` / `stopped working` 已写死，无空格 | 数据错误 |
| 第9题 情态动词推测 | `must be` / `can't be` 已写死，无空格 | 数据错误 |
| 第6题 定语从句 | 主句系动词 is 标成连接词，表语标成从句 | 三色标注错误 |
| 第1题 | 并列连词 so 标成主句，逗号标成连接词 | 三色标注错误 |

**B. 主题矛盾**
- 标题"复合句·三色标注"，但后10题是词法题（名词复数/冠词/序数词等），强行套三色框架 → 误导学生。

**C. 与试课流程单矛盾**
- 流程单 `试课流程单_35分钟.md` 明确"发《01_语法诊断》10 题，限时 8 分钟"，但原课件是 20 题、无计时器，与试课节奏不匹配。

**D. 交互/视觉缺陷**
- 无限时计时器（流程单硬性要求，但原课件是完整练习库不强制限时）
- 选项 hover 用 translateX 导致整行抖动
- 答完即锁死、无法复查错题
- 报告页逐题清单不可跳转
- 配色平淡

## 二、重建内容（v2.0）

### 2.1 题量修正
- 恢复为完整 **20 题**（前10初二核心语法 + 后10初一重难点/选词填空必考）
- 答案分布：A6 / B7 / C5 / D2，避免集中扎堆

### 2.2 Bug 修复

| 题 | 修复方式 |
|----|---------|
| 第3题 for/since | 改为挖 **两个空**（b + b2 + twoBlanks:true），选项 "since / for" 分别填充 |
| 第7题 stop doing/to do | 改为挖 **两个空**，选项 "to have / working" 分别填充 |
| 第9题 情态动词推测 | 改为挖 **两个空**，选项 "must / can't" 分别填充 |
| 第6题 定语从句 | 重排三色：主句/关系词空格/定语从句/主句谓语/从句2，标注正确归属 |
| 第1题 | so 正确归入连接词（红色），逗号移除连接词标记 |

### 2.3 视觉重建
- **配色**：深色背景 `#0F172A` + 蓝紫渐变品牌条 `linear-gradient(135deg, #2563EB, #7C3AED)`
- **卡片**：圆角 16px、阴影 `0 10px 30px`、过渡动画 `slideIn .4s`
- **进度环**：SVG circle + stroke-dasharray 动画，显示分数百分比
- **计时胶囊**：顶部品牌条右侧，正计时显示
- **三色智能降级**：仅含主句/连接词/从句的题显示蓝红绿图例，简单句自动隐藏

### 2.4 交互重建
- **正计时**：从 `00:00` 累加，结束页报告总用时，不强制交卷
- **即时反馈**：选后即时显示正误 + 解析，空格高亮填充
- **复查模式**：结束页错题清单可点击跳转，改答案后分数实时回滚
- **双空格渲染**：双空题（第3/4/7/9/11题）两空分别填充，`split(" / ")` 逻辑对齐

### 2.5 后10题修复
- 第11题名词复数：双空用 `b` + `b2` + `twoBlanks:true`，渲染逻辑对齐
- 三色标注保留（这些句子含主句/连接词/从句结构，与原设计一致）
- 答案分布均匀化
