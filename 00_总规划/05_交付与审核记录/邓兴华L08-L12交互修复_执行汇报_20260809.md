## 问题诊断

### 核心问题：orderClick 排序题无法工作（L09/L10/L11/L12）
- **根因**：`orderClick(el)` 函数只切换词块的 `.active` 类（高亮），**不交换 DOM 位置**。用户点击词块后视觉上纹丝不动，排序永远失败。
- **影响范围**：L09（1题）、L10（3题）、L11（5题）、L12（4题），共 13 道排序题
- **L08 不受影响**：L08 排序题用拖拽模式（draggable + dragStartHandler + orderDropHandler），不依赖 orderClick

### 次要问题：event.stopPropagation() 不安全调用
- L09/L10/L11/L12 的 `checkOpt`、`gameCheck`、`sortCard`、`b5Pick`、`b5ToggleBlank`、`flipCard` 共 6 个函数直接调用 `event.stopPropagation()`
- 在 onclick 调用时 `window.event` 可用，但某些场景（如 Playwright 测试、某些浏览器严格模式）可能出错
- 已修复为 `if(typeof event!=='undefined'&&event)event.stopPropagation()`

### L08 特殊情况
- 选择题用 `handleQuizMeta`（非 `checkOpt`），38 个 `<button class="quiz-opt">` ✅ 正常
- 填空用 `checkSpell`（非 `checkFill`），用 `inputId` 参数 ✅ 正常
- 数据采集用 `saveData`（非 `saveAnswer`）+ `exportJSON`/`exportCSV`/`syncStatus` ✅ 正常
- 排序用拖拽 ✅ 正常

## 修复内容

### 1. orderClick 函数重写（L09/L10/L11/L12）
旧实现（只切换 class，不交换位置）：
```js
function orderClick(el) {
  var active = container.querySelector('.order-chunk.active');
  if (active && active !== el) active.classList.remove('active');
  el.classList.toggle('active');
}
```

新实现（交换 DOM 位置）：
```js
function orderClick(el) {
  if (typeof event !== 'undefined' && event) event.stopPropagation();
  var container = el.closest('.order-container');
  if (!container) return;
  var active = container.querySelector('.order-chunk.active');
  if (!active) { el.classList.add('active'); return; }
  if (active === el) { el.classList.remove('active'); return; }
  // 交换 active 和 el 的 DOM 位置
  var parent = active.parentNode;
  var activeNext = active.nextSibling;
  var elNext = el.nextSibling;
  if (activeNext === el) parent.insertBefore(el, active);
  else if (elNext === active) parent.insertBefore(active, el);
  else { parent.insertBefore(el, activeNext); parent.insertBefore(active, elNext); }
  active.classList.remove('active');
  el.classList.remove('active');
}
```

操作方式：点击第一个词块（高亮），再点击第二个词块 → 两词块 DOM 位置互换。
