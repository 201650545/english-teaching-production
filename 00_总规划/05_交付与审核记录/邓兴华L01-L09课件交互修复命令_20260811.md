## 一、统一排查清单（逐课、逐缺陷实测）

执行 Agent 对每课打开课件 HTML，逐项检查以下 **5 类逻辑缺陷**：

### ① 词汇快闪 = 静态 / 假召回
- **判定**：找到词汇快闪页（含 `mini-flash-item` / `flash-card` / 翻卡组件）。
  - 若卡片**无 onclick** 且英文+中文同屏展示 → 缺陷（同 L10 p2）。
  - 若 `onclick="flipCard(this)"` 但 flipCard 只做 `scale(1.05)` 缩放、不隐藏中文 → 缺陷（同 L11/L12）。
  - 若 flipCard 真调用（点击切换中英显示/翻转动画）→ PASS。
- **修复**：默认只显英文（`mf-word`），中文（`mf-cn`）默认隐藏；点击卡片翻转/切换显示中文；再点翻回。补/重写 `flipCard(card)`。

### ② 拖拽分类 = 假游戏（category 硬编码）
- **判定**：找到拖拽/分类游戏（含 `dd-bin` + `sortCard`/`sortCard2`）。
  - 若卡片 `onclick="sortCard(this,'分类名')"` 且**分类名=卡片自身 data-cat** → `isCorrect = data-cat===category` 恒真，二次点击自动入正确箱 → **假游戏**（同 L10 p4）。
  - 若卡片仅选中、箱子 onclick 判定（选卡→点箱→比较 data-cat 与箱类别）→ PASS。
- **修复**：改两段式——卡片 `onclick="pickCard(this)"` 仅选中高亮；箱子 `onclick="dropCard(this,'箱类别')"` 从待选卡取 data-cat 与箱类别比较；相等→入箱+`correct`+音效；不等→标 `wrong`+错误音效+**双击撤销**。保留现有 `dd-bin` id 与词池结构。

### ③ 连线配对错位
- **判定**：找连线页（`link-item` + `data-pair`）。核对左右 `data-pair` 是否与页内提示/正确搭配一致。
  - 若正确连法被标错（如 L10 p10 的 study↔the question）→ 缺陷。
  - 若左右对齐、正确连法判对 → PASS。
- **修复**：重排 data-pair 使正确配对唯一且与提示一致。L07/L08/L09 有 link-item，逐页核对。

### ④ 五选四 / 选择类答案泄漏
- **判定**：搜索 `答案：` / `正确答案：` / `答案：1-` 等字样。
  - 若在选项区外（tip-box/段落）直接写出答案 → 缺陷（同 L10/L15）。
  - 若仅存在于 `data-correct`/解析反馈（答题后显示）→ PASS。
- **修复**：删除/隐藏直接答案行；答案只保留在 `data-correct` 判定与答题后解析里。

### ⑤ Exit Ticket 缺失 / 不足 5 题
- **判定**：搜索 `Exit Ticket` / `出门检测` / `L0N-EX-` 题 ID。
  - 无该页 → 缺陷（新建）。
  - 有但 <5 题、或缺 RET 主动提取/EXP 表达/自评 → 缺陷（补齐）。
  - L06/L09 已含 Exit 关键词，重点核对是否 5 题、是否含自评。
- **修复**：每课末尾新建/补齐 Exit Ticket 页，5 题覆盖 REC（再认选择）+ RET（主动提取/补全）+ EXP（表达/翻译/造句）+ 学生自评。题面用本课知识点，不超本课语法上限。`data-question-id="L0N-EX-01..05"`、答题即判、答错双击撤销、IndexedDB 采集对齐现网。
