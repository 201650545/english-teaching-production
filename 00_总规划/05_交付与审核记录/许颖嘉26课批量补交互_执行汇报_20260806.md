### 2.3 8 字段元数据（`data-interaction-type`）

每道题 `data-interaction-type` 包含 8 个字段，用 `|` 分隔：

```
interaction-type=choice|selection=1|section=复习|knowledge=语法|cognitive=记忆|interaction=click|response=immediate|feedback=auto
```

字段生成规则：
- **interaction-type**：`choice`（所有题均为单选）
- **selection**：`1`（单选）
- **section**：根据 `sh-num` 标记动态推断（复习/词汇/语法/阅读/练习/诊断）
- **knowledge**：根据 `sh-num` 文本推断（语法/词汇/句型/阅读策略/写作/拼读/功能）
- **cognitive**：根据知识点类型推断（记忆/理解/应用/分析/评价）
- **interaction**：`click`
- **response**：`immediate`
- **feedback**：`auto`

### 2.4 `<CW-SECTION>` 标记

在 CSS 末尾插入：

```html
<!-- <CW-SECTION components="quiz-q,quiz-opt,section-head,game-board,fill,sentence-tile" theme="default" /> -->
```
