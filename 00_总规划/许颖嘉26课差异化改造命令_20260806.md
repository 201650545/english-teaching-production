## 二、A 层：22 课脚本化基础差异化（全员）

### 步骤 1：模板指纹聚类
- 提取各课 CSS 规则哈希 / DOM 结构 / 页数 / 题型数 / 公共脚本哈希 / 截图感知哈希；
- 确认 22 课是否共享同一底层模板、其余 4 课分属几个变体；
- 输出聚类报告（进回报）。

### 步骤 2：建立兼容 CSS 变量层（不重写原 CSS）
在原 CSS 末尾增加兼容映射，高频旧值分批替换为变量：
```css
:root {
  --style-bg: #f6f3ec;
  --style-surface: #ffffff;
  --style-text: #242424;
  --style-primary: #315c50;
  --style-accent: #c9793d;
  --style-heading-family: system-ui, sans-serif;
  --style-body-family: system-ui, sans-serif;
  --style-radius: 6px;
  --style-border-width: 1px;
  --style-shadow: none;
}
```
优先替换：body/页背景、正文色、主按钮、卡片背景边框、标题、选项、正误反馈、进度条。**状态色与正文色必须保持语义区分**（成功绿/错误红不靠明度差）。

### 步骤 3：按 5 个 retrofit recipe 分配（GPT 推荐，每组 5-6 课）

| 族 | 变化要点 | 适合主题 |
|---|---|---|
| **R1 编辑杂志** | 大标题+编号、分隔线、矩形/轻描边卡片、中性色+单强调、图片裁切 | 人物/城市/文化/阅读/新闻 |
| **R2 档案推理** | 文件标签、编号、虚线/印章/夹子、深绿棕灰克制色、证据确认反馈 | 语法发现/推断/匹配/问题解决 |
| **R3 自然手账** | 纸张表面、注释箭头、田野标签、自然色、观察记录式图片 | 动植物/环境/天气/旅行/户外 |
| **R4 任务游戏** | 任务编号、进度、关卡式封面、明确即时反馈、动效克制 | 复习/高频练习/闯关/综合 |
| **R5 极简学术** | 大留白、少装饰、高对比字体、稳定卡片、低动效 | 检测/长阅读/写作/结构化总结 |

**分配**：R1×6 + R2×5 + R3×5 + R4×5 + R5×5 = 26 课。有主题语义数据时按「语义匹配 + 最少使用 + 相邻三课不重复」评分分配；无可靠主题标签时 R1→R2→R3→R4→R5 循环后人工交换明显不匹配，**保持任何连续三课不重复**。

### 步骤 4：封面只改安全区域
可调：标题位置、副标题构成、主图比例、背景分区、装饰形态、标签编号方式。
**禁动**：`page-id`、导航合同、课程/学生 ID、开始按钮事件绑定、IndexedDB 初始化。

### 步骤 5：局部组件调整（附加 class/变量，不改题目 DOM）
卡片边框、选项容器、提示框、页码、进度条、正误状态、标签。

### 步骤 6：回归检查（每课截 5 屏）
封面 / 讲解页 / 选择题 / 交互页 / 总结页。检查：文本溢出、按钮遮挡、字体加载、正误反馈、翻页、交互合同、IndexedDB、验证器结果。

### 工作量参考（GPT 估，样板后校准）
- 一次性：聚类 0.5-1 天 + 变量层 0.5-1 天 + 5 recipe 0.5-1 天 + 批处理脚本 0.5 天
- 每课：自动注入 3-8 分 + 封面 10-25 分 + 截图 10-15 分 + 修复 0-30 分 ≈ 25-60 分
- 22 课总约 2.5-4 人日

## 三、B 层：近期 6-8 课人工深化

从 A 层中选**近期要上/高频**的 6-8 课，增加：
1. 封面重新构图（不止换色换肤）；
2. 一种关键组件变体（如阅读页改时间线/地图式）；
3. 反馈语言调整（如"证据确认"vs"闯关成功"）；
4. 代表性内容页局部版式变化。

**选课原则**：下一阶段频繁使用 > 教师明确投诉 > 连续多课 > 换肤后仍相似 > 内容长期复用。
