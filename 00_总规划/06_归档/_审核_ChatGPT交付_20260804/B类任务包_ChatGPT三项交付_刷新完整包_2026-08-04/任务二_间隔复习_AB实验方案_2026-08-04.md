# 任务二：间隔复习A/B对照实验方案

> 版本：2026-08-04  
> 适用范围：小样本、一对一或少人数初中英语词汇复习  
> 实验性质：项目内可逆性试点，不修改正式保守操作口径  
> 核心原则：同一学生内按词项随机分组，使用共同无提示探测题比较保持效果

## 一、实验目标

比较两套已定复习参数在以下方面的实际表现：

1. 跨日期无提示主动提取；
2. 无提示拼写、词形或搭配；
3. 新语境迁移；
4. 单个词达到稳定掌握所需的复习次数；
5. 学生和教师的复习负担。

实验不回答“哪套日程是所有学生唯一最佳”，只判断在本项目学生、词项和课时条件下，实验版是否能在不降低保持率的前提下减少复习次数，或是否对特定弱词/稳定词更合适。

课堂分散练习Meta分析支持分散优于集中，但也显示效果随保持时间和具体设计而变化。因此本试验采用共同探测点，而不是只比较两套日程各自最后一次练习后的成绩。

## 二、已锁定的两套干预

### A组：保守版

| 阶段 | 时间窗 | 主要任务 |
|---|---|---|
| 首学 | D0 | 建立词形—词义—语境联系 |
| 课内复测 | D0，间隔10—20分钟 | 无提示主动提取 |
| 第一次跨日 | D1—D2 | 主动提取 |
| 第二次 | D3—D5 | 拼写或词形 |
| 第三次 | D7—D10 | 搭配或句中填空 |
| 第四次 | D21—D28 | 新语境迁移 |

动态规则保持不变：首错D1再测；用时过长只作为辅助信号；连续两次跨日无提示正确可按7→14→28天延长；延迟失败缩短间隔并回退生成要求。

### B组：实验版

| 词项状态 | 日程 |
|---|---|
| 弱词 | D0 / D1 / D3 / D7 / D14 |
| 稳定词 | D0 / D3 / D10 / D21 / D42 |

弱词和稳定词的初始分类只用于安排，不作为永久能力标签。任何B组词若出现首次错误、高级提示、答案展示、高置信错误或共同探测失败，可立即获得与A组同等或更密集的补救复习。

## 三、推荐分组方案

### 3.1 首选：同一学生内、词项级随机分组

小班或一对一项目不适合把整名学生分到A或B，因为学生差异会大于日程差异。推荐每名学生同时学习A组词和B组词：

```text
同一学生
├── 匹配词对1：A词 / B词
├── 匹配词对2：B词 / A词
└── ……
```

优点：

- 每名学生作为自己的对照；
- 不因学生基础、出勤或教师风格不同造成明显偏差；
- 即使只有3名学生也能获得词项级试点数据；
- B组出现风险时可按单词立即补救，不必停止整名学生的实验。

### 3.2 词项匹配与随机化

在D0正式学习前，先做一次短预检。只纳入：

- 未达到M2的目标词；
- 课程确实需要学习的词；
- 可在两组使用相同题型和语境难度的词。

按以下特征形成匹配对：

1. 预检状态：完全不会／能识别但不能提取；
2. 词长和音节数；
3. 词性；
4. 具体词或抽象词；
5. 规则或不规则拼写；
6. 本课出现频率和教学重要度。

每个匹配对用随机数决定哪个词进入A、哪个进入B。下一课的匹配对反向平衡，避免某一组长期获得更容易的词。

### 3.3 现实样本量

本项目不宜宣称完成正式统计学临床式试验。建议按以下层级解释：

| 有效规模 | 定位 |
|---|---|
| 每名学生每组少于15词 | 可行性测试，只检查流程和数据质量 |
| 每名学生每组20—30词 | 项目级初步比较 |
| 3名学生累计每组60词以上 | 可做分学生、分词项的描述性和自助法区间分析 |
| 更大规模、多班级 | 才适合正式推断和预注册统计检验 |

建议首轮8—12周，每名学生纳入40—60个目标词，A/B各20—30词。结果必须同时按学生和词项展示，不能把大量词项当作大量独立学生。

## 四、共同探测设计

复习日程本身不同，若只比较“最后一次练习后成绩”，会造成不公平。两组必须参加不提供教学反馈的共同探测；探测完成后再给正常反馈，不让学生处于劣势。

| 共同探测 | 时间窗 | 题型 | 用途 |
|---|---|---|---|
| P1 | D7±1 | 无提示主动提取 | 早期保持 |
| P2 | D14±2 | 无提示拼写或词形 | 中期保持 |
| P3 | D28±3 | 新语境无提示使用 | 主要结局 |
| P4 | D42±4 | 新语境或混合延迟复测 | 长期观察 |

共同探测规则：

- 不显示选项、首字母、词长或答案；
- 首次答案提交后才能反馈；
- 探测题语境对A/B两组等难；
- 原题不得直接重复；
- 探测失败立即进入补救，不为了“实验纯度”延迟帮助。

## 五、干预差异表

| 项目 | A保守版 | B实验版 | 保持一致的部分 |
|---|---|---|---|
| D0课内复测 | 10—20分钟后 | 10—20分钟后 | 无提示首次提取 |
| 首次跨日 | D1—D2 | 弱词D1；稳定词D3 | 失败立即反馈 |
| 中期复习 | D3—D5、D7—D10 | 弱词D3/D7；稳定词D10 | 题型按M级递进 |
| 后期复习 | D21—D28 | 弱词D14；稳定词D21/D42 | 共同P3/P4探测 |
| 失败处理 | 缩短间隔 | 立即切换为安全补救，可采用A组密度 | 不允许学生因分组少获帮助 |
| M4判定 | 现有阈值 | 同一阈值 | ≥7天、≥2日期、无提示、主动提取/拼写、新语境 |

## 六、数据采集字段

以下16项为任务包规定的必填事件字段，不得缺失：

| 字段 | 类型 | 说明 |
|---|---|---|
| `event_id` | string | 全局唯一事件ID |
| `question_id` | string | 具体题目或探测题ID |
| `knowledge_id` | string | 词项唯一ID |
| `first_answer` | string | 首次原始答案，不覆盖 |
| `final_answer` | string | 反馈和重试后的最终答案 |
| `is_first_correct` | boolean | 首次答案是否正确 |
| `is_final_correct` | boolean | 最终答案是否正确 |
| `independent_correct` | boolean | 无提示、未展示答案时是否正确 |
| `attempt_no` | integer | 本事件内提交次数 |
| `hint_used` | boolean | 是否使用任何提示 |
| `max_hint_level` | integer | 0—3；答案展示另记 |
| `answer_revealed` | boolean | 是否展示过完整答案 |
| `response_time_ms` | integer | 首次有效提交前的用时 |
| `transfer_correct` | boolean/null | 新语境任务结果；非迁移题为null |
| `sync_status` | enum | `pending/synced/failed` |

### 建议增加但不替代必填字段

| 字段 | 用途 |
|---|---|
| `student_id` | 连接学生记录 |
| `schedule_arm` | A或B |
| `word_state_at_assignment` | weak/stable及依据 |
| `study_day` | D0/D1等计划日 |
| `actual_interval_hours` | 实际间隔，避免只按计划推断 |
| `probe_id` | P1/P2/P3/P4 |
| `confidence` | 仅重点探测采集1—4级 |
| `context_id` | 判定是否新语境 |
| `rescue_applied` | 是否触发安全补救 |

全部数据沿用现有IndexedDB→CSV/JSON→飞书链路，不新增第二套数据库。

## 七、主要指标与成功判据

### 7.1 主要指标

**P3（D28±3）新语境无提示独立正确率**：

```text
P3中 independent_correct=true 且 transfer_correct=true 的词项数
÷
P3有效词项数
```

选择P3作为主要指标，因为它同时检查跨日期、无提示和新语境，最接近M4目标。

### 7.2 次要指标

1. P1主动提取独立正确率；
2. P2无提示拼写/词形正确率；
3. P4长期保持率；
4. 达到项目M4阈值的词项比例；
5. 每个稳定词所需复习事件数；
6. 每个稳定词的总有效练习时间；
7. 提示依赖率；
8. 答案展示率；
9. 延迟失败后重新稳定所需次数；
10. 高置信错误在下一次跨日探测中的修正率。

### 7.3 不作为主要成功指标

- 最终正确率；
- 点击数；
- 页面停留；
- 游戏分数；
- 连胜；
- 单纯作答速度。

这些指标容易被提示、重试、离座或界面操作影响。

### 7.4 项目决策规则

由于样本小，首轮不以单次p值决定胜负。建议使用以下可解释规则：

#### B版可扩大试点

同时满足：

1. B组P3独立迁移正确率不低于A组5个百分点以上；
2. B组平均复习事件数比A组少至少15%，或教师复习时间明显下降；
3. B组答案展示率和高置信错误回归率未恶化；
4. 至少2名学生方向一致，没有学生明显受损。

这里的5%和15%是项目决策阈值，不是科学通用标准。

#### 两套并存并按词项分流

若弱词在A更好、稳定词在B更省时，则保留：

```text
弱词走保守密集路径
稳定词走实验扩展路径
```

#### 暂不采用B版

若B组在两个连续共同探测中独立正确率低于A组10个百分点以上，且不能由词项难度或缺勤解释，则暂停新词进入B组，现有B词立即转安全补救。

## 八、分析方法

### 8.1 每名学生内分析

对每名学生分别报告：

- A/B组P1—P4正确率；
- 每个词的轨迹；
- 弱词和稳定词分层结果；
- 复习次数与保持率的权衡。

### 8.2 汇总分析

推荐：

- 按学生计算A-B差值后再汇总；
- 对词项进行配对比较；
- 使用bootstrap置信区间或贝叶斯分层模型作为探索分析；
- 不把同一学生的几十个词当作几十名独立学生。

如果本地执行方不具备统计建模能力，使用中位数、比例差、配对词表和趋势图即可，结论标记为“项目试点观察”。

## 九、混淆变量控制

### 9.1 提示依赖

统一四档：

```text
0 无提示
1 语义/语境提示
2 首字母或长度
3 部分词形/词块
答案展示 answer_revealed=true
```

提示后答对不得记为`independent_correct=true`。

### 9.2 跨日期

- 以设备记录的实际时间戳和日期判断；
- 同一自然日内多次作答只算同日证据；
- 教师补录必须标记来源；
- D0连续答对不能替代跨日证据。

### 9.3 新语境

新语境至少满足：

- 句子或任务不是原题复制；
- 目标词周围搭配、主语、时态或情境至少改变一项；
- 不能只换题号或选项顺序；
- `context_id`与教学原句不同。

### 9.4 题型和内容难度

A/B共同探测使用相同题型比例、相近句长和相同评分规则。不得让A组做选择、B组做拼写后直接比较。

### 9.5 教师影响

- 两组使用相同反馈措辞和提示梯；
- 教师不能因知道分组而给某组更多口头线索；
- 发生额外讲解时记录`teacher_intervention=true`；
- 复习顺序在A/B之间交替，避免疲劳总落在同一组。

### 9.6 词项污染

如果A词和B词为近义、反义或同一词族，尽量不要放在同一匹配对；若课程必须同时出现，标记`related_item_cluster`并在分析中单独检查。

## 十、高置信错误处理

只在重点探测题采集1—4级确定度。定义：

```text
is_first_correct=false
且 confidence≥3
```

处理：

```text
立即解释冲突
→ 遮盖后重答
→ 同构变式
→ 下一跨日探测
```

高置信错误不得因学生在当场改对而退出复习池。

## 十一、红线自查

- [x] 不公开A/B成绩或排名；
- [x] 不使用羞辱、巨大红叉或失败清零；
- [x] 提示按等级提供，不在首次作答前泄露答案；
- [x] B组失败立即获得A组密度或更强补救；
- [x] 积分和游戏分数不进入长期能力标签；
- [x] 不新增第二套数据系统；
- [x] 同课内连续答对不直接判M4；
- [x] 最终正确率不作为主要结论；
- [x] 学生姓名不出现在公开报告中；
- [x] 教师可随时人工覆盖分组和复习日期。

## 十二、终止条件

### 12.1 安全暂停

出现任一情况，立即暂停该学生的新词进入B组：

1. B组在连续两个共同探测中比A组低至少10个百分点；
2. B组连续出现3个以上延迟失败词，且A组同难度匹配词稳定；
3. 学生明确表示复习间隔导致持续遗忘或挫败；
4. 数据丢失、分组错误或提示泄露使比较失真；
5. 教师判断某重点词不能承担实验风险。

暂停后，B组现有弱词全部切换到保守版或更密集补救，不删除历史数据。

### 12.2 全实验终止

- 有效词项未达到每组15个且无法继续；
- 超过20%的事件缺少关键字段；
- A/B实际间隔重叠严重，无法区分干预；
- 学生出勤或课程调整使P3共同探测无法完成；
- 教师工作量超过可接受范围且无法通过自动化降低。

## 十三、数据导出与安全

1. 每课结束将IndexedDB记录导出为JSON或CSV；
2. `event_id`去重，保留原始首次答案；
3. `sync_status`统一为`pending/synced/failed`；
4. 上传飞书前只使用学生内部ID，不在分析文件中出现姓名；
5. 原始事件表只追加，不覆盖；教师修正使用单独覆盖字段；
6. 周报只展示学习指标，不展示hover、滚动、动画次数等技术噪音；
7. 每周检查缺失字段和异常时间戳；
8. 实验结束后保留匿名汇总和必要原始证据，不扩散无关个人数据。

## 十四、建议实施节奏

| 周次 | 工作 |
|---|---|
| 第0周 | 校验字段、建立词项匹配规则、试跑5—10词，不做效果结论 |
| 第1—2周 | 正式纳入第一批词；完成D0、P1和早期补救 |
| 第3—4周 | 完成P2；检查分组平衡、字段缺失和学生负担 |
| 第5—8周 | 完成P3主要结局；按预设规则决定继续、分流或暂停 |
| 第9—12周 | 完成P4长期观察；形成分学生与分词项报告 |
| 结束后 | 将验证后的规则写回项目参数；未验证数值继续标“项目初始参数” |

## 十五、最小周报

```text

```

## 十六、改动点摘要

本方案不更改两套既定日程，而是增加同生词项级随机分组、匹配和反向平衡；设置D7、D14、D28、D42共同无提示探测；以D28新语境独立正确率为主要指标，并把复习次数、提示依赖和高置信错误回归作为负担与安全指标。实验版任何失败词均可立即切换保守补救，数据继续沿用单一IndexedDB—CSV/JSON—飞书链路。
