## 二、逐项变更详情

### 变更1：新建 `08_学习数据闭环规范.md`（V1.0）

**来源**：《互动英语课件与飞书多维表格学习数据闭环实施方案.txt》全文

**内容**：13 章完整规范，按规范文件体例重组（非原文搬运）：

1. 规范目标与定位：纸笔学习 + HTML 互动测试 + 浏览器本地保存 + 飞书汇总
2. 双层保存架构：IndexedDB 本地保存 + 飞书云同步
3. 飞书多维表格结构（7 张表）：学生表 / 课程课次表 / 词汇主表 / 题目主表 / 答题明细表 / 词汇掌握表 / 课次总结表
4. 同步方案（三阶段）：CSV 人工导入（当前）→ 本地同步工具（正式）→ 云函数实时同步（后期）
5. 每课数据闭环：课前选词 → 课中记录 → 课末总结 → 课后同步
6. 飞书视图建议（5 类）
7. 飞书自动化建议（4 类）
8. Agent 数据读取规范
9. 导出规范（JSON + CSV）
10. 未成年人数据保护
11. 第一阶段不建议实施的功能
12. 实施顺序（10 步）
13. 参考资料

**关键字段**：
- `event_id` 去重规则 = `student_id + session_id + question_id + attempt_no`
- `word_id` 命名规则如 `u1_ancient`
- M0-M4 掌握等级：M0 未掌握 → M1 识别 → M2 提取 → M3 拼写 → M4 语境使用
