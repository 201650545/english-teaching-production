## 一、修复要求（L15 课件）

### 1. 补齐全部未定义交互函数（核心）
9 个函数（`startT2` / `weatherScene` / `requestScene` / `itScene` / `checkQuiz` / `toggleMask` / `toggleCheck` / `matchGame` / `selectFiveFour`）逐一实现，**实现必须与页面结构匹配**：
- **startT2（词汇竞技场）**：点击开始后展示第一题（看英文选中文），5 条命（❤️×5），答对得分、答错扣命，命尽结束；更新 `#t2Score`、`#t2Lives`；
- **weatherScene（天气互动台）**：点击天气图标 → 对应场景（晴天/下雨/刮风等）背景/文案/例句切换；
- **requestScene（礼貌请求互动）**：点击请求场景 → 对应 Could/Would 例句与反馈；
- **itScene（It 指代）**：点击选项 → 对应 It 指代物展示；
- **checkQuiz（通用判题）**：答对绿 `correct` + 文字提示"正确"，答错红 `wrong` + 显示正确答案，锁定选项；与 `checkOpt` 行为一致；
- **toggleMask / toggleCheck / matchGame / selectFiveFour**：按页面对应组件语义实现（翻牌/勾选/配对/五选四）。
- 判题逻辑对齐新引擎（`btn.closest('.quiz-container')||btn.closest('.quiz-q')` 容器定位 + IndexedDB 采集 + 双击撤销）。

### 2. 修复页面高度塌陷（第11页等）
- 排查 `.page-content` / 题目容器高度为 0 的根因（可能 `.pages-container` 的 `aspect-ratio:21/9` + 绝对定位冲突），确保内容页正常显示高度、题目可见；
- 修复后第11页题目必须可见可答。

### 3. 去掉翻页过渡动画（教师明确要求"点击立即闪现，无过渡动画"）
- 删除/禁用 `.page.active` 的 `pageFadeIn` 0.4s 动画，翻页**立即显示**目标页内容，无闪烁、无过渡；
- 全课件检查是否有其他页面切换过渡/闪烁源（`@keyframes` 与翻页相关者、`.active` 动画），一并去除；
- 视觉反馈动画（答题正确彩带、气泡）**保留**，只去页面切换动画。

### 4. 补思维导图页
- L15 蓝图含思维导图环节（weather/request/It 三考点归纳），在课堂总结后**补 1 页思维导图**（对齐 00 规范思维导图形式：中心主题 + 分支考点 + 关键例句），确保页数仍在 40-45。

### 5. L1 流程标签图
