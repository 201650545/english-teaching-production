# 已知局限（批次2 V1.0）

1. **静态 CSS 检查不等同 computed style**
   - 无法解析 CSS 变量在运行时计算的最终值
   - 无法判断继承、级联和层叠顺序的实际效果
   - 无法测量实际渲染像素尺寸

2. **正则不能完整理解所有 CSS**
   - 嵌套选择器（`&`）可能被截断
   - `@supports`、`@container` 等条件规则中的选择器可能误报
   - 多行注释和字符串中的花括号可能干扰平衡检查

3. **对比度、重叠、真实换行仍需浏览器和人工检查**
   - 本模块不检查颜色对比度
   - 不检查元素重叠或 z-index 冲突
   - 不检查实际换行和溢出

4. **无可信视觉基线时不能可靠判断 30% 骤降**
   - CSS-I003 的基线依赖需要至少 1 个合格样本
   - 跨主题或跨学生时基线不适用

5. **触屏目标无显式尺寸时需要运行时测量**
   - 无 `width/height/min-width/min-height` 的元素无法静态判断
   - 伪元素（`::before`/`::after`）的尺寸可能误报

6. **页面"是否高级"不能由脚本证明**
   - 视觉质量、可读性和审美判断需要人工评估
   - 本模块只检查可量化的硬性指标

7. **CORE_CSS 中的导航/状态栏小字会触发 VIS-W101**
   - 导航 `.nav-item` (14px)、状态栏 `.sync-status` (12px) 等属于 UI 辅助元素
   - 已设为 HIGH-WARN 而非 ERROR，提醒但不阻塞交付

8. **CSS-W002 孤儿选择器占比偏高**
   - 因为 CSS_EXTRA 中大量类定义在不同组件间共享
   - 部分选择器只在 JS 动态条件中使用，静态扫描无法捕获

9. **CSS-W003 重复选择器包含 CORE_CSS 与 CSS_EXTRA 之间的同名覆盖**
   - 如 `:root` 在 CORE_CSS 和 CSS_EXTRA 中各定义一次，属正常覆盖
   - 本模块仅报告不自动删除

10. **CSS-W007 颜色字面量阈值在大项目中可能偏低**
    - 基线 18 个 hex 值在大型 CSS 中很容易超过
    - 当前为项目初始参数，8-12 周后可校准
