## 2. 任务二：间隔复习 A/B 对照实验方案设计（B1/B3 收尾）

### 2.1 已定参数（不得改动，只能围绕它们设计）

**保守版（正式操作口径）**：D0 课内复测（间隔 10—20 分钟）→ D1—D2 首次跨日主动提取 → D3—D5 拼写词形 → D7—D10 搭配句填 → D21—D28 新语境。动态规则：首错 D1 再测；用时过长保持短间隔（用时仅辅助信号，不单独判未掌握）；连续两次跨日无提示正确则延长间隔 7→14→28 天；延迟复测失败缩短间隔并回退生成要求。

**实验版（仅收集真实数据，不进硬规范）**：弱词 D0/D1/D3/D7/D14；稳定词 D0/D3/D10/D21/D42。

**掌握判定（M0—M4）**：M1 能识别（四选一猜对一次不足）；M2 无提示主动提取正确（首字母提示后答对不足）；M3 无提示拼写/词形/搭配正确（抄写正确不足）；M4 **跨日期＋无提示＋新语境**正确（同一原句重复答对不足）。M4 项目阈值 = ≥7 天 / ≥2 不同日期 / 无提示 / ≥1 主动提取或拼写 / ≥1 新语境——这是**操作阈值不是科学定论**，不得把 D1/D3/D7 写成唯一科学答案。

### 2.2 需要你交付的实验设计（6 部分）

1. **分组方案**：班级规模小、已有既定教学安排。给出如何把学生（或同生不同词）分 A/B 的可行办法，含样本量现实约束说明。
2. **数据采集字段**：必须覆盖以下事件字段，缺一不可——`event_id / question_id / knowledge_id / first_answer / final_answer / is_first_correct / is_final_correct / independent_correct / attempt_no / hint_used / max_hint_level / answer_revealed / response_time_ms / transfer_correct / sync_status`。
3. **成功判据**：用什么指标比较两套参数。注意：首次独立正确率优先于最终正确率；提示后答对≠无提示正确；高置信错误（首次错误＋确定度高）必须安排跨日复测。
4. **混淆变量控制**：提示依赖分级（无提示/一级/二级/三级或答案展示）、跨日期判定、新语境判定、同课内连续答对不得直判 M4。
5. **红线约束**：不公开排名；不羞辱；提示不得泄露答案；实验版不得让学生处于劣势（弱词也可获得保守版间隔）；积分不进长期能力标签；不新增第二套数据系统（沿用 IndexedDB 本地→CSV/JSON→飞书）。
6. **终止与数据安全**：何时停实验（如某套参数在 N 次复测中显著更差即停）；数据导出方式；防止把技术行为数据包装成学习指标。

### 2.3 输出格式

一份可直接落地的《间隔复习 A/B 实验方案》文档结构：目标 → 分组 → 干预差异表（两套间隔逐档对照）→ 数据字段 → 指标与判据 → 混淆控制 → 红线自查 → 终止条件。可给建议的实施节奏表（第几周做什么）。
