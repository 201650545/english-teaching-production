## 二、冲突处理结论

1. **语法（Q1.1）**：保留每课 3 考点，组织为「1 核心语法主题 + 2 相关考点」。**改 C3 的表述，不改引擎/九环节/verify**。例 L02：核心=一般过去时，相关=was/were 与 did 区别 / did 后动词恢复原形 / 过去时间状语与句型转换。
2. **词汇（Q1.2）**：复习池**按学生参数**，不全局统一。李民宪 10+20 启用 5/5/5/5 复习池；许颖嘉 / 邓兴华维持 20 新+0 巩固（错词先入课前检测/作业/阶段复习，不改变课程契约）。
