- 品牌主色：#E63946　强调色：#FFD700　背景渐变：#FFF8F0 → #FFE8D6

## 三、互动与数据采集

- 交互函数：checkOpt / fillCheck / pickWord / dragSubmit / moveUp / moveDown / orderCheck / matchPick / flipCard

- 会话规则：L21_{studentId}_{YYYYMMDD}

## 四、注意事项

1. 防越级：严格按内容蓝图第二节语法约束，不越级引入新语法点
2. 生词比例：阅读篇目保持 15%–20%
3. 词数控制：严格落在各课闭区间
4. 互动反馈：每个交互都有音效和视觉反馈
5. 主题色：#E63946 + #FFD700，亮色主题
6. 全中文命名，不出现真实学生姓名
