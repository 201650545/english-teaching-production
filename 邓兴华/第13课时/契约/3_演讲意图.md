## 二、各环节讲解意图

### 1. 复习导入（8分钟）
- **意图**：通过L12口诀快闪，快速唤醒点餐/冠词记忆
- **关键点**：建立"L12点餐→L13购物价格"的衔接感
- **过渡语**："How much is the pancake? I'd like to buy some snacks."

### 2. 新词20（16分钟）
- **意图**：分组呈现20词，用记忆法降低负担，预埋价格概念
- **关键点**：
  - 食物/调料/支付/市场分类记忆
  - 价格词汇强调搭配（pay for/buy/cost/spend）
  - spend/cost/sell/buy 动词辨析

### 3. 语法3考点（28分钟）
- **意图**：本课是购物表达系统课，三个考点必须讲透
- **节奏**：
  - G34 would like：12分钟（含互动组件1）
  - G35 how much/many：8分钟
  - G36 价格表达：8分钟（含互动组件2）
- **关键点**：
  - G34：would like + sth./to do/sb. to do，等于 want 的礼貌版本
  - G35：how much 问不可数/价格，how many 问可数复数
  - G36：cost 物作主语，spend 人作主语（spend...on）

### 4. 随堂演练（10分钟）
- **意图**：即时检测G34/G35/G36掌握情况
- **关键点**：错题当场讲解，注意 cost/spend 主宾语

### 5. 阅读理解（14分钟）
- **意图**：运用五步阅读法，培养阅读策略
- **关键点**：引导学生在语篇中识别 would like 和价格表达

### 6. 句子练习（7分钟）
- **意图**：输出练习，巩固购物句型

### 7. 自然拼读（4分钟）
- **意图**：ea/ee /iː/ 音素学习

### 8. 课堂总结（3分钟）
- **意图**：口诀串联，购物表达系统思维导图收尾

## 三、互动组件使用指南

### 组件1：点餐选择器
1. 选择食物"pancake"
2. 生成"I'd like a pancake."
3. 切换"to buy"，生成"I'd like to buy some snacks."
4. 切换疑问"Would you like some dessert?"
5. 总结：would like 三种结构

### 组件2：购物结算台
1. 选择商品"dumplings"，数量"two"
2. 计算总价"two yuan each, total four yuan"
3. 生成"How much are the dumplings?"
4. 让学生自行组合购物句子

## 四、注意事项

1. **防越级**：不引入 feel like doing / would rather do
2. **生词比例**：阅读篇目保持15%-20%生词比例
3. **词数控制**：严格在Stage 4闭区间内（129/150词）
4. **互动反馈**：每个交互都有音效和视觉反馈
5. **主题色**：Stage 4红金主题
