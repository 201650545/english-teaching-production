# 第04课 课程概要

> **课名**：名词单复数、tidy 形容词与房间介词
> **Stage**：Stage 2（L4–L7）
> **建议时长**：90 分钟
> **课型**：授课课（阶段切换首课，强制 3 页复习导入）

---

## 语法考点

| 编号 | 考点 | 核心口诀 |
|------|------|----------|
| G10 | 可数名词规则复数变化 | 直加 s 最常见，遇 s/x/sh/ch 加 es，辅音+y 去 y 加 ies |
| G11 | 形容词作定语与作表语 | 定语在前修饰名（a tidy room），表语在后跟 be 动（The room is tidy） |
| G12 | 方位介词短语 | in 里面 on 上面，under 下面 behind 后；next to 紧挨着，between...and 夹中间 |

## 词汇概要

- **新词数量**：20 词

- **去重校验**：与 L1–L3 共 60 词交集校验 = 0 ✅
- **词性分布**：名词7 + 介词4 + 形容词2 + 副词2 + 连词1 + 动词2 + 其他2

## 课件页数

- **总页数**：27 页（P0 封面 + P1–P26 内容）
- **八段式结构**：复习导入3 + 新词20(6页) + 语法3考点(6页) + 随堂演练2 + 阅读理解3 + 句子练习3 + 自然拼读4 + 课堂总结1

## 防越级约束

- G10：仅限规则变化（直加s / 加es / 去y加ies），不引入不规则复数（man→men/child→children 留至 L11）
- G11：仅限原级，严禁比较级（-er/more）和最高级（-est/most）
- G12：仅限 in/on/under/behind/next to/between...and/in front of，不引入 above/below
