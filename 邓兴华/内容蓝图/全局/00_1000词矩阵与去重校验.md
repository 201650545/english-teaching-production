## 三、跨课去重 Set 交集校验

### 3.1 校验方法

```python
learned_words = set()
for lesson in [L1, L2, ..., L50]:
    current_words = set(本课20词)
    overlap = current_words.intersection(learned_words)
    if overlap:
        ERROR(f"L{lesson} 与前课词汇重复: {overlap}")
    learned_words.update(current_words)
```

## 六、子代理使用规则

1. **生成第 N 课时**，必须先加载 `learned_words = set(L1 ~ L(N-1) 的全部词汇)`，执行交集校验。
2. 若本课 20 词与历史词库出现交集，**立即阻断并报错**，不得继续生成。
3. 本文件为**全局锁定表**，子代理**只读引用**，严禁修改。
4. L35–L50 为刷题阶段，词汇在刷题语境中巩固复现，不引入本表之外的生词。
5. 若后续合并课时（如 L37+L38 合并），合并后该课词汇量为 40 词（20+20），总词汇量 1000 词不变。
6. 每道含短文题目允许且要求出现 15%–20% 超纲词/未学词（生词比例规则），但这些超纲词不计入本表 1000 词。
