## 二、语法详解（3 考点）

### 语法①：because/since/as 原因状语 & although/though 让步状语（G60）——首次

**口诀**：
> "因为因为 because，既然必然 since；虽然虽然 although/though，原因让步要分清"

**公式矩阵**：

| 结构 | 含义 | 示例 |
|---|---|---|
| because + 从句 | 因为（原因） | I stayed home because it rained. |
| since / as + 从句 | 既然/因为（已知原因） | Since you're here, let's start. |
| although / though + 从句 | 虽然（让步） | Although it was cold, we went out. |
| 主句 + although/though | 虽然（让步在后） | We went out though it was cold. |

**中考辨析**：
- because 与 so 不能连用（because 表原因，so 表结果，二选一）
- although/though 与 but 不能连用
- since/as 表已知原因，语气比 because 弱

**易错点**：
- ❌ Because it rained, so I stayed home. → ✅ Because it rained, I stayed home.
- ❌ Although it was cold, but we went out. → ✅ Although it was cold, we went out.

**防越级约束**：**不引入定语从句**（留至 L33）。

### 语法②：so / so that / in order that 结果与目的状语（G61）——首次

**口诀**：
> "so 表因此结果出，so that 表目的和结果；in order that 表目的，so 后接句子要记牢"

**公式矩阵**：

| 结构 | 含义 | 示例 |
|---|---|---|
| 主句 + so + 结果从句 | 因此（结果） | I was tired, so I slept. |
| 主句 + so that + 从句 | 以便（目的/结果） | He studied hard so that he could pass. |
| 主句 + in order that + 从句 | 为了（目的） | She got up early in order that she could catch the bus. |

**中考辨析**：
- so 表结果，后接完整句子
- so that 既可表目的（以便），也可表结果
- in order that 主要表目的，较正式

**易错点**：
- ❌ so that + 不定式误用（so that 接从句，to do 表目的用 so as to/in order to）
- 目的状语从句常用 can/could

**防越级约束**：**不引入定语从句**。

### 语法③：G60 复现扩展（although/though/even though 让步状语）

**口诀**：
> "让步状语 although，虽然随时跟其后；even though 更强调，主句转折不迟疑"

**公式矩阵**：

| 结构 | 含义 | 示例 |
|---|---|---|
| although + 从句 | 虽然 | Although he is tired, he keeps working. |
| though + 从句 | 虽然 | Though it's hard, I'll try. |
| even though + 从句 | 即使 | Even though he is young, he knows a lot. |
