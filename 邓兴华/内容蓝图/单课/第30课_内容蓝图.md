## 二、语法详解（3 考点）

### 语法①：情态动词被动（can/must/should be + done）（G65）——进阶

**口诀**：
> "情态被动也不难，情态动词 be done 连；can must should 加 be，过去分词在最后"

**公式矩阵**：

| 结构 | 公式 | 示例 |
|---|---|---|
| 现在情态被动 | 情态动词 + be + 过去分词 | The work can be done today. |
| must 被动 | must + be + 过去分词 | Homework must be finished. |
| should 被动 | should + be + 过去分词 | Books should be returned. |

**易错点**：
- ❌ The work can done → ✅ The work can be done（须有 be）
- 情态动词后接 be + 过去分词，情态动词不变

**防越级约束**：**不引入完成时被动**（have been done）、**不引入将来时被动**（will be done 复习可）、**不引入被动+不定式复合结构**。

### 语法②：主动表被动（sell well / read well / wash easily）（G65）——进阶

**口诀**：
> "主动表被动，sell well 记心中；物作主语动在后，read well 好读又顺畅"

**公式矩阵**：

| 结构 | 公式 | 示例 |
|---|---|---|
| sell well | 物 + sell + well | This book sells well. |
| read well | 物 + read + well | The story reads well. |
| wash easily | 物 + wash + easily | This cloth washes easily. |

**易错点**：
- ❌ This book is sold well（误用被动）→ ✅ This book sells well（主动表被动）
- 这类动词用主动形式表被动含义，主语多为物

**防越级**：不引入完成时被动、不引入将来时被动。

### 语法③：被动句否定与疑问 + 阅读识别被动（G65）——进阶

**口诀**：
> "被动否定添 not，疑问 be 提到句首；阅读识别看 be 加过去分词，规则牢记不用愁"

**公式矩阵**：

| 结构 | 公式 | 示例 |
|---|---|---|
| 否定 | 主语 + be not + 过去分词 | The room is not cleaned. |
| 一般疑问 | Be + 主语 + 过去分词 | Is the room cleaned? |
| 阅读识别 | 找 be + 过去分词 | They are made of wood. |

**易错点**：
- 疑问句把 be 提到句首
- 阅读中识别被动：be + 过去分词结构

**螺旋递进链**：
```
G65 (L29) 被动首次 → G65 (L30) 情态被动/主动表被动（本课进阶）
```
