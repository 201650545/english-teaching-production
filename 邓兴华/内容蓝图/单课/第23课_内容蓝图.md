## 二、语法详解（3 考点）

### 语法①：if 真实条件句（主将从现）（G58）——首次

**口诀**：
> "if 条件句真简单，主将从现记心间；if 后从句用现在，主句将来或祈使"

**公式矩阵**：

| 结构 | 公式 | 示例 |
|---|---|---|
| 主将从现 | if + 一般现在时, 主句 will + V | If it rains, we'll stay home. |
| if 从句 + 祈使句 | if + 现在时, 祈使句 | If you are tired, have a rest. |
| if 从句 + 情态动词 | if + 现在时, 主句 can/may + V | If you study hard, you can pass. |

**中考辨析**：
- if 后从句**不能用将来时**，用一般现在时表将来
- 主句常用 will/shall/can/may 或祈使句
- if 从句可放句首或句尾

**易错点**：
- ❌ If it will rain → ✅ If it rains（if 从句用一般现在时）
- ❌ If you will study → ✅ If you study（主将从现原则）

**防越级约束**：仅限真实条件句，**不引入虚拟语气**（If I were...）。

### 语法②：unless 否定条件句（G59）——首次

**口诀**：
> "unless 意思是除非，等于 if...not；unless 后用原时态，主将从现照样来"

**公式矩阵**：

| 结构 | 含义 | 示例 |
|---|---|---|
| unless + 现在时, 主句将/祈 | 除非…否则… | You'll fail unless you work hard. |
| unless = if...not | 除非 = 如果不 | Unless you hurry, you'll be late. |

**中考辨析**：
- unless = if...not
- unless 从句用一般现在时表将来
- 主句多用 will/祈使

**易错点**：
- ❌ unless you will work → ✅ unless you work（unless 从句用现在时）
- ❌ if not you work → ✅ unless you work 或 if you don't work

### 语法③：祈使句 + and/or + 将来句型（G13 复现扩展）

**口诀**：
> "祈使句再接 and/or，结果自然显出来；and 表示'就会'，or 表示'否则'"

**公式矩阵**：

| 结构 | 含义 | 示例 |
|---|---|---|
| 祈使句 + and + 主句 | 做…就会… | Work hard, and you'll succeed. |
| 祈使句 + or + 主句 | 做…否则… | Hurry up, or you'll be late. |

**中考辨析**：
- 「祈使句 + and/or + 简单句」是中考高频句型
- and 表顺承结果，or 表反之后果

**易错点**：
- ❌ Work hard, and you will succeed. → ✅ 正确（and 表结果）
- ❌ Work hard, or you will succeed. → ✅ 语义反了，该用 and

**防越级约束**：仅限真实条件句 + 祈使句，**不引入虚拟语气**。
