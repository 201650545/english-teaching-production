- 品牌主色：#E63946　强调色：#FFD700　背景渐变：#FFF8F0 → #FFE8D6

- 交互函数：checkOpt / fillCheck / pickWord / dragSubmit / moveUp / moveDown / orderCheck / flipCard

- 会话规则：L16_{studentId}_{YYYYMMDD}

1. 防越级：严格按内容蓝图语法约束，本课为测试课，G01–G42 均为 L1–L15 已学考点滚动回顾

3. 词数控制：严格落在各课闭区间
4. 互动反馈：每个交互都有音效和视觉反馈
5. 主题色：#E63946 + #FFD700，亮色主题
6. 全中文命名，不出现真实学生姓名
