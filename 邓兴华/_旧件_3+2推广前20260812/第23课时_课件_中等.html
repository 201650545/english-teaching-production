if条件句

G58 规则

语
if 真实条件句 · 主将从现
G58 规则
结构
if + 一般现在时，主句 will + 动词原形。从句用现在时表将来，主句用将来时。
例句
If it rains, we will stay at home.（如果下雨，我们就待在家。）主句 We will stay。
易错
❌ If it will rain → ✅ If it rains（从句不用将来时）。
if 从句用哪种时态？
主句用哪种时态？
If it ____ (rain), we will stay home.
主将从现详解
主句表主事件的将来结果，从句表条件。条件用一般现在时表达'将来'，这是英语的固定规则，不是时态错误。
If she ____ (get) up early, she will catch the bus.
主句 will 后接？

unless规则

G59 规则

语
unless 否定条件句
G59 规则
unless = if not
除非：unless 引导的从句放否定条件，主句用将来时。
例句
You won't pass unless you study.（除非你学习，否则不会通过。）
易错
unless 已含否定，从句不再加 not（❌ unless you don't study → ✅ unless you study）。
unless 等于？
unless 从句还能加 not 吗？
You won't win ____ you try.
unless 双重否定
unless 本身含否定，句意等于'如果不…就…'。理解时拆成 if not 更清晰：Unless you study = If you don't study。
Unless she comes = ____.
主句：You ____ not succeed unless you try.
