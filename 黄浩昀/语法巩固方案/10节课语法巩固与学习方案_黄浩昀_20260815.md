## 四、词汇难度策略

- **难度定位**：拔高训练，取八年级哈佛外刊词汇量级（学生已证明可读懂）
- **上限**：不超过湖南省 2026 年中考英语难度
- **实现方式**：
  - 语法选择题干为**长难句**（含定语从句/状语从句/复合结构），词汇来自中考高频词 1000 第 4-6 课区间
  - **选词填空直接借用哈佛外刊八年级的选词填空原文**（如 2090 学校篇、崀山篇等），挖空改编确保 **70% 空位考查本课语法点**（词形变化/时态/从句引导词等）
  - 造句题只考**本课核心语法结构的直译**（不考俗语、不考意译），参考词汇允许外刊高频词
  - 每课生词率控制在 15%-20%，题干句子长度 ≤ 25 词（长难句但可控）

## 五、10 节课详案（V2.0）

---

### L1 · 数词与名词体系（复习 50% + 宾语从句引导词 50%）

**复习板块（50%，八年级系统梳理）**
1. 基数词：hundred/thousand/million 精确数与模糊数（two hundred students vs hundreds of）
2. 分数表达：one third, two fifths（分子基数词、分母序数词，分子>1 分母加 s）
3. 大数字读写法：3,456 → three thousand four hundred and fifty-six
4. 可数/不可数名词 + some/any 规则：肯定句用 some；疑问句表建议/请求用 some，一般疑问用 any

**新知板块（50%，九年级：宾语从句·引导词体系）**
1. 定义：作宾语的句子（动词/介词/形容词后）
2. that（陈述句变来，可省略）；if/whether（一般疑问变来，表"是否"）；疑问词 what/which/who/whose/when/where/why/how（特殊疑问变来）
3. 判断引导词四步法：先看从句类型（陈述/一般疑问/特殊疑问）→ 再选对应引导词

**练习（10 + 外刊选词 + 造句3）**
- 语法选择 10：① 数词精确/模糊辨析 ② 分数表达 ③ 宾语从句引导词（that/if/疑问词）等，题干长难句
- 选词填空：借用外刊 2090 学校篇改编，70% 空考数词/名词/引导词
- 造句 3：① 用 three hundred ② 用 two thirds ③ 用 I wonder whether...

**词汇区间**：1000 词表第 4 课（旅行/数字相关）

---

### L2 · 感叹句与句子结构（复习 50% + 宾语从句语序 50%）

**复习板块（50%）**
1. What + a/an + adj + 可数单数名词 + 主谓！（What a clever boy he is!）
2. What + adj + 不可数/复数名词 + 主谓！（What beautiful flowers!）
3. How + adj/adv + 主谓！（How beautiful the flowers are!）
4. 判诀：**有名用 What，无名用 How**
5. 祈使句复习 + 基本句型五类回顾

**新知板块（50%，宾语从句·陈述语序 + 时态呼应）**
1. 陈述语序：从句一律"主语 + 谓语"（无 do/does/did 助动词倒装）
2. 时态呼应：主句现在时→从句任意时态；主句过去时→从句相应过去时态（客观真理除外）
3. 例句：Could you tell me where the library is?（不是 where is）

**练习（10 + 外刊选词 + 造句3）**
- 语法选择 10：感叹句 What/How 判断 + 宾语从句语序/时态，题干长难句
- 选词填空：借用外刊改编，70% 空考感叹词/语序
- 造句 3：① 感叹句 ② 宾语从句陈述语序 ③ 时态呼应

**针对错题 12**：What a clever boy he is!（强化"a clever boy"有名词 → What）

---

### L3 · 动词"花费"四兄弟（复习 50% + 宾语从句引导词辨析 50%）

**复习板块（50%）**
1. **spend**：人 + spend + 时间/钱 + (in) doing / on sth
2. **cost**：物 + cost + 人 + 钱（无被动）
3. **take**：It takes + 人 + 时间 + to do
4. **pay**：人 + pay + 钱 + for sth
5. It's + adj + **of** + sb + to do（人品评价）vs **for** + sb + to do（事情评价）

**新知板块（50%，宾语从句·三大引导词辨析）**
1. that vs if/whether vs 疑问词 的选择依据
2. whether 特例：whether or not / 介词后 / 不定式前
3. if 不能用于 or not 前；whether 可以

**练习（10 + 外刊选词 + 造句3）**
- 语法选择 10：spend/cost/take/pay 主语判断 + for/of + 引导词辨析，题干长难句
- 选词填空：借用外刊改编，70% 空考动词/引导词
- 造句 3：① spend...doing ② It's kind of you to... ③ whether or not

**针对错题 23/25**：spend two hours finishing（非 cost）；kind of you（非 for）

---

### L4 · 情态动词与反身代词（复习 50% + 定语从句关系代词 50%）

**复习板块（50%）**
1. had better (not) do sth——后接动词原形，否定 not 在 better 后
2. should/could 表建议、请求、义务
3. 反身代词八宫格 + 用法（teach oneself, enjoy oneself 等）
4. 情态动词表推测：must（肯定）/can't（否定）/might（可能）

**新知板块（50%，定语从句·关系代词）**
1. 定义：修饰名词/代词的从句（先行词 + 关系词 + 从句）
2. who/whom（人）、which（物）、that（人/物通用）、whose（所属）
3. 关系代词在从句中作主语/宾语/定语

**练习（10 + 外刊选词 + 造句3）**
- 语法选择 10：had better not do + 情态动词表推测 + 关系代词选择，题干长难句
- 选词填空：借用外刊改编，70% 空考情态动词/关系代词
- 造句 3：① had better not 建议句 ② 反身代词自学句 ③ who 定语从句

**针对错题 30/31**：had better not eat（非 not to eat）；teach herself（非 him）

---

### L5 · 被动语态基础（复习 50% + 定语从句关系副词 50%）

**复习板块（50%）**
1. 被动构成：be + 过去分词（时态由 be 体现）
2. 一般现在时被动：am/is/are + done（English is spoken...）
3. 一般过去时被动：was/were + done（It was invented...）
4. 变被动三步骤：宾语提前→动词变 be+过去分词→主语变 by+宾格（可省略）

**新知板块（50%，定语从句·关系副词）**
1. when（时间）、where（地点）、why（原因）
2. 关系副词 = 介词 + which（when = in/at which；where = in/at which；why = for which）
3. 关系代词 vs 关系副词的选择：看从句缺主语/宾语 → 代词；缺状语 → 副词

**练习（10 + 外刊选词 + 造句3）**
- 语法选择 10：被动时态判断 + 关系副词选择，题干长难句
- 选词填空：借用外刊改编，70% 空考被动/关系副词
- 造句 3：① 一般现在时被动 ② where 定语从句 ③ when 定语从句

**针对错题 44**：English is spoken（误选 is speaking）

---

### L6 · 时态综合（复习 50% + 定语从句 that/which 特例 50%）

**复习板块（50%）**
1. 八种时态总表复习
2. 现在完成时 for/since 辨析（已强项，滚动巩固）
3. 过去完成时 had + done——"过去的过去"

**新知板块（50%，定语从句·只用 that / 只用 which）**
1. **只用 that**：先行词为不定代词、被 the only/the very/序数词/最高级修饰、既有人又有物
2. **只用 which**：介词 + which、非限制性定语从句

**练习（10 + 外刊选词 + 造句3）**
- 语法选择 10：时态辨析 + that/which 特例，题干长难句
- 选词填空：借用外刊改编，70% 空考时态/引导词
- 造句 3：① for/since ② had done ③ the only + that

---

### L7 · 非谓语动词（复习 50% + 被动语态含情态 50%）

**复习板块（50%）**
1. 动词不定式 to do：作宾语/目的状语（已强项，巩固）
2. stop doing vs stop to do（已强项，巩固）
3. make + 宾语 + 宾补：make sb do / make sth adj
4. It's + adj + to do 句型扩展 + 不定式作主语

**新知板块（50%，被动语态·含情态动词）**
1. 情态动词 + be + done（should be allowed...）
2. 主动表被动：need doing = need to be done；物作主语（The book sells well）

**练习（10 + 外刊选词 + 造句3）**
- 语法选择 10：make 复合宾语 + It's adj to do + 情态动词被动，题干长难句
- 选词填空：借用外刊改编，70% 空考非谓语/被动
- 造句 3：① make 复合宾语 ② It's adj to do ③ should be + done

---

### L8 · 句子成分与句型（复习 50% + 被动语态各时态 50%）

**复习板块（50%）**
1. 主语/谓语/宾语/宾补/状语识别
2. 五种基本句型：主谓/主谓宾/主系表/主谓双宾/主谓宾补
3. 句子成分在长难句中的拆解

**新知板块（50%，被动语态·各种时态完整）**
1. 现在完成时被动：has/have been + done
2. 一般将来时被动：will be + done
3. 含情态动词被动完整：情态动词 + be + done

**练习（10 + 外刊选词 + 造句3）**
- 语法选择 10：句子成分识别 + 各时态被动，题干长难句
- 选词填空：借用外刊改编，70% 空考被动
- 造句 3：① 主谓宾补 ② has been done ③ will be done

---

### L9 · 时态与语态综合（复习 50% + 九年级补充语法 50%）

**复习板块（50%）**
1. 八种时态总表 + 主谓一致
2. if 条件句、although/until/so that 状语从句
3. 现在完成时 for/since 深度辨析

**新知板块（50%，九年级 U3 补充语法）**
1. be supposed to do sth（应该做某事）
2. make + 宾语 + 宾补完整（make sb do / make sth adj / make it + adj + to do）

**练习（10 + 外刊选词 + 造句3）**
- 语法选择 10：时态/主谓一致 + be supposed to + make 复合宾语，题干长难句
- 选词填空：借用外刊改编，70% 空考时态/补充语法
- 造句 3：① be supposed to ② make sb do ③ make sth adj

2. **语法选择固定 10 题**：每题 2 空，A/B/C/D 每选项提供两个词（分别对应两个空），**不得将选项拆成 (1)(2) 两行重复**

4. **造句题只考本课核心语法结构直译**，不考俗语、不考意译
5. 词汇难度：生词率 15%-20%，不超过湖南 2026 中考难度
6. 所有文件命名统一中文，落盘 `黄浩昀\语法巩固方案\`，学生版/教师版分目录
7. 语法知识点成体系（复习按板块、新知按完整语法点），不零散
