### 2. 作文不讲
- 黄浩昀阶段目标不含书面表达专项训练

### 3. 考察重点（丢分点）
- **完形填空**：重点训练
- **五选四**：重点训练
- **阅读回答问题**（非阅读理解选择）：重点训练，这是主要丢分项

## 三、核心学习任务分解

| 任务 | 内容 | 方法 |
|------|------|------|
| **基础词汇过关** | 八年级全册词汇 → 批量筛选 → 未掌握词汇建档 | 词汇诊断 + 逐批筛选，未记住的反复记 |
| **高频新词掌握** | 高频词重点记 | 结合时文阅读，出现即标注掌握 |
| **词性转化** | 名词→动词→形容词→副词 派生 | 每课附加学习 |
| **重点句型** | 高频句型理解与运用 | 每课附加，配练习 |
| **完形填空** | 中考题型专项 | 每周精练 + 讲评 |
| **五选四** | 篇章衔接判断专项 | 每周精练 + 讲评 |
| **阅读回答问题** | 中考「阅读表达」题型（5 题：细节 + Why/Why not + 翻译） | 重点专项，逐题精练 |

## 六、教学原则（黄浩昀适用）

1. **词汇优先**：基础词汇大面积筛，未掌握词汇建档反复记
2. **题型导向**：围绕丢分点（完形/五选四/阅读回答问题）训练，不撒网
3. **语篇输入**：用哈佛外刊语篇承载词汇与题型训练，一举多得
4. **少而精**：作文不讲，词性转化/重点句型附加掌握
5. **数据追踪**：每课记录正确率，动态调整重点
