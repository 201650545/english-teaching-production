## 阶段三：语法/能力（P13-P18）

### P13 📖 比较级复现运用

| 维度 | 内容 |
|------|------|
| **[视觉焦点]** | more honest than / as honest as / the most honest / not as honest as |
| **[教师话术]** | "上节课学了比较级，今天在友谊语境中复现运用。口诀：比较用 more…than，同级 as…as 中间站，最高 the most 加最后。" |
| **[学生可能错点与纠错]** | more honester 误用。纠错："honest 是多音节词，用 more——more honest。" |

### P14 📖 Fact vs Opinion 讲解

| 维度 | 内容 |
|------|------|
| **[视觉焦点]** | 定义 + 识别标记表 + 例句 |
| **[教师话术]** | "区分事实和观点。口诀：事实能证明真假，观点是个人的看法；数据描述是事实，think/believe 是观点。'Tom is 14 years old'是事实，'Tom is the best friend'是观点。" |
| **[学生可能错点与纠错]** | 把"He is a good person"当事实。纠错："good 是主观判断，所以是 Opinion。" |

### P15 ✍️ Fact vs Opinion 判断练习

| 维度 | 内容 |
|------|------|
| **[视觉焦点]** | 10 句标注 F/O |
| **[教师话术]** | "给这 10 个句子标注 F 或 O。注意主观判断词：should, best, most important。" |

### P16 📖 观点表达句型

| 维度 | 内容 |
|------|------|
| **[视觉焦点]** | In my opinion, ... / I think that ... / For example, ... / However, ... |
| **[教师话术]** | "第三个能力：表达观点。口诀：观点开口 In my opinion，think/believe that 跟上来；举例 For example，转折 However 不忘加。" |
| **[学生可能错点与纠错]** | In my opinion, I think... 语义重复。纠错："两者二选一——In my opinion, ... 或 I think that ..." |

### P17-P18 ✍️ 观点句型练习与写作框架

| 维度 | 内容 |
|------|------|
| **[视觉焦点]** | 四句型框架模板 + 示范段落 |
| **[教师话术]** | "写作框架：In my opinion → I think that → For example → However → So I believe。注意 However 后必须加逗号。" |

## 阶段四：拼读教学（P19-P22）

### P19-P20 🔤 -tion/-sion 规则

| 维度 | 内容 |
|------|------|
| **[视觉焦点]** | -tion 发 /ʃən/；-sion 元音后发 /ʒən/、辅音后发 /ʃən/ |
| **[教师话术]** | "今天拼读聚焦后缀。action, information, suggestion 的 -tion 发 /ʃən/；decision, conclusion, television 的 -sion 发 /ʒən/。注意 opinion 的 -nion 是特殊变体，发 /njən/。" |
