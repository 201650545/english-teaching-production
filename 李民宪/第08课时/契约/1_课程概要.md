## 三、语法硬契约

### 3.1 比较级复现运用（L07 已授，本课在友谊语境中运用）

**口诀**：比较用 more…than，同级 as…as 中间站，最高 the most 加最后，否定 not so/as 来变幻。

**公式矩阵**：
- 比较级：A is more honest than B.
- 同级比较：A is as honest as B.
- 最高级：A is the most honest (of all).
- 不及比较：A is not as/so honest as B.

**防越级**：仅复现运用，不引入新语法点；不引入 than ever before / the more...the more... 等超纲结构；比较对象限定为人物品质。

### 3.2 事实与观点区分（Fact vs Opinion）

**口诀**：事实能证明真假，观点是个人的看法；数据描述是事实，think/believe 是观点。

**公式矩阵**：
- Fact（事实）：可被证明真假 → 数据、日期、可观察的描述（Tom is 14 years old.）
- Opinion（观点）：个人想法/感受 → think, believe, in my opinion, should, best（I think Tom is the best friend.）

**防越级**：不引入 factual claim / subjective statement 等学术术语，用学生能理解的方式区分。

### 3.3 观点表达句型

**口诀**：观点开口 In my opinion，think/believe that 跟上来；举例 For example，转折 However 不忘加。

**公式矩阵**：
- 表达观点：In my opinion, ... / I think/believe that ...
- 举例说明：For example, ...
- 转折对比：However, ...

**写作段落框架**：[观点句] In my opinion, ... → [理由] I think that ... → [事实/例子] For example, ... → [转折/补充] However, ... → [总结] So I believe ...

**防越级**：不引入 From my perspective / As far as I'm concerned 等高级表达；不要求让步状语从句；写作框架固定四句型。

## 五、拼读/音标硬契约

- **发音规则**：`-tion` 后缀发 /ʃən/；`-sion` 后缀（元音后）发 /ʒən/、（辅音后）发 /ʃən/
- **典型例词**：-tion→/ʃən/（action, information, suggestion, celebration）；-sion→/ʒən/（decision, conclusion, television）；-sion→/ʃən/（discussion, compression）
- **注意**：opinion 的 -nion 发 /njən/，是 -tion 的变体形式，需单独记忆
- **练习**：听音标注 → 分类朗读 → 填空朗读 → 对比朗读（最小对立体 action vs vision）

## 七、输出任务硬契约

- **任务情境**：书面表达"A good friend"观点短文。
- **交际目标**：用观点表达四句型（In my opinion + I think that + For example + However）+ 比较级复现，完成 80-100 词短文。
- **必用词（5+）**：spare time, pleasure, have sth in common, opinion, honest, friendship, difference（至少 5 个目标词）
- **必含要素**：事实 + 观点 + 例子
- **句型支架**：In my opinion, ... / I think that ... / For example, ... / However, ...
- **完成标准**：至少 5 个必用词 + 含事实/观点/例子 + 四句型框架 + 结构完整 + 语言正确
