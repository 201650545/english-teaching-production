## 阶段三：语法 3 考点（P13-P18）

### P13 📖 语法①：数量/长度/重量表达

| 维度 | 内容 |
|------|------|
| **[视觉焦点]** | How long/How tall/How much does it weigh + meters/kilograms |
| **[教师话术]** | "本课第一个能力：描述数据。口诀：How long 问长度，How tall 问高度；How much 问重量。How long is this bamboo? How much does the panda weigh?" |
| **[学生可能错点与纠错]** | How long does it weigh 误用。纠错："问重量用 How much——How much does it weigh?" |

### P14 ✍️ 语法①练习

| 维度 | 内容 |
|------|------|
| **[视觉焦点]** | 5 题（How much 问重量 / is + 数字 + meters long） |
| **[教师话术]** | "注意：The bamboo is 10 meters long（有 is 和 long）；It weighs 100 kilograms（weigh 是动词）。" |

### P15 📖 语法②：比较级与最高级复习

| 维度 | 内容 |
|------|------|
| **[视觉焦点]** | -er/-est + than / the + 最高级 + 范围 / as...as |
| **[教师话术]** | "复习七下的比较级和最高级。口诀：tall-taller-tallest，fast-faster-fastest；the cheetah is the fastest animal on land." |
| **[学生可能错点与纠错]** | more faster 误用。纠错："fastest 不能再加 most——the fastest。" |

### P16 ✍️ 语法②练习

| 维度 | 内容 |
|------|------|
| **[视觉焦点]** | 5 题（-er/-est 变化 + 最高级加 the + as...as 原级） |
| **[教师话术]** | "注意：最高级前必须加 the；as...as 中间用原级。" |

### P17 📖 语法③：看图描述与信息卡

| 维度 | 内容 |
|------|------|
| **[视觉焦点]** | This is... / It has... / It can... / It lives... / It weighs... |
| **[教师话术]** | "第三个能力：看图描述。口诀：This is 这是什么，It has 它有什么，It can 它会什么，It lives 它住哪里。This is a cheetah. It has long legs. It can run very fast." |
| **[学生可能错点与纠错]** | This is butterfly 误用。纠错："可数名词单数前加 a/an——This is a butterfly." |

### P18 ✍️ 语法③练习

| 维度 | 内容 |
|------|------|
| **[视觉焦点]** | 5 题（a/an 单数 / has / can 原形 / weighs） |
| **[教师话术]** | "注意：It can + 动词原形（can run）；It has + 名词（has long legs）。" |
