> 本课承接 L08（Unit 3 友谊与观点），词汇复习以 L08 核心词为跨课复习对象。

## 三、语法硬契约

### 3.1 数量、长度和重量表达（How long / How tall / How much does it weigh？）

**口诀**：How long 问长度，How tall 问高度；How much 问重量；数量 many 接可数，much 接不可数。

**公式**：
- 问长度：How long + is + 物?（How long is this bamboo?）
- 问高度：How tall + is + 物?（How tall is the redwood?）
- 问重量：How much + does + 物 + weigh?（How much does the panda weigh?）
- 答：The bamboo is 10 meters long. / It weighs about 100 kilograms.

**防越级**：不引入 How far / How heavy 等混合问句；单位仅限 meters 和 kilograms。

### 3.2 比较级与最高级复习（tallest / fastest / biggest + than / as...as）

**口诀**：tall-taller-tallest，fast-faster-fastest；big-bigger-biggest；than 比较两者，the + 最高级 + 范围；as...as 同一级。

**公式**：
- 比较级：A + be + 比较级 + than + B（The redwood is **taller than** the pine tree.）
- 最高级：A + be + the + 最高级 + 范围（The cheetah is **the fastest** animal on land.）
- 同级：A + be + as + 原级 + as + B / not as...as

**防越级（培优红线）**：最高级仅复习七下规则变化；不规则最高级仅辨认复习；不引入 the + 比较级, the + 比较级、more and more、by far 等。

### 3.3 看图描述与信息表格（This is... / It has... / It can...）

**口诀**：This is 这是什么，It has 它有什么；It can 它会什么，It lives 它住哪里；信息卡上六要素。

**公式**：
- 名称：This is a / an ...
- 外观：It has ... / It is ...
- 大小/长度/重量：It is ... tall/long. It weighs ...
- 能力：It can ...
- 栖息/食物：It lives / grows in ... / It eats ...

**防越级**：不引入定语从句（which/that）和被动语态（is used for 仅认读不产出）；信息卡句式仅限简单句。

## 五、拼读/音标硬契约

- **发音规则**：字母组合 `oo` 长元音 /uː/ 与短元音 /ʊ/ 的对比（moon, zoo vs. book, look）
- **典型例词**：oo→/uː/（moon, zoo, food, cool, school, bamboo, tool）；oo→/ʊ/（book, look, good, foot, wood）
- **练习**：朗读 15 词 → 辨音归类 → 听音选词 → 拼写

## 七、输出任务硬契约

- **任务情境**：制作一种动植物的"信息卡"。

- **完成标准**：至少 6 个必用词 + 含数据 + 至少 1 个比较级/最高级 + 结构完整 + 语言正确
