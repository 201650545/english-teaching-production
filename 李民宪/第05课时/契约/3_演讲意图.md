## 阶段三：语法 3 考点（P9-P14）

### P9 📖 语法①：can/could 请求与帮助

| 维度 | 内容 |
|------|------|
| **[视觉焦点]** | 口诀+公式+表格：Can/Could you (please)...? / Can I...? / Let me help you. 答语 |
| **[教师话术]** | "本课第一个交际功能：请求与帮助。口诀：Can 来请求很礼貌，Could 更客气；Can/Could 后面动词原形，please 记得加上。请求帮助用 Can/Could you...?，提出帮助用 Can I...? 或 Let me help you." |
| **[学生可能错点与纠错]** | Could you please help me 与 Could you help me please 语序。纠错："please 可放在句首或句末，但不能放在动词后——Could you please help me? / Could you help me, please?" |

### P10 ✍️ 语法①练习

| 维度 | 内容 |
|------|------|
| **[视觉焦点]** | 5 题情景选择，高相似干扰（Can you...? vs Could you...? 语气、语序） |
| **[教师话术]** | "做练习检验一下。注意情景——对朋友用 Can you 就可以，对不太熟的人用 Could you 更礼貌。" |
| **[学生可能错点与纠错]** | 混淆请求帮助与提出帮助。纠错："请求帮助 = 请别人做 → Could you...?；提出帮助 = 我来做 → Can I...? / Let me..." |

### P11 📖 语法②：邀请与回应

| 维度 | 内容 |
|------|------|
| **[视觉焦点]** | Would you like to...? / Why not come to...? / Yes, I'd love to. / I'd love to, but... |
| **[教师话术]** | "第二个交际功能：邀请与回应。邀请常用 Would you like to + 动词原形；接受说 Yes, I'd love to. / That sounds great.；拒绝要礼貌并给理由：I'd love to, but I have to..." |
| **[学生可能错点与纠错]** | Would you like to do 与 Would you like doing。纠错："Would you like to do sth. 表示邀请/意愿，Do you like doing sth. 表示兴趣爱好，两者不同。" |

### P12 ✍️ 语法②练习

| 维度 | 内容 |
|------|------|
| **[视觉焦点]** | 5 题邀请情景选择（接受/拒绝+理由，高相似干扰） |
| **[教师话术]** | "现在选择正确的回应。注意：拒绝时要先表示感谢再给理由，不能只说 No。" |
| **[学生可能错点与纠错]** | 拒绝时忘记给理由。纠错："礼貌拒绝 = I'd love to, but... + 理由，如 but I have to pack up my things." |

### P13 📖 语法③：方位表达

| 维度 | 内容 |
|------|------|
| **[视觉焦点]** | in/on/under/behind/next to 口诀+公式+家庭场景例句 |
| **[教师话术]** | "第三个功能：用方位词描述家庭空间。口诀：in 在里面，on 在上面，under 在下方；next to 紧挨着，behind 在后头。句型：The lamp is on the table. / The cat is under the chair." |
| **[学生可能错点与纠错]** | next to 与 behind 混淆。纠错："next to = 紧挨着（并排），behind = 在后面（前后）。The balcony is next to the living room." |

### P14 ✍️ 语法③练习

| 维度 | 内容 |
|------|------|
| **[视觉焦点]** | 5 题方位选择（图片场景+高相似干扰） |
| **[教师话术]** | "看图选方位词。注意图片细节——物体是在桌子上面、下面，还是在旁边、后面。" |
| **[学生可能错点与纠错]** | on 与 in 混淆。纠错："on = 在表面上（on the table），in = 在里面（in the box）。" |
