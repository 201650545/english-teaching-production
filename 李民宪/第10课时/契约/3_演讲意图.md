## 阶段三：语法 3 考点（P13-P18）

### P13 📖 语法①：because/so 因果句

| 维度 | 内容 |
|------|------|
| **[视觉焦点]** | because 表原因 + because 句首 + so 表结果 + if 表条件 口诀+公式+表格 |
| **[教师话术]** | "本课第一个能力：用 because/so/if 表达因果关系。口诀：because 因为表原因，so 所以表结果；if 如果表条件，because 和 so 不同用。" |
| **[学生可能错点与纠错]** | Bees are important, so we must... 中 because 与 so 重复。纠错："because 和 so 只能用一个——Because bees are important, we must protect them." |

| 维度 | 内容 |

| **[教师话术]** | "做练习。注意：because 表原因，so 表结果，if 表条件；because 和 so 不能同时用。" |

### P15 📖 语法②：主旨与细节

| 维度 | 内容 |
|------|------|
| **[视觉焦点]** | topic sentence 段首/段尾 + supporting details + 主旨题/细节题提问 |

## 阶段四：自然拼读（P19-P22）

### P19-P20 🔊 ow/ou 双元音规则

| 维度 | 内容 |
|------|------|
| **[视觉焦点]** | ow→/aʊ/（flower, how, now, cow, brown）、ou→/aʊ/（loud, about, house, cloud, mouse）、ow→/əʊ/（slow, know, snow, grow, yellow） |
| **[教师话术]** | "今天拼读聚焦 ow/ou 双元音。ow 和 ou 都可以发 /aʊ/（张大嘴'啊屋'，如 flower, loud）；但 ow 有时发 /əʊ/（口型收圆'欧'，如 slow, know）。注意对比：flower（/aʊ/）vs slow（/əʊ/）。" |

### P21-P22 🔤 辨音归类与拼读练习

| 维度 | 内容 |
|------|------|
| **[视觉焦点]** | 15 词拖入 /aʊ/ 与 /əʊ/ 两栏归类 + 听音选词 + 拼写 |
| **[教师话术]** | "把单词拖到正确的类别里，然后听音判断它属于 /aʊ/ 还是 /əʊ/。" |
