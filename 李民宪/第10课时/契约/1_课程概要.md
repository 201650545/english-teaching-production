## 三、语法硬契约

### 3.1 because/so 因果关系句（含 if 条件）

**口诀**：because 因为表原因，so 所以表结果；if 如果表条件，because 和 so 不同用。

**公式**：
- because 表原因：主句 + because + 从句（Bees are important because they help plants.）
- because 开头：Because + 从句, + 主句（Because bees carry pollen, plants can grow.）
- so 表结果：原因句, + so + 结果句（Bees carry pollen, so plants can grow.）
- if 表条件：主句 + if + 从句（If we protect bees, plants will grow well.）

**防越级（培优红线）**：因果表达仅限 because/so/if 简单结构，不引入让步状语从句（although/though）、目的状语从句（so that/in order to）等。

### 3.2 主旨与细节（topic sentence + supporting details）

**口诀**：主题句 topic sentence 常在段首，支撑细节 supporting details 跟在后；主旨题看中心概括全段，细节题回原文逐句比对。

**公式**：
- topic sentence：段落中心句，常在段首或段尾（Bees play an important role in our ecosystem.）
- supporting details：支撑细节（For example, they carry pollen from flower to flower.）
- 主旨题：main idea / best title / mainly about
- 细节题：according to / which / how many

**防越级**：仅限段落主旨识别，不引入深层推断与作者意图分析（留至阅读专项）。

### 3.3 词义猜测策略（上下文线索/同义复现）

**口诀**：猜词先看上下文，前后句子找线索；同义复现提示同义，but/unlike 提示反义。

**公式**：
- 定义法：means / is called / that is（Pollination means carrying pollen...）
- 同义复现：前后句同义词重复（link = connect）
- 举例法：for example / such as / like
- 对比法：but / unlike / however

**防越级**：仅限句内/段内上下文线索与同义复现猜词，不引入跨段推理猜词。

## 五、拼读/音标硬契约

- **发音规则**：字母组合 `ow` / `ou` 双元音对比——/aʊ/（张大嘴"啊屋"）与 /əʊ/（口型收圆"欧"）
- **典型例词**：ow→/aʊ/（flower, how, now, cow, brown）；ou→/aʊ/（loud, about, house, cloud, mouse）；ow→/əʊ/（slow, know, snow, grow, yellow）
- **练习**：朗读 15 词 → 辨音归类（/aʊ/ vs /əʊ/）→ 听音选词 → 拼写

## 七、输出任务硬契约

- **任务情境**：写一段说明文，回答"Why are plants and animals important?"。
- **交际目标**：用 because/so/if 因果句 + 生态词汇，完成 80 词左右的说明文。
- **必用词（6+）**：connect, be connected with/to, imagine, protect, importance, play a role in（至少 6 个目标词）
- **必含句式**：至少一句 because/so 因果句
- **句型支架**：...because... / ..., so... / If we protect..., ... / ...play an important role in...
- **完成标准**：至少 6 个必用词 + 至少 1 个因果句 + 结构完整（总起→分点→总结）+ 语言正确
