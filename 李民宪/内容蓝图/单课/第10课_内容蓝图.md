## 二、语法/能力详案（3 考点）

### 能力①：because/so 因果关系句（含 if 条件）

**口诀**：
> "because 因为表原因，so 所以表结果；if 如果表条件，because 和 so 不同用"

**公式矩阵**：

| 句型 | 公式 | 示例 |
|---|---|---|
| because 表原因 | 主句 + because + 从句 | Bees are important because they help plants. |
| because 开头 | Because + 从句, + 主句 | Because bees carry pollen, plants can grow. |
| so 表结果 | 原因句, + so + 结果句 | Bees carry pollen, so plants can grow. |
| if 表条件 | 主句 + if + 从句 | If we protect bees, plants will grow well. |

**易错点**：
- ❌ Because bees are important, so we must protect them. → ✅ Bees are important, so we must protect them.（because 与 so 不同时用）
- ❌ Plants grow well so bees help them. → ✅ Plants grow well because bees help them.（原因句用 because）
- ❌ If we protect the ecosystem so animals will live. → ✅ If we protect the ecosystem, animals will live.（if 句不加 so）

**防越级约束（培优红线）**：因果表达仅限 because/so/if 简单结构，不引入让步状语从句（although/though）、目的状语从句（so that/in order to）等。

---

### 能力②：主旨与细节（topic sentence + supporting details）

**口诀**：
> "主题句 topic sentence 常在段首，支撑细节 supporting details 跟在后；主旨题看中心概括全段，细节题回原文逐句比对"

**公式矩阵**：

| 要素 | 说明 | 示例 |
|---|---|---|
| topic sentence | 段落中心句，常在段首或段尾 | Bees play an important role in our ecosystem. |
| supporting details | 支撑细节：例子、数据、解释 | For example, they carry pollen from flower to flower. |
| 主旨题提问 | main idea / best title / mainly about | What is the main idea of this passage? |
| 细节题提问 | according to / which / how many | According to the passage, what do bees carry? |

**易错点**：
- ❌ 把细节当主旨：选 "Bees carry pollen." 作段落主旨 → ✅ 选 "Bees help plants grow."（概括全段）
- ❌ 主旨题凭开头一句话就选 → ✅ 主旨题必须覆盖全段/全文中心
- ❌ 细节题凭印象作答 → ✅ 回原文定位，找到原句并比对

**防越级约束**：仅限段落主旨识别（topic sentence + supporting details），不引入深层推断与作者意图分析（留至阅读专项）。

---

### 能力③：词义猜测策略（上下文线索/同义复现）

**口诀**：
> "猜词先看上下文，前后句子找线索；同义复现提示同义，but/unlike 提示反义"

**公式矩阵**：

| 策略 | 线索 | 示例 |
|---|---|---|
| 定义法 | means / is called / that is | Pollination means carrying pollen from flower to flower. |
| 同义复现 | 前后句同义词、近义词重复出现 | Bees connect flowers. They link one flower to another.（link = connect） |
| 举例法 | for example / such as / like | Some animals, such as bees and butterflies, help plants. |
| 对比法 | but / unlike / however | Unlike slow animals, cheetahs run very fast. |

**易错点**：
- ❌ 只背词义不读上下文 → ✅ 回到画线词前后句找线索
- ❌ 忽略同义复现 → ✅ 前后句重复出现的同义词语义相同
- ❌ 把 but 后的词当同义词 → ✅ but/unlike 提示反义关系

**防越级约束**：仅限句内/段内上下文线索与同义复现猜词，不引入跨段推理猜词（留至阅读专项）。

## 五、自然拼读（本课规则）

**规则**：字母组合 `ow` / `ou` 双元音对比——/aʊ/（张大嘴"啊屋"）与 /əʊ/（口型收圆"欧"）

| 组合 | 音素 | 示例词 |
|---|---|---|
| ow | /aʊ/ | flower, how, now, cow, brown |
| ou | /aʊ/ | loud, about, house, cloud, mouse |
| ow | /əʊ/ | slow, know, snow, grow, yellow |

**练习**：朗读 15 词 → 辨音归类（/aʊ/ vs /əʊ/）→ 听音选词 → 拼写。
