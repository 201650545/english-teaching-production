## 二、语法/能力详案（3 考点）

### 能力①：数量、长度和重量表达（How long / How tall / How much does it weigh？+ meters / kilograms）

**口诀**：
> "How long 问长度，How tall 问高度；How much 问重量，meters 米 kilograms 公斤；数量 many 接可数，much 接不可数"

**公式矩阵**：

| 句型 | 公式 | 示例 |
|---|---|---|
| 问长度 | How long + is + 物? | How long is this bamboo? |
| 问高度 | How tall + is + 物? | How tall is the redwood? |
| 问重量 | How much + does + 物 + weigh? | How much does the panda weigh? |
| 答长度 | 物 + is + 数字 + meters long | The bamboo is 10 meters long. |
| 答高度 | 物 + is + 数字 + meters tall | The redwood is over 100 meters tall. |
| 答重量 | 物 + weighs + 数字 + kilograms | The panda weighs about 100 kilograms. |
| 数量表达 | There is/are + many/much + ... | There are many trees in the forest. |

**易错点**：
- ❌ How long does it weigh? → ✅ How **much** does it weigh?（问重量用 How much）
- ❌ The bamboo long 10 meters. → ✅ The bamboo **is** 10 meters **long**.（长度/高度必须有 is）
- ❌ It weigh 100 kilograms. → ✅ It **weighs** 100 kilograms.（第三人称单数加 s）

**防越级约束**：不引入 How far / How heavy 等混合问句；单位仅限 meters 和 kilograms，不做 ton/km 换算。

---

### 能力②：比较级与最高级复习（tallest / fastest / biggest + than / as...as）

**口诀**：
> "tall-taller-tallest，fast-faster-fastest；big-bigger-biggest，双写辅音记心间；than 比较两者，the + 最高级 + 范围；as...as 表同级，一样高来一样快"

**公式矩阵**：

| 句型 | 公式 | 示例 |
|---|---|---|
| 比较级 | A + be + 比较级 + than + B | The redwood is **taller than** the pine tree. |
| 最高级 | A + be + the + 最高级 + 范围 | The cheetah is **the fastest** animal on land. |
| 同级肯定 | A + be + as + 原级 + as + B | An elephant is **as big as** a small car. |
| 同级否定 | A + be + not + as + 原级 + as + B | A snail is **not as fast as** a cheetah. |
| 最高级疑问 | 疑问词 + be + A + the + 最高级 + ...? | Which animal is **the biggest** in the forest? |

**变化规则（复习七下已学）**：

| 类型 | 构成规则 | 示例（本课词） |
|---|---|---|
| 单音节 + -er/-est | 直接加 | tall→taller→tallest, fast→faster→fastest |
| 重读闭音节双写 + -er/-est | 双写尾字母再加 | big→bigger→biggest |
| 不规则（仅辨认复习） | 特殊记忆 | good→better→best, bad→worse→worst |

**易错点**：
- ❌ He is more taller than me. → ✅ He is **taller** than me.（避免双重比较级）
- ❌ The cheetah is the most fastest. → ✅ the **fastest**（fastest 不能再加 most）
- ❌ The cheetah is fastest animal. → ✅ **the fastest**（最高级前必须加 the）
- ❌ as tall than the giraffe → ✅ as tall **as** the giraffe（as...as 中间用原级）

**防越级约束（培优红线）**：
- 最高级仅限复习七下已学规则变化：以 tall→taller→tallest、fast→faster→fastest、big→bigger→biggest 一组示范；
- 不规则最高级（good→best, bad→worst, many→most）仅作辨认复习，不作产出要求；
- 不引入 the + 比较级, the + 比较级、more and more、by far 等生僻/超纲表达。

---

### 能力③：看图描述与信息表格（This is... / It has... / It can... 信息卡句式）

**口诀**：
> "This is 这是什么，It has 它有什么；It can 它会什么，It lives 它住哪里；信息卡上六要素，名称外观和能力"

**公式矩阵**：

| 要素 | 句型 | 示例 |
|---|---|---|
| 名称 | This is a / an ... | This is a cheetah. |
| 外观 | It has ... / It is ... | It has long legs and a small head. |
| 颜色 | It is ... | It is yellow with black spots. |
| 大小/长度/重量 | It is ... tall/long. It weighs ... | It is about 75 cm tall. It weighs about 60 kilograms. |
| 能力 | It can ... | It can run very fast. |
| 栖息/生长 | It lives / grows in ... | It lives in Africa. |
| 食物 | It eats / feeds on ... | It eats other animals. |
| 比较 | It is ... than ... / the ... -est | It is the fastest animal on land. |

**易错点**：
- ❌ This is butterfly. → ✅ This is **a** butterfly.（可数名词单数前加 a/an）
- ❌ It have long legs. → ✅ It **has** long legs.（第三人称单数用 has）
- ❌ It can runs fast. → ✅ It can **run** fast.（can 后接动词原形）
- ❌ It is 60 kilograms weigh. → ✅ It **weighs** 60 kilograms.（weigh 是动词）

**防越级约束**：不引入定语从句（which/that）和被动语态（is used for 仅认读不产出）；信息卡句式仅限简单句。

## 五、自然拼读（本课规则）

**规则**：字母组合 `oo` 长元音 /uː/ 与短元音 /ʊ/ 的对比（moon, zoo vs. book, look）

| 组合 | 音素 | 示例词 |
|---|---|---|
| oo 长音 | /uː/ | moon, zoo, food, cool, school, bamboo, tool |
| oo 短音 | /ʊ/ | book, look, good, foot, wood |
