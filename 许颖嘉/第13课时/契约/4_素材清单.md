## 一、视觉与声效基线

- **配色方案**：红金主色（主色 #C0392B 中国红 + #2C3E50 墨蓝 + 金 #D4AF37 点缀），本课主题强调色 **暖橙 #E67E22**（呼应超市/食物语义）；背景浅米/深底卡片。
- **页面比例**：21:9 宽屏；总页数 **30 页**（八段式：复习3 / 新词5 / 语法7 / 演练4 / 阅读4 / 句子3 / 拼读3 / 总结1）。
- **声效（Web Audio 三函数）**：`playCorrect()`（答对）/ `playError()`（答错）/ `playPageTurn()`（翻页）。
- **翻页交互**：左半屏上一页、右半屏下一页；答案/交互元素 `event.stopPropagation()` 优先，避免误触翻页。
- **答案隐藏**：所有揭晓类元素默认 `display:none`，点击后追加 `.show` 类显示。
- **图标**：emoji 直贴（🛒🥟💰🧾📊✅⚠️📖🔍🎯 等），无需外部图标库。

## 二、本课内容锚点

- **语法考点**：① would like to do / would like sth（意愿表达） ② how much（不可数/价格）vs how many（可数） ③ 数词与价格表达（yuan / dollar / total / pay / cost / spend）
- **词汇语境故事**：为家庭特别晚餐去超市采购（串联 pancake, dumpling, dessert, snack, sugar, salt, oil, price, dollar, yuan, total, pay, change, spend, cost, sell, buy, market, supermarket, service 等 20 词）
- **主题互动游戏（专属，不跨课复用）**：**🛒 超市收银台 · 价格结算器** —— 学生扮演收银员，根据顾客 would like 的清单点击商品、累加价格并结账（操练 would like / how much / 价格计算）
