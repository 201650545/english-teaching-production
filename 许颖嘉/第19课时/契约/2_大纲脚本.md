## ⑦ 自然拼读（P25–P28，共 4 页）

### P25 · 软音 c/g 规则讲解

| 要素 | 内容 |
|---|---|
| 页面标题 | 拼读·软音 c/g 规则 |
| 副标题 | c + e/i/y → /s/；g + e/i/y → /dʒ/ |
| 软音 c 规则表 | c + e/i/y → /s/（city, face, ice, pencil, center, cycle）vs c + a/o/u/辅音 → /k/（cat, cold, cup, class, clean, cream） |
| 软音 g 规则表 | g + e/i/y → /dʒ/（gym, giant, page, age, magic, stage）vs g + a/o/u → /g/（go, game, bag, green, glad, dog） |
| 例外提示 | give, girl, gift 中 g 在 i 前仍发 /g/（硬音），需单独记忆 |
| 核心口诀 | "e/i/y 前面 c 念 /s/，g 念 /dʒ/" |
| 交互设计 | 规则表悬停高亮；点击单词播放发音；例外词红色警示框 |
| 视觉 | 软音行金色高亮，硬音行红色标注，例外词红色警示框 |

### P26 · y 发音规则讲解 + 30 词朗读表

| 要素 | 内容 |
|---|---|
| 页面标题 | 拼读·y 发音规则 + 朗读表 |
| 副标题 | 词首 /j/ · 词尾 /aɪ/ 或 /ɪ/ |
| y 规则表 | y 在词首→/j/（yes, you, yellow, young, year）/ y 在词尾单音节→/aɪ/（my, fly, sky, cry, by, try）/ y 在词尾多音节→/ɪ/（happy, city, baby, funny, sunny, lazy） |
| 30 词朗读表 | 软音 c /s/ 6 词 + 硬音 c /k/ 5 词 + 软音 g /dʒ/ 5 词 + 硬音 g /g/ 5 词 + y 词首 /j/ 4 词 + y 词尾 /aɪ/ 5 词 |
| 核心口诀 | "y 词首念 /j/，词尾元音 /aɪ/ 或 /ɪ/" |
| 交互设计 | 规则表悬停高亮；30 词朗读表点击播放发音；朗读时软音/硬音用颜色区分 |
| 视觉 | 朗读表按类别分组排列，软音金色、硬音红色 |
