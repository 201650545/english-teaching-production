## 一、配色方案（Stage 1 天空蓝主题）

### 1.1 CSS 变量定义

```css
:root {
    --bg-color: #F0F8FF;              /* 页面背景色（爱丽丝蓝） */
    --bg-gradient: linear-gradient(135deg, #F0F8FF 0%, #E0F2FE 100%);  /* 背景渐变 */
    --card-bg: #FFFFFF;               /* 卡片背景色（纯白） */
    --text-primary: #2C3E50;          /* 主文字色（深青黛黑） */
    --text-secondary: #5A6C7D;        /* 次文字色（灰青） */
    --brand: #4A90E2;                 /* 品牌主色（天空蓝） */
    --accent: #FF6B6B;                /* 强调色（珊瑚红） */
    --success: #06D6A0;               /* 成功/正确色（草莓绿） */
    --error: #FF6B6B;                 /* 错误色（珊瑚红） */
    --warning: #FFD166;               /* 警告/遮罩色（亮黄） */
    --info: #4A90E2;                  /* 信息色（天空蓝） */
    --shadow-card: 0 10px 30px rgba(0,0,0,0.06);   /* 卡片阴影 */
    --shadow-hover: 0 4px 12px rgba(0,0,0,0.15);   /* hover 阴影 */
    --radius-card: 20px;              /* 卡片圆角 */
    --radius-btn: 12px;               /* 按钮圆角 */
    --radius-pill: 999px;             /* 药丸形圆角 */
    --font-cn: '微软雅黑', 'Microsoft YaHei', sans-serif;   /* 中文字体 */
    --font-en: 'Arial', sans-serif;   /* 英文字体 */
    --font-ipa: 'Segoe UI', 'Arial', sans-serif;  /* 音标字体 */
}
```

### 1.2 配色应用场景

| 元素 | 颜色 | 用途 |
|---|---|---|
| 页面背景 | `--bg-gradient` (#F0F8FF → #E0F2FE) | 全页渐变背景 |
| 主舞台卡片 | `--card-bg` (#FFFFFF) | 内容卡片纯白底 |
| 导航栏底边 | `--brand` (#4A90E2) | 54px 导航栏品牌色底边 |
| 阶段徽章 | `--brand` 背景 + 白字 | 右上角 Stage 1 · L01 |
| 口诀文字 | `--brand` (#4A90E2) | 语法口诀大标题 |
| 强调重点 | `--accent` (#FF6B6B) | 关键词高亮、错误标注 |
| 遮罩槽 | `--warning` (#FFD166) | 答案遮罩初始色（亮黄） |
| 正确答案 | `--success` (#06D6A0) | 遮罩点击后答案变绿 |
| 进度条 | `--brand` (#4A90E2) | 底部进度条 |
| 页码文字 | `--text-secondary` (#5A6C7D) | 底部页码 |

## 七、本课专属创意标识声明（跨课零重复）

### 7.1 创意标识名称

**打招呼气泡粒子动效（Greeting Bubble Particle Animation）**

### 7.2 创意描述

- **技术**：Canvas 2D 粒子系统（原生 JS，无外部库）
- **视觉**：从页面底部持续飘升的半透明气泡粒子，每个气泡内含一个问候语字母（H/E/L/L/O）
- **运动**：气泡以正弦波形左右摆动上升，透明度随高度递减，到达顶部消失并在底部重生
- **粒子数**：≤ 60 个（符合 ≤100 约束）
- **性能**：使用 requestAnimationFrame，不影响翻页交互
- **应用页**：P1（封面）、P2（问候互动）

### 7.3 跨课零重复声明

> 本创意为第 01 课专属，后续课程不得复用"气泡粒子 + 字母内容"的组合。后续课程须使用不同的创意标识（如 Three.js 3D、CSS 3D 动画、不同母题的粒子效果等）。

### 7.4 Fallback 机制

- 若 Canvas 不支持，显示静态问候语背景
- 粒子动效在翻页时暂停，避免性能问题

## 九、字体规范

| 用途 | 字体 | 备注 |
|---|---|---|
| 中文正文 | 微软雅黑 / Microsoft YaHei | `--font-cn` |
| 英文正文 | Arial | `--font-en` |
| 音标 | Segoe UI, Arial | `--font-ipa`，Unicode 音标字符 |

### 音标显示规范
- 使用 Unicode 音标字符（如 /neɪm/、/frend/）
- 音标颜色：`--text-secondary`（次文字色）
- 音标字号：与正文同级或小一号（26pt）
