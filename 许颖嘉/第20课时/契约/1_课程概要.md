## 二、语法硬契约（3 考点）

### 语法①：G52 一般过去时全套综合与混淆项排除

| 项目 | 内容 |
|---|---|
| 考点编号 | G52 |
| 考点名称 | 一般过去时（was/were & did）全套综合与混淆项排除 |
| 螺旋来源 | 螺旋自 G19/G20（一般过去时引入） |
| 口诀 | 过去时态两套兵，was were 配主语；did 助动问与否，否定 didn't 加原形 |
| 公式 | 肯定句：主语 + V-ed（不规则变形）；否定句：主语 + didn't + 动词原形；一般疑问句：Did + 主语 + 动词原形 + ...?；特殊疑问句：疑问词 + did + 主语 + 动词原形 + ...? |
| be 动词选择 | I/He/She/It/单数名词 → was；We/You/They/复数名词 → were |
| 三步判断法 | 第一步：判断动词类型（be 还是实义）；第二步：be 变 was/were，实义肯定变过去式、否定疑问用 did；第三步：didn't + 动词原形；Did + 主语 + 动词原形 |
| 例句 1 | I was at the top of the hill at noon.（be 动词过去式） |
| 例句 2 | We didn't bring enough water for the journey.（实义动词否定，didn't + 原形） |
| 例句 3 | Did you see the ducks by the lake? — Yes, we did.（实义动词疑问，Did + 原形） |
| 例句 4 | She rode a bicycle to the building.（不规则动词过去式 rode） |
| 例句 5 | The weather was foggy, but we remained happy.（be 动词 + 实义动词过去式） |
| 易错点 | ❌ He didn't went there. → ✅ He didn't go there.（didn't 后接动词原形） |
| 易错点 | ❌ Did she was happy? → ✅ Was she happy?（be 动词疑问用 Was/Were） |
| 易错点 | ❌ They was tired. → ✅ They were tired.（复数用 were） |
| 防越级约束 | 仅限一般过去时（was/were & did）综合复习与混淆项排除，不引入过去进行时（was/were + V-ing）和过去完成时 ✅ |

### 语法②：G53 复合不定代词与形容词后置在过去时中的综合运用

| 项目 | 内容 |
|---|---|
| 考点编号 | G53 |
| 考点名称 | 复合不定代词与形容词后置在过去时中的综合运用 |
| 螺旋来源 | 螺旋自 G49/G50（复合不定代词引入） |
| 口诀 | 复合不定 some any no every，形容词后置跟在后；过去时中综合用，something anything 准确填 |
| 公式 | 肯定句 + some 系列；否定/疑问句 + any 系列；形容词修饰复合不定代词必须后置（something new）；复合不定代词作主语谓语用单数 |
| 三步法 | 第一步：看句型——肯定用 some，否定疑问用 any；第二步：看主谓——复合不定代词作主语谓语用单数（Everyone was...）；第三步：看修饰——形容词后置（something new） |
| 例句 1 | I bought something special on the journey.（some 系列 + 形容词后置） |
| 例句 2 | Did you see anything below the hill?（any 系列 + 疑问句过去时） |
| 例句 3 | Nobody disliked the trip.（no 系列 + 过去时） |
| 例句 4 | We found nothing in the foggy building.（no 系列 + 过去时） |
| 例句 5 | Everyone realized the journey was wonderful.（every 系列 + 过去时，谓语单数） |
| 易错点 | ❌ I didn't see something. → ✅ I didn't see anything.（否定句用 any 系列） |
| 易错点 | ❌ We saw new something. → ✅ We saw something new.（形容词后置） |
| 易错点 | ❌ Everyone were tired. → ✅ Everyone was tired.（复合不定代词谓语单数） |
| 防越级约束 | 仅限已学复合不定代词在过去时语境中的综合运用，不引入 else 后缀结构和其他不定代词 ✅ |

### 语法③：G54 频度副词与过去时间的跨时态对照与识别 ★语法授课最高终点

| 项目 | 内容 |
|---|---|
| 考点编号 | G54 ★ |
| 考点名称 | 频度副词与过去时间的跨时态对照与识别 |
| 螺旋来源 | 螺旋自 G43（频度副词位置） |
| ★ 特别标注 | G54 为全部语法授课的**最高终点**。完成本考点后，L21–L40 不再教授任何新语法，全部转入综合复习与运用阶段 |
| 口诀 | 频度副词跨时态，现在过去位置同；be 后实前不变位，时间词辨时态用 |
| 公式 | 频度副词位置：be 动词后、实义动词前——跨时态不变；时态判断看时间词：every day→现在时；yesterday/last week→过去时；now→进行时 |
| 位置规律 | always/usually/often/sometimes/hardly ever/never 在 be 动词后、实义动词前，时态改变只影响动词形式，不影响副词位置 |
| 三步法 | 第一步：找时间词判断时态；第二步：定动词形式（原形/三单/V-ed/was/were）；第三步：放频度副词（be 后实前） |
| 例句 1 | She was always happy during the journey.（always + be 过去式 was） |
| 例句 2 | We usually walked to the top of the hill.（usually + 实义动词过去式） |
| 例句 3 | He hardly ever ate fast food last month.（hardly ever + 过去式） |
| 例句 4 | Sometimes I went shopping last weekend.（sometimes 句首 + 过去式） |
| 例句 5 | I never drank coffee in 2023.（never + 过去式） |
| 易错点 | ❌ She always was happy. → ✅ She was always happy.（be 动词后） |
| 易错点 | ❌ He usually didn't walked. → ✅ He didn't usually walk.（didn't + 原形，副词在 didn't 后） |
| 易错点 | ❌ She often play yesterday. → ✅ She often played yesterday.（过去时间词→过去式） |
| 防越级约束 | 仅限频度副词与过去时间的跨时态对照识别，不引入现在完成时、过去完成时 ✅ |
| ★ 语法终点里程碑 | 至此，G01–G54 全部语法考点授课完毕。L21–L40 进入纯综合复习与中考真题演练阶段 |
