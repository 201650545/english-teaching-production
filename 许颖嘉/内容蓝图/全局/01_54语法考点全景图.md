## 二、螺旋递进链追踪

### 2.1 动词不定式 to do 三阶螺旋链

```
G15 (L5) like to do     ──首次接触──→
G18 (L6) want to do     ──螺旋复现──→
G34 (L13) would like to do  ──螺旋终点──→  三阶完成
```

### 2.2 一般现在时三阶螺旋链

```
G16 (L6) 非三单肯定/否定  ──首次──→
G25 (L10) 三单 -s/-es 变化  ──补齐三单──→
G26 (L10) 三单否定疑问 does/doesn't  ──补齐否定疑问──→  完整闭环
```

### 2.3 不定代词二阶螺旋链

```
G33 (L12) some/any 基础辨析  ──首次──→
G49 (L19) 复合不定代词 someone/anything/nothing  ──升级──→  完成
```

### 2.4 疑问句系统螺旋链

```
G06 (L1) Who         ──→
G09 (L3) Where       ──→
G14 (L5) What        ──→
G22 (L9) 六宝系统归纳  ──→
G35 (L13) how much/many  ──→
G44 (L17) how often  ──→  六疑问词全部完成
```

### 2.5 名词复数二阶螺旋链

```
G10 (L4) 规则复数 -s/-es/-ies  ──首次──→
G29 (L11) 不规则复数 man→men/child→children  ──补齐──→  完成
```

### 2.6 时态综合螺旋链

```
G03 (L1) be 现在时         ──→
G16 (L6) 一般现在时非三单    ──→
G25 (L10) 一般现在时三单     ──→
G19 (L8) be 过去时          ──→

G46 (L18) 现在进行时        ──→
G52 (L20) 过去时全套综合     ──→  时态授课终点
```

## 五、子代理使用规则

1. **生成第 N 课时**，必须确认本课 3 个考点的编号、名称、防越级约束与本表一致。
2. 课件和练习中**严禁出现超越本课考点防越级清单的内容**（如 L4 出现比较级、L8 出现不规则动词过去时）。
3. 螺旋复现链中的前序考点，可在"复习导入"环节回顾，但**不得在练习中作为新考点出题**。
4. L21–L40 为纯刷题阶段，所有练习题仅围绕 G01–G54 这 54 个考点出题，**严禁引入新语法**。
5. 本文件为**全局锁定表**，子代理**只读引用**，严禁修改。
