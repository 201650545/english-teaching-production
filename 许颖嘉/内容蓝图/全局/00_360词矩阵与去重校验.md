## 一、800 词逐课分配规则与要求

1. **硬性指标**：L1–L40 全部 40 课时，无论课型为新授课、阶段检测课（L7/L16）还是刷题巩固课（L21–L40），**每课均必须安排 20 个目标词汇**。
2. **总量**：40 课时 × 20 词/课 = **800 湖南中考核心词汇**。
3. **分阶段落实**：
   - **L1–L20（语法与核心词汇授课）**：

     - L7、L16（检测课）：每课20个阶段诊断高频词/易错重难点词汇。

     - 每课20个真题高频拓展词汇，结合当课刷题语篇进行专精突破与检测。

## 三、跨课去重 Set 交集校验

### 3.1 校验方法

```python
learned_words = set()
for lesson in [L1, L2, ..., L40]:
    current_words = set(本课20词)
    overlap = current_words.intersection(learned_words)
    if overlap:
        ERROR(f"L{lesson} 与前课词汇重复: {overlap}")
    learned_words.update(current_words)
```

### 3.2 校验要求

| 校验项 | 要求 |
|---|---|
| L1–L40 词汇总量 | **800 词**（40 课 × 20 词） |
| 去重后唯一词汇数 | **800 词** |
| 重复词汇数 | **0** |
| 校验状态 | **✅ 必须通过 100% 零重复校验** |

## 四、Agent 使用规则

1. **生成第 N 课时**，必须加载 `learned_words = set(L1 ~ L(N-1) 的全部词汇)`，执行交集校验。
2. 无论生成哪一课（包括测试课与刷题课），契约 1 与 HTML 课件必须完整体现 **20 个当课目标词汇** 的教学/检测环节。
3. 练习卷 DOCX 的词汇巩固题与语篇生词控制均围绕当课 20 词展开。
