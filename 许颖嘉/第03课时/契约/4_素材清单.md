## 一、配色方案（天际蓝 + 琥珀橙 双色主题）

### 1.1 CSS 变量定义

```css
:root {
    --bg-color: #F0F6FC;              /* 页面背景色（冰蓝白） */
    --bg-gradient: linear-gradient(135deg, #F0F6FC 0%, #E3F0FA 100%);  /* 背景渐变 */
    --card-bg: #FFFFFF;               /* 卡片背景色（纯白） */
    --text-primary: #2C3E50;          /* 主文字色（深青黛黑） */
    --text-secondary: #5A6C7D;        /* 次文字色（灰青） */
    --brand: #4A90E2;                 /* 品牌主色（天际蓝） */
    --accent: #F39C12;                /* 强调色（琥珀橙） */
    --success: #27AE60;               /* 成功/正确色（翡翠绿） */
    --error: #E74C3C;                 /* 错误色（珊瑚红） */
    --warning: #F1C40F;               /* 警告/遮罩色（亮黄） */
    --info: #4A90E2;                  /* 信息色（天际蓝） */
    --brand-light: #D6EAF8;           /* 品牌浅色（天际蓝10%透明度底色） */
    --accent-light: #FDEBD0;          /* 强调浅色（琥珀橙10%透明度底色） */
    --shadow-card: 0 8px 24px rgba(74,144,226,0.08);   /* 卡片阴影（带品牌色调） */
    --shadow-hover: 0 4px 12px rgba(74,144,226,0.15);  /* hover 阴影 */
    --radius-card: 20px;              /* 卡片圆角 */
    --radius-btn: 12px;               /* 按钮圆角 */
    --radius-pill: 999px;             /* 药丸形圆角 */
    --font-cn: '微软雅黑', 'Microsoft YaHei', sans-serif;   /* 中文字体 */
    --font-en: 'Arial', sans-serif;   /* 英文字体 */
    --font-ipa: 'Segoe UI', 'Arial', sans-serif;  /* 音标字体 */
}
```

| 音效类型 | 频率 | 时长 | 触发场景 |

## 七、本课专属创意标识声明（跨课零重复）

### 7.1 创意标识名称

**失物招领站主题视觉系统（LostFoundStation Visual System）**

### 7.2 创意描述

本课将"失物招领站"作为贯穿全课的创意主题，所有页面、组件、互动均围绕这一主题设计：

- **lost-found-tag（招领标签）**：每页左上角的招领标签挂牌装饰，琥珀橙底色+📋图标，轻微摆动动效（2s ease-in-out无限循环），作为本课的视觉签名
- **item-board（登记板）**：新词展示页使用"失物招领登记板"样式，每个单词是一张登记卡，模拟失物招领处的物品登记流程
- **where-locator（方位演示器）**：CSS定位动画演示in/on/under三个方位，物品随按钮点击在箱子/桌面/椅子间移动
- **number-builder（拼写器）**：分段展示基数词，点击数字段按钮切换拼写展示
- **possessive-builder（搭配器）**：点击"有生命/无生命"按钮切换所有格形式
- **lf-ticket（招领票据）**：总结页使用失物招领票据样式，模拟真实招领单

### 7.3 技术实现

- **技术**：纯CSS + 原生JS（无外部库）
- **视觉**：CSS动画 + Flexbox/Grid布局 + CSS变量
- **交互**：addEventListener + classList toggle
- **性能**：无Canvas/WebGL，确保流畅翻页
- **应用页**：全课25页（lost-found-tag），P3-P7（item-board），P9（possessive-builder），P10（number-builder），P11（where-locator），P24（lf-ticket）

### 7.4 跨课零重复声明

> 本创意为第03课专属，后续课程不得复用"失物招领站"主题视觉系统。后续课程须使用不同的创意标识和主题母题。

### 7.5 Fallback 机制

- 招领标签摆动动效在翻页时暂停，避免性能问题
- 互动组件在不支持的浏览器中降级为静态展示

- 音标颜色：`--text-secondary`（次文字色）
- 音标字号：与正文同级（28px）
