## 二、声效系统声明

### 2.1 声效函数

| 函数名 | 声效描述 | 技术实现 | 触发场景 |
|---|---|---|---|
| `playCorrect()` | 正向提示音（上行三音阶 C-E-G） | Web Audio API OscillatorNode，频率 523→659→784Hz，三角波，各 100ms | 答对题目、交互成功、螺旋链节点亮起、复习完成徽章 |
| `playError()` | 纠错提示音（下行两音 G-C） | Web Audio API OscillatorNode，频率 392→261Hz，方波，各 200ms | 答错题目、交互失败 |
| `playPageTurn()` | 翻页/翻转音效（短促"唰"声） | Web Audio API OscillatorNode + 白噪声，频率 800→400Hz，正弦波，80ms 淡出 | 翻页、翻转卡片、主题切换、标签切换 |

### 2.2 声效实现规范

- 基于 Web Audio API（`AudioContext`），不依赖外部音频文件
- 首次调用时初始化 `AudioContext`（需用户交互后才能创建，遵循浏览器自动播放策略）
- 每个音效独立创建振荡器节点，播放后自动释放
- 音量适中（gain 0.15–0.3），不刺耳
