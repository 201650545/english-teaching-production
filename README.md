# English Teaching Production · 英语教学生产体系

初中英语教学资源的**生产方法库**（非成品库）。存放课件/练习的**规范、生成工具、工作流程与样例**，供 AI 助手读取工作方法后，更好地参与课件生产与迭代。

> **关联仓库**：`feishu-data-hub`（飞书数据枢纽）= 学生学习数据（词汇/计划/日志）；本仓库 = 生产体系（规范/工具/流程）。两者互补：前者让 AI 知道"学生在哪"，后者让 AI 知道"我们怎么生产"。

## 核心规范速览（GPT 优先读）

- `00_格式规范/00_全局约束与红线.md` — 文件命名、防越级、红线（禁学生姓名/废 PPTX/词汇零重复）
- `00_格式规范/01_课件格式规范.md` — 课件 page-id 契约、六色卡、题型结构
- `00_格式规范/04_分级差异化参数表.md` — 三档（基础/中等/培优）难度/题型配比/选择题占比硬线
- `00_格式规范/09_风格包规范.md` — **V2.0**：三轴正交（风格族×课型×档位）+ 8 风格变量 + style_manifest 风格合同 + 验证器边界（不审审美，守可读可操作/交互/数据底线）
- `00_格式规范/更新记录.md` — 全部规范变更的唯一记录

## 给 AI 的读取建议

1. 开始前先 `git pull`，确保读到的是最新规范（本仓库会随交付持续推进）；
2. 先读 `00_格式规范/05_索引说明.md` 与 `更新记录.md`，建立规范全貌；
3. 涉及具体生产（生成/修复/重做课件）时，读 `00_总规划/` 对应课时命令 + `00_格式规范/` 对应条目；
4. 看 `样例课件/` 理解真实产出形态（40-45 页 HTML，含交互 + IndexedDB 数据采集）。

## 同步机制（本地 → 本仓库 → 飞书）

- **本仓库** = 规范/工具/命令/汇报的**镜像**（生产方法库）。本地 `D:\英语教学` 才是唯一真源；学生课件体积大且频繁变更，**不入库**。
- **飞书看板**（英语教学流水线 Base）= 课时进度**状态镜像**（蓝图/课件/练习/契约完成度 + 汇报归集），供手机查看与对外展示。
- **一键双发**：`python publish_all.py` 同步三个目录到本仓库 → `git commit + push` → 跑 `feishu_sync.py sync` 刷飞书。交付收尾时跑一次即可。
- 范围约定（见 `00_总规划/GPT对话流程规范_20260806.md` §步骤2）：`00_格式规范/`（全）、`00_工具/`（正式工具 + 词库 JSON，不含 `_`/`fix_`/`check_` 临时脚本与一次性工具）、`00_总规划/`（不含 `06_归档/` 与 zip）、`样例课件/`、`README.md`。
