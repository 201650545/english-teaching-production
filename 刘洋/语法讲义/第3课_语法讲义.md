## 一、语法概念

### 1. 规则与构成

- **构成**：**be + 过去分词（done）**，时态由 be 动词体现
  - 一般现在时被动：**is / am / are + done** → English **is spoken** everywhere.
  - 一般过去时被动：**was / were + done** → The bridge **was built** last year.
  - 含情态动词被动：**情态动词 + be + done** → The work **should be finished** today.
  - 现在完成时被动：**have / has been + done** → The room **has been cleaned**.
- **何时用被动**：主语是动作的"承受者"，或不知道/不必说动作发出者
- **主动变被动**：主动宾语 → 被动主语；动词变 be + done；主动主语可加 by 引出

### 2. 典例（6 句）

1. The classroom **is cleaned** every day.（教室每天被打扫。）
2. The bridge **was built** last year.（这座桥是去年建的。）
3. English **is spoken** by many people in the world.（英语被世界上许多人使用。）
4. The homework **should be finished** on time.（作业应当按时完成。）
5. The library **has been used** by thousands of readers since then.（自那以后图书馆已被成千上万的读者使用。）
6. These books **were written** by a famous writer.（这些书是一位著名作家写的。）

### 3. 高频易错（5 条）

1. ❌ The bridge is build last year. → ✅ The bridge **was built** last year.（过去用 was，且 build 过去分词是 built）
2. ❌ English is speak everywhere. → ✅ English is **spoken** everywhere.（过去分词 spoken，不是原形）
3. ❌ The room has been clean. → ✅ The room has been **cleaned**.（被动用过去分词 cleaned）
4. ❌ The work should finish today. → ✅ The work should **be** finished today.（情态动词后要有 be）
5. ❌ The library has built since then.（歧义）→ ✅ The library **has been built** since then.（图书馆是"被建"的，用被动）

### 4. 判诀

> **be + 过去分词定被动，时态穿在 be 身上；**
> **情态 + be done，完成 has been done；**
> **主语承受动作用被动，别忘过去分词用 done。**

## 二、当堂练习（2 : 6 : 2）

### 语法选择（2 题）

1. The new library ___ last year, and it ___ by many students since then.
   A. built; is used　B. was built; has been used　C. is built; used　D. has built; was used

2. — Many trees ___ every year in our city. — That's good for the air.
   A. plant　B. are planted　C. planted　D. are planting

### 选词填空（6 题，选项词：is / was / are / be / been / spoken / built / cleaned）

1. English ___ spoken in many countries.
2. The classroom ___ cleaned by the students yesterday.
3. A new school will ___ built near my home next year.
4. The fruit ___ taken home by Tom just now.
5. This song has ___ sung by the children many times.
6. The old bridge was ___ a hundred years ago.

### 造句（2 题）

1. 用"一般过去时被动（was/were + done）"造一句，表示"某物是过去被做的"。
2. 用"情态动词 + be + done"造一句，表示"某事应当/可以被动完成"。

---

## 三、答案与解析

**语法选择**：1. B（去年建成 → was built；since then 搭配现在完成 → has been used）；2. B（每年被种，一般现在被动 are planted）

**选词填空**：
1. is（一般现在被动 is spoken）
2. was（yesterday 过去 → was cleaned）
3. be（will be built，将来被动）
4. was（just now 过去 → was taken）
5. been（has been sung，现在完成被动）
6. built（was built，被动用过去分词）

**造句参考答案**：
1. The homework **was finished** by me last night.
2. The classroom **should be cleaned** every day.
