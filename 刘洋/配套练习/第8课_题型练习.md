# 第8课 · 题型练习：作文（书面表达）

> 学生：刘洋（八升九）｜ 本课语法：连词与状语从句｜ 限时建议：20 分钟（80 词左右）

**技巧提示——三段式模板**：① **开头**（引入话题或表明观点）；② **主体**（2–3 个点，用 First / Second / What's more 连接）；③ **结尾**（总结或表达愿望）。适当用连词（because / so / if / although）让逻辑清晰。

---

## 一、题目

**题目一（必做）**：暑假就要到了，请以 "My Summer Plan"（我的暑假计划）为题，写一篇 80 词左右的短文。内容要点：
1. 完成作业、读两本书；
2. 每天运动，保持健康；
3. 帮父母做家务。

**题目二（选做）**：请以 "My Favorite Teacher" 为题，写一篇 80 词左右的短文，介绍你最喜欢的老师（外貌、性格、喜欢他/她的原因）。

---

## 二、范文（题目一）

My Summer Plan

Summer vacation is coming. I have a good plan for it.

First, I will finish my homework carefully and read two English books. Second, I will play basketball with my friends every afternoon because it can keep me healthy. What's more, I will help my parents do some housework, such as cleaning the room and washing the dishes.

I think my summer holiday will be interesting and meaningful. I can't wait for it!

---

## 三、常用句型积累

| 位置 | 句型 |
|------|------|
| 开头 | ... is coming. / I have a good plan for ... / In my opinion, ... |
| 主体 | First, ... Second, ... What's more, ... / because ... / so that ... |
| 结尾 | I think ... will be ... / I hope ... / In a word, ... |

---

## 四、评分要点（自检用）

1. **要点齐全**：题目要求的 3 个要点是否都写到；
2. **语法正确**：时态（写计划多用 will / be going to）、主谓一致、三单；
3. **连贯**：用 First / Second / What's more / because 等连接词；
4. **字数**：80 词左右（太少扣分，太多不必要）。
