## 第一章：规范目标与定位

数据闭环定义：**纸笔学习 + HTML互动测试 + 浏览器本地保存 + 飞书汇总**。

现有教学方式继续保留：教师讲解、学生抄写重点、A4纸四列法刷词、"正"字计数、现场讲评纠错。

网页与飞书各自承担不同任务：

| 载体 | 职责 |
|---|---|
| 纸笔 | 学习、抄写、背诵、订正和长期保留 |
| HTML课件 | 互动测试、自动判分、保存过程和即时反馈 |
| 浏览器本地数据库 | 断网或接口异常时不丢失答题数据 |
| 飞书多维表格 | 集中查看、筛选、关联、统计和形成学生长期档案 |
| Agent | 读取规范、学生画像和飞书导出数据，生成后续复习与课程建议 |

**核心原则**：

> 飞书多维表格是教学数据的云端管理层，**不替代纸笔学习**，也不应成为课堂答题的唯一保存位置。

## 第二章：双层保存架构

推荐"本地保存 + 飞书同步"双层架构，避免逐题等待飞书接口受网络、权限或令牌影响。

```
学生提交答案
    ↓
先写入浏览器 IndexedDB
    ↓
页面立即反馈并进入下一题
    ↓
后台或课后同步到飞书多维表格
    ↓
同步成功后标记 synced
```

优点：
- 断网时仍能继续上课；
- 飞书接口异常时不丢答案；
- 学生不需要等待远程接口；
- 可以在课后批量同步，减少API调用次数。

**重要规则**：
- 第一次答案不得被后续修改覆盖；
- 每次重答新增记录；
- `event_id` 必须唯一；
- 导入时按 `event_id` 去重；
- 教师分析时同时查看第一次答案和最终答案。

**event_id 去重规则**：

```
event_id = student_id + session_id + question_id + attempt_no
```

示例：`stu_001_20260808AM_L03_VOC007_A1`

**M0—M4 掌握等级定义**：

| 等级 | 含义 |
|---|---|
| M0 | 未掌握（从未接触或反复错误） |
| M1 | 能识别（听力/阅读中辨认） |
| M2 | 能主动提取（主动想出该词） |
| M3 | 能拼写（正确拼写） |
| M4 | 能在语境中使用（正确运用于句篇） |

**初始状态与升级/降级规则（2026-08-02 补充，依据 C3 决议）**：

1. **初始状态 = `UNASSESSED`（未测）**：新知识点（新词 / 新语法点）第一次进入系统时，`当前掌握等级` 置为 **UNASSESSED**，不算 M0；完成一次有效测试后才进入 M0—M4。避免「没见过就算不会」的误判。
2. **升级触发**：
   - M0：识别题仍错误；
   - M1：能识别，但主动提取错误；
   - M2：能主动提取，但拼写或词形不稳；
   - M3：拼写、变形、搭配和句子正确；
   - M4：不同日期延迟复测后，仍能在新语境正确使用。
3. **M4 硬性阈值**（须同时满足）：
   - 已达到 M3；
   - 与上次测试间隔 ≥ 7 天；
   - 至少 2 个不同日期复测成功；
   - 全程无提示；
   - 至少 1 次主动提取或拼写；
   - 至少 1 次新语境应用。
4. **升降级由同步脚本初算，教师拥有最终覆盖权**（`教师调整` 字段：提高 / 降低 / 保持）。一道选择题答对不能直接记为 M3 或 M4。

## 第四章：同步方案（三阶段）

### 4.1 基础版：CSV人工导入（当前推荐起点）

流程：HTML逐题保存到IndexedDB → 课后导出CSV → 教师把CSV导入飞书多维表格 → 视图和仪表盘统计。

优点：开发难度最低、不需要飞书开放平台应用、不涉及密钥、适合先检验字段设计。
不足：每课需要人工导入、需要处理重复数据、不能自动实时同步。

### 4.2 推荐版：本地同步工具（正式使用）

```
HTML导出或写入本地JSON
    ↓
本地Node.js或Python同步脚本
    ↓
获取飞书tenant_access_token
    ↓
批量新增或更新多维表格记录
```

优点：学生端HTML中不保存 `app_secret`、可批量写入、教师点击一次即可同步、便于备份排错。

### 4.3 进阶版：云函数实时同步（后期）

```
HTML → HTTPS → 自有后端或云函数 → 飞书多维表格API
```

优点：可实时同步、能统一处理权限令牌和重复数据、学生可跨设备使用。

**安全红线**：

> 不得把飞书应用的 `app_secret` 直接写进发给学生使用的HTML或前端JavaScript中。前端代码可以被查看，密钥暴露后可能导致数据被越权读取或修改。

### 4.4 三种方案对比

| 方案 | 难度 | 适用阶段 | 推荐度 |
|---|---|---|---|
| 导出CSV后人工导入 | 低 | 原型验证 | 高 |
| 本地Python或Node同步器 | 中 | 三名学生稳定教学 | 最高 |
| 云函数或服务器实时同步 | 高 | 跨设备、多人协作 | 后期 |

当前建议：先完成CSV导入版，确认字段和统计真正有用；再开发本地同步器；不必立即做云端实时写入。

## 第五章：每课数据闭环

### 5.1 课前

从飞书"词汇掌握"表筛选：上一课错词、最近两课不稳定词、连续错误词、长期未复习词、本课教材目标词。形成本课20个七年级复习词和复习游戏。

### 5.2 课中

HTML记录：词汇识别、主动提取、拼写、语境使用、语法练习、阅读与听力、提示使用、修改答案、用时。

### 5.3 课末

自动生成：本课首次正确率、最终正确率、新掌握词、不稳定词、错词、下节课优先复习词、需要纸笔抄写订正的内容。

### 5.4 课后

教师完成：数据同步 → 查看飞书"本课总结"视图 → 补充课堂观察 → 确认下节课复习词 → 导出给Agent使用。

Agent不应直接读取所有历史原始记录后自行猜测，应优先读取：

## 第十三章：B类研究落地（2026-08-03 · B1/B2/B3 报告第一批）

### 13.1 M0—M4 操作口径（独立掌握判定）

- 掌握判断以 **`independent_correct`（无提示独立正确）** 为主；提示后答对、显示答案后答对**不得直接升级**。

- 升级口径：M1 能识别（四选一猜对一次不足）；M2 无提示主动提取正确（首字母提示后答对不足）；M3 无提示拼写/词形/搭配正确（抄写正确不足）；M4 **跨日期＋无提示＋新语境**正确（同一原句重复答对不足）。
- M4 阈值维持（≥7 天 / ≥2 不同日期 / 无提示 / ≥1 主动提取或拼写 / ≥1 新语境），标注为**项目操作阈值**。
- **禁止**：同一节课内连续答对多次直接判 M4；把 D1/D3/D7 写成唯一科学答案（间隔应动态调整）。

### 13.2 间隔复习参数（保守初始版）

首次学习 D0 → 课内复测（间隔 10—20 分钟）→ D1—D2 首次跨日主动提取 → D3—D5 拼写词形 → D7—D10 搭配句填 → D21—D28 新语境。

动态：首错 D1 再测；用时过长保持短间隔（用时仅辅助信号，不单独判未掌握）；连续两次跨日无提示正确则延长间隔（7→14→28 天）；延迟复测失败缩短间隔并回退生成要求。

实验版（弱词 D0/D1/D3/D7/D14；稳定词 D0/D3/D10/D21/D42）只用于收集真实数据，不进硬规范。

### 13.3 GM-V02 提示梯流程（正式版）

首次无提示提取 → 判断正误 → 一级提示（语义/语境）→ 二级提示（首字母＋长度）→ 三级提示（词块/部分形式）→ 必要时显示答案 → **遮盖后再次提取**（3—6 秒隐藏重拼）→ 迁移题 → 进入复习池。

- 首次错误**不得立即展示完整答案**；不允许无限猜测（选择题最多 1 次正式作答＋1 次带依据修正）。

- 事件最低字段：`event_id / question_id / knowledge_id / first_answer / final_answer / is_first_correct / is_final_correct / independent_correct / attempt_no / hint_used / max_hint_level / answer_revealed / response_time_ms / transfer_correct / sync_status`（详见 B 类报告 4.7）。

## 第十四章：D类研究落地（2026-08-04 · D1 教师周报 / D2 错题闭环 / D3 AI 建议边界）

> 依据《深度调研报告_D类_2026-08-04.md》。沿用现数据路径（IndexedDB 本地→CSV/JSON→飞书7表）；学生 HTML 保持离线、无后端、无密钥；不新增第二套数据系统；不改变飞书7表权威关系；不把技术行为数据包装成学习指标。

### 14.1 教师周报（D1）——最小有效指标

**周报首页只放 8 项以内核心指标**（每项都能触发教学行动）：

1. 首次独立正确率（首次无提示正确÷首次有效作答，不得用最终正确率代替）；
2. 跨日复测结果（不同日期、无提示、同知识点正确次数）；
3. 提示依赖（分四级：无提示／一级／二级／三级或答案展示，不只显示"提示次数"）；
4. 同知识点连续错误（同一 knowledge_id 连续两个有效任务均首次错误）；
5. 迁移题失败（原题反馈后正确但新语境/变式仍错误）；
6. 高置信错误（首次错误＋确定度较高，仅重点题采集）；
7. 最终确认错因（只显示 `error_code_final`；未确认显示"待确认"）；
8. 当前 M0—M4 及下次复习日期（只显示状态变化，如 M2→M3、M4复测失败）。

**周报结构**：一页四区域——本周最需处理3个问题／下节课3项动作（各配预计用时）／趋势（仅首次独立正确率、跨日复测成功数、高优先级知识点数、提示依赖变化）／教师确认（接受/编辑/暂不处理/错因需确认）。每周阅读和处理总时间 ≤30 分钟。

**核心口径**：
- 首次正确与最终正确分开；提示后正确≠无提示正确；均不得用最终正确率或提示后答对当独立掌握。
- 高置信错误必须安排跨日复测（不只改一次就结束）。
- 用时不用原始 `response_time_ms` 判掌握；只算个人同类题中位数＋异常倍数（<0.25×可能快速猜测、>2.5×可能犹豫/中断，项目实验参数）；用时不得单独触发降级，必须与正误、提示、题型联合判断。
- 技术排错指标（IndexedDB 写失败／CSV 导出失败／`sync_status=failed`／JS 异常／页面加载失败／音频失败／Canvas 未初始化／重复 event_id／异常长停留）只进**系统健康视图**，不进学生学习报告。
- 不建议采集：hover、滚动距离、动画次数、卡片移动轨迹、触屏坐标、鼠标移动、每个点击、登录次数、无任务边界总停留时间——立即停止扩张。

### 14.2 M14 错题闭环（D2）

**错误分五类**（错误阶段决定处理方式，不按"错题次数"排序）：

| 类 | 含义 | 处理方式 |
|---|---|---|
| E1 | 首次提取失败 | 立即提示→再提取→同课稍后复测→次日复习 |
| E2 | 形式/拼写错误 | 标错位置→修正→遮盖再写→1—3天后无提示复测（不只抄写） |
| E3 | 规则/概念错误 | 基础：正确示范→规则解释→半完成例题→独立题；中等/培优：找错→解释→修正→变式迁移 |
| E4 | 迁移失败 | 回到结构→更接近原题的变式→新语境→跨日再测（不重复原题） |
| E5 | 延迟复测失败 | 状态回退或标不稳定→缩短间隔→换题型→重建立独立提取 |

**优先级算法**（项目初始参数，保留分项构成，不存总分）：
`延迟复测失败+5 / 迁移失败+4 / 高置信+3 / 同知识点连续首次错误+3 / 显示答案后完成+2 / 二级或三级提示+2 / 首次错误但当场迁移正确+1 / 异常长用时+1`；分级 0—3低／4—7中／8+高。示例：`priority_score=8，原因=迁移失败4＋高置信3＋用时异常1`。

**高置信错误用"显式反驳"结构**：你的答案→为何看起来合理→与规则冲突→正确结构→立即重答→变式题→跨日复测。

**原题＋变式题**：原题仅用于展示首次答案、解释、当场确认、一次遮盖后重答；变式题用于检验真正掌握、跨日复测、M3—M4 升级。推荐比例：原题重答1次＋至少1道同构变式。

**复习排期**：高优先级 当场纠正→同课变式→D1→D3—D5→D7—D14；中优先级 当场纠正→D2—D3→D7—D10；低优先级 当场确认→下一正常复习周期。跨日失败重新进入高优先级。

**退出错题池条件**（须同时满足）：最近一次无提示正确／至少一次同构变式正确／至少一次跨日期复测正确／没有答案展示／最近两次无连续同类错误／当前等级达目标／教师未手动锁定。M4 知识点保留低频抽查，不从长期数据删除。

**M4 延迟复测失败**：保留历史 M4 证据，当前状态标 `M4_REVIEW_REQUIRED`，是否正式降 M3 由本规范掌握等级规则决定。

**教师覆盖机制**：可提高/降低优先级、修改错因、推迟/提前复习、标记设备问题、标记题目有误、标记数据无效；覆盖记 `override_by/override_at/override_reason`，不得删除原始系统判断。

### 14.3 AI 教学建议边界（D3）

**AI 最适合生成**：数据明确、范围很小的建议；每条必须附数据来源（涉及题目/知识点/日期/首次答案/提示使用/迁移结果）；教师可立即编辑（接受/修改题量/修改时间/换组件/推迟/拒绝）；明确节省的工作（自动整理高优先知识点/生成复习池/起草周报/推荐组件/备选题型）。

**AI 建议卡片格式**：建议→触发数据→涉及知识点→建议动作→预计用时→建议理由→数据充分性（低/中/高）→需教师确认（是/否）。

**数据充分性**（不用模糊"AI置信度"）：低=只有1次作答或只出现于同一道题；中=至少2道不同题或至少2个有效时间点；高=不同题型＋不同日期＋错误模式一致。以上为项目操作分级，非统计学概率。

**每周建议上限**：本周发现3条＋下节课建议3条＋需教师确认1—2条；每条正文60—120中文字，再提供"展开证据"。

**AI 不得自动完成**：判断学生"粗心"/态度、贴能力标签、自动修改长期课程规划、自动修改锁定 `exam_spec`、自动修改 M0—M4 最终状态、自动给开放写作定终评、自动删除错题、自动降低学生层级、自动向学生或家长发送报告、自动替教师决定是否返讲。

**接受/编辑/拒绝流程**：接受→记 `recommendation_status=accepted` 并加入下一课设计卡；编辑→保存 `original_recommendation`＋`teacher_revision`（AI 可从修改总结规则，但不得改历史）；拒绝→教师选理由（数据不足/题目问题/时间不足/已口头处理/学生状态特殊/建议不适合/其他），拒绝理由用于改进规则，不评价教师。

**生成位置**：学生 HTML 离线答题→IndexedDB→CSV/JSON→飞书7表或教师端本地工具→生成建议草稿→教师审核→写入下一课设计卡。AI 只处理教师端已导出字段，不嵌入学生 HTML、不放密钥。

**隐私与最少数据**：AI 建议输入优先用 `student_id / knowledge_id / 题型 / 首次正误 / 提示等级 / 迁移结果 / 延迟复测 / 教师确认错因`；原则上不需要学生完整姓名、住址、联系方式、学校班级敏感信息、无关聊天记录、完整录音、入学分数、家庭信息。

### 14.4 落地清单（对应 D 类"现在就改"）

## 第十五章：间隔复习 A/B 实验方案（试点 · B类收口 2026-08-04）

> 来源：《任务二：间隔复习 A/B 对照实验方案》（ChatGPT 交付，Claude 审核通过，2026-08-04）。
> 实验性质：项目内可逆性试点，不修改正式保守操作口径。
> 核心原则：同一学生内按词项随机分组，使用共同无提示探测题比较保持效果。

### 15.1 实验目标

比较两套已定复习参数在以下方面的实际表现：

1. 跨日期无提示主动提取；
2. 无提示拼写、词形或搭配；
3. 新语境迁移；
4. 单个词达到稳定掌握所需的复习次数；
5. 学生和教师的复习负担。

实验不回答"哪套日程是所有学生唯一最佳"，只判断在本项目学生、词项和课时条件下，实验版是否能在不降低保持率的前提下减少复习次数，或是否对特定弱词/稳定词更合适。

### 15.2 两套干预

**A组：保守版**

| 阶段 | 时间窗 | 主要任务 |
|---|---|---|
| 首学 | D0 | 建立词形—词义—语境联系 |
| 课内复测 | D0，间隔10—20分钟 | 无提示主动提取 |
| 第一次跨日 | D1—D2 | 主动提取 |
| 第二次 | D3—D5 | 拼写或词形 |
| 第三次 | D7—D10 | 搭配或句中填空 |
| 第四次 | D21—D28 | 新语境迁移 |

动态规则：首错D1再测；用时过长只作为辅助信号；连续两次跨日无提示正确可按7→14→28天延长；延迟失败缩短间隔并回退生成要求。

**B组：实验版**

| 词项状态 | 日程 |
|---|---|
| 弱词 | D0 / D1 / D3 / D7 / D14 |
| 稳定词 | D0 / D3 / D10 / D21 / D42 |

弱词和稳定词的初始分类只用于安排，不作为永久能力标签。任何B组词若出现首次错误、高级提示、答案展示、高置信错误或共同探测失败，可立即获得与A组同等或更密集的补救复习。

### 15.3 分组方案

**首选：同一学生内、词项级随机分组**

每名学生同时学习A组词和B组词——同一学生内按匹配对随机分配，下一课反向平衡。

**词项匹配与随机化**

在D0正式学习前先做一次短预检。只纳入：未达到M2的目标词、课程确实需要学习的词、可在两组使用相同题型和语境难度的词。

按以下特征形成匹配对：预检状态、词长和音节数、词性、具体词或抽象词、规则或不规则拼写、本课出现频率和教学重要度。

**现实样本量**

| 有效规模 | 定位 |
|---|---|
| 每名学生每组少于15词 | 可行性测试，只检查流程和数据质量 |
| 每名学生每组20—30词 | 项目级初步比较 |
| 3名学生累计每组60词以上 | 可做分学生、分词项的描述性和自助法区间分析 |
| 更大规模、多班级 | 才适合正式推断和预注册统计检验 |

### 15.4 共同探测设计

| 共同探测 | 时间窗 | 题型 | 用途 |
|---|---|---|---|
| P1 | D7±1 | 无提示主动提取 | 早期保持 |
| P2 | D14±2 | 无提示拼写或词形 | 中期保持 |
| P3 | D28±3 | 新语境无提示使用 | 主要结局 |
| P4 | D42±4 | 新语境或混合延迟复测 | 长期观察 |

共同探测规则：不显示选项、首字母、词长或答案；首次答案提交后才能反馈；探测题语境对A/B两组等难；原题不得直接重复；探测失败立即进入补救，不为了"实验纯度"延迟帮助。

### 15.5 干预差异表

| 项目 | A保守版 | B实验版 | 保持一致的部分 |
|---|---|---|---|
| D0课内复测 | 10—20分钟后 | 10—20分钟后 | 无提示首次提取 |
| 首次跨日 | D1—D2 | 弱词D1；稳定词D3 | 失败立即反馈 |
| 中期复习 | D3—D5、D7—D10 | 弱词D3/D7；稳定词D10 | 题型按M级递进 |
| 后期复习 | D21—D28 | 弱词D14；稳定词D21/D42 | 共同P3/P4探测 |
| 失败处理 | 缩短间隔 | 立即切换为安全补救，可采用A组密度 | 不允许学生因分组少获帮助 |
| M4判定 | 现有阈值 | 同一阈值 | ≥7天、≥2日期、无提示、主动提取/拼写、新语境 |

### 15.7 主要指标与决策阈值

**主要指标**：P3（D28±3）新语境无提示独立正确率。

**次要指标**：P1主动提取独立正确率；P2无提示拼写/词形正确率；P4长期保持率；达到M4阈值的词项比例；每个稳定词所需复习事件数；提示依赖率；答案展示率；高置信错误在下一次跨日探测中的修正率。

**不作为主要成功指标**：最终正确率、点击数、页面停留、游戏分数、连胜、单纯作答速度。这些指标容易被提示、重试、离座或界面操作影响。

**项目决策规则**（项目决策阈值，非科学通用标准）：

- **B版可扩大试点**：同时满足 B组P3独立迁移正确率不低于A组5个百分点以上；B组平均复习事件数比A组少至少15%或教师复习时间明显下降；B组答案展示率和高置信错误回归率未恶化；至少2名学生方向一致，没有学生明显受损。
- **两套并存并按词项分流**：若弱词在A更好、稳定词在B更省时，则保留弱词走保守密集路径、稳定词走实验扩展路径。
- **暂不采用B版**：若B组在两个连续共同探测中独立正确率低于A组10个百分点以上，且不能由词项难度或缺勤解释，则暂停新词进入B组，现有B词立即转安全补救。

### 15.8 混淆控制

- **提示依赖**：统一四档（0=无提示，1=语义/语境，2=首字母/长度，3=词形/词块，答案展示=revealed）；提示后答对不得记为`independent_correct=true`。
- **跨日期**：以设备记录的实际时间戳判断；同一自然日内多次作答只算同日证据。
- **新语境**：句子或任务不是原题复制；目标词周围搭配、主语、时态或情境至少改变一项；不能只换题号或选项顺序。
- **题型和内容难度**：A/B共同探测使用相同题型比例、相近句长和相同评分规则。
- **教师影响**：两组使用相同反馈措辞和提示梯；教师不能因知道分组而给某组更多口头线索；发生额外讲解时记录`teacher_intervention=true`。
- **词项污染**：若A词和B词为近义、反义或同一词族，尽量不要放在同一匹配对。

### 15.9 红线自查

- [x] 不公开A/B成绩或排名；
- [x] 不使用羞辱、巨大红叉或失败清零；
- [x] 提示按等级提供，不在首次作答前泄露答案；
- [x] B组失败立即获得A组密度或更强补救；
- [x] 积分和游戏分数不进入长期能力标签；
- [x] 不新增第二套数据系统；
- [x] 同课内连续答对不直接判M4；
- [x] 最终正确率不作为主要结论；
- [x] 学生姓名不出现在公开报告中；
- [x] 教师可随时人工覆盖分组和复习日期。

### 15.10 终止条件

**安全暂停**（任一情况即暂停该学生新词进入B组）：
1. B组在连续两个共同探测中比A组低至少10个百分点；
2. B组连续出现3个以上延迟失败词，且A组同难度匹配词稳定；
3. 学生明确表示复习间隔导致持续遗忘或挫败；
4. 数据丢失、分组错误或提示泄露使比较失真；
5. 教师判断某重点词不能承担实验风险。

**全实验终止**：有效词项未达到每组15个且无法继续；超过20%的事件缺少关键字段；A/B实际间隔重叠严重无法区分干预；学生出勤或课程调整使P3共同探测无法完成；教师工作量超过可接受范围且无法通过自动化降低。
