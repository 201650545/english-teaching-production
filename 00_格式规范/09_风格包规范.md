# 09 · 课件风格包规范（Style Pack · 2026-08-06 V2.0）

> **目的**：解决课件视觉趋同。让执行 Agent **按知识点自主选风格**，验证器**放开审美表达、守住工程/交互/数据底线**。
> **真源**：本文件为课件视觉风格唯一真源，取代旧"默认红金/单模板"约定。
> **V2.0 升级**（依据 GPT 研究汇报 2026-08-06）：风格包从「主色+封面+组件建议」升格为**8 个风格变量 × 3 个独立配置轴**；新增机器可读 `style_manifest` 风格合同；验证器边界一句话化。10 套风格名**保留作沟通标签**，不再作为底层架构。

---

## 一、核心原则

1. **风格由知识点决定**，不由模板决定。每课开工前，Agent 按「结构风格族 × 课型 × 学生档位」三轴选型，在课程设计卡 + `style_manifest` 中声明。
2. **验证器边界（一句话）**：
   > **验证器不审判风格是否传统、对称或符合模板；验证器只阻止不可读、不可操作、交互造假、数据缺失和声明欺骗。**
   - **放开**：封面布局/主色/组件形态/页面版式/字体/动效——由风格变量决定，视觉 ERROR（WARN/CSS-I001/类名偏离）不作为交付否决项，创新偏离书面说明即放行。
   - **守住（硬规则，不可放开）**：体积 ≥150KB、页数 40-45、div 平衡、JS 语法、每题唯一 data-correct、答案分布 ≤40%、`CW-INTERACTION-CONTRACT:1`、题容器元数据、IndexedDB 数据采集、交互真实（VIS-613 反换皮）、**可读可操作（对比度/可点区/键盘替代）**。
3. **风格不重样**：同学生相邻 3 课不同风格族；**仅换色不算有效创新**（见 §四）。

---

## 二、三轴正交配置（核心）

风格 = **结构风格族（观感）× 课型配置（节奏）× 学生档位配置（支架）**，三者独立，不互相绑架。

### 2.1 第一轴：结构风格族（决定主要观感）

10 套风格名保留，但每套必须声明**不同的底层变量组合**，不能只换色：

| 风格族 | 核心变量倾向（示例） | 适用主题 |
|---|---|---|
| S01 博物馆/探索 | 版式=探索地图型；卡片=展柜；媒体=文物轮廓 | 历史文化 |
| S02 交通/出行 | 版式=路线图型；组件=站牌/路标；媒体=地标 PIN | 交通方位 |
| S03 侦探/推理 | 版式=档案推理型；组件=线索卡/证据框；媒体=照片+印章 | 疑问句、推理阅读 |
| S04 自然/森林 | 版式=自然叙事型；组件=叶片卡；媒体=手绘动线 | 季节天气 |
| S05 海洋/星空 | 版式=中心舞台型；组件=气泡卡；媒体=插画 | 海洋宇宙 |
| S06 校园/活力 | 版式=卡片矩阵型；组件=便签/课表；媒体=文具拼贴 | 校园生活 |
| S07 杂志/报纸 | 版式=编辑杂志型；组件=引语框/栏目标签；媒体=照片配文 | 时文阅读 |
| S08 游戏/闯关 | 版式=游戏任务型；组件=关卡门/进度条；媒体=游戏图标 | 复习闯关、检测 |
| S09 手绘/涂鸦 | 版式=手绘笔记型；组件=涂鸦框；媒体=手绘箭头 | 写作示范、低龄 |
| S10 极简/商务 | 版式=极简测评型；组件=细线卡；媒体=几何图形 | 考点清单、讲评 |

### 2.2 第二轴：课型配置（决定教学节奏，独立于风格族）

| 课型 | 页面节奏 | 每页内容量 | 提示强度 | 反馈时机 |
|---|---|---|---|---|
| TEACH 授课 | 讲解→示例→操作→反馈 | 中 | 明确 | 即时 |
| PRACTICE 练习 | 操作密集 | 中高 | 关键节点 | 即时 |
| REVIEW 复习 | 快速轮换 | 高 | 按需 | 即时 |
| ASSESS 检测 | 正式、少装饰 | 高 | 无提示 | 提交后 |

> 复习/检测课**不强锁** S08/S10，由课型配置控制节奏；风格族仍按主题选。

### 2.3 第三轴：学生档位配置（决定支架，独立于风格美术）

| 档位 | 支架 | 密度 | 提示 | 自主探索 |
|---|---|---|---|---|
| FOUNDATION 基础 | 高 | 低至中 | 明确、连续 | 较低 |
| STANDARD 中等 | 中 | 中 | 关键节点 | 中 |
| ADVANCED 培优 | 低 | 中至高 | 按需 | 高 |

> **关键约束**：档位控制**支架/提示/密度**，**不控制"幼不幼稚"**。基础档可适度游戏化（闯关/奖励感强），培优档可更克制专业；但三档都禁止把档位标签化作"幼稚/高端"的刻板审美，**不得**因培优就做暗色/低龄、因基础就做卡通化堆砌。

## 三、8 个一级风格变量（最小但有效）

每套风格 = 以下 8 个一级变量的组合。**只改颜色或封面 = 换皮，不算有效风格**。

| # | 一级变量 | 控制内容 | 是否必须显著区分 |
|---|---|---|---|
| 1 | `layout_archetype` | 网格、重心、分栏、标题位置（单栏/分栏/中心舞台/卡片矩阵/时间轴/地图/编辑部式） | 是 |
| 2 | `density_level` | 留白、内容块数、文字占比（低/中/高） | 是 |
| 3 | `type_profile` | 字体、字号比例、字重、标题构成（杂志大标题/档案标签/手绘标题/极简少层级） | 是 |
| 4 | `surface_profile` | 卡片、边框、圆角、阴影、纹理（实底/描边/纸张/票据/终端/便签） | 是 |
| 5 | `palette_profile` | 背景、主色、强调色、状态色 | 是 |
| 6 | `media_language` | 图标（线性/实心/手绘/印章）、插画（扁平/拼贴/照片）、裁切比例 | 是 |
| 7 | `motion_profile` | 时长、缓动、进入/反馈动画 | 可弱化 |
| 8 | `feedback_profile` | 可操作提示、正误/完成反馈（抖动/描边/盖章/变色） | 是 |

**防趋同硬检查**：风格 ID 不同但 8 变量中仅 `palette_profile` 不同 → 判定**无效换包**；必须至少 `layout_archetype` + `density_level` + `type_profile` + `surface_profile` 中的多个随风格改变。

## 四、机器可读风格合同 `style_manifest`（STYLE-001~005）

每课课件必须包含以下合同，供验证器与人工核验"声明 vs 实际"：

```json
{
  "course_id": "DXH_L09",
  "student_level": "STANDARD",
  "lesson_mode": "TEACH",
  "style_family": "S01",
  "style_vars": {
    "layout_archetype": "explore-map",
    "density_level": "medium",
    "type_profile": "bold-sans-editorial",
    "surface_profile": "exhibit-card",
    "palette_profile": "amber-navy",
    "media_language": "artifact-line",
    "motion_profile": "slide-and-reveal",
    "feedback_profile": "stamp-confirm"
  },
  "difference_from_recent_lessons": [
    "使用探索地图版式，非卡片矩阵",
    "采用展馆卡片+琥珀藏蓝，非薄荷绿",
    "反馈用盖章而非按钮变色"
  ]
}
```

| 规则 | 内容 |
|---|---|
| **STYLE-001** | 每课必须含 `style_manifest`；风格族/课型/档位/8 变量不得缺失 |
| **STYLE-002** | 禁止纯换色：与同学生最近 2 课相比仅 `palette_profile` 变 → 判"纯换皮" |
| **STYLE-003** | 验证器以**浏览器计算样式/实际 DOM/截图特征**为准，不以源码注释/元数据为准 |
| **STYLE-004** | 允许受控创新：Agent 可经 `custom_overrides` 加新变体，须声明覆盖字段/适用页/教学理由，不得覆盖可访问性与交互合同 |
| **STYLE-005** | 同学生相邻 3 课不只查风格 ID，还查结构/组件/截图差异 |

**声明不一致级别**：声明字段缺失/非法 → ERROR；声明 vs 计算样式不符 → ERROR；仅局部页偏离 → WARNING；有合理 overrides 且不破坏底线 → PASS。

## 五、验证器口径（V2.0 细化）

| 层 | 内容 | 口径 |
|---|---|---|
| 工程硬规则 | 体积/页数/div/JS/data-correct/答案分布/合同/数据采集/交互真实 | **ERROR=0 必须** |
| 可读可操作 | 对比度 ≥4.5:1（正文）/≥3:1（大文字/控件）、可点区 ≥24px、键盘替代、拖拽有点击替代 | **待实现为硬检查**（见 §六） |
| 视觉软检查 | 字号/颜色数/圆角/CSS 杂项 WARN | 记录即可，不否决 |
| 风格合同 | style_manifest 完整性 + 声明一致性 | 校验器查声明缺失；计算样式核验待实现 |
| 封面/版式 | cover-* 顺序/order/布局 | 由风格变量决定，不按单模板校验 |

- verify_v2 / verify_interaction_v1 的**视觉 ERROR**：若来自"风格创新打破默认类名"，书面说明即放行；若来自交互/契约/数据/可读可操作硬伤，必须修。
- Agent 回报必须声明：风格族/课型/档位/主色/版式创新点 + `style_manifest`。

## 附录 A · 新课自动选型规则（V2.1 依据 GPT 研究 2026-08-06 落规范）

> **原则**：**选择器负责防止趋同，验证器负责阻止不可读/不可操作/交互造假/数据失真，教师负责判断风格是否适合课堂。** 新课 L27+ 必须用选型器，Agent 不得自行从 S01-S10 中任意挑选。

### A1 连续三课定义（务必精确定义）

> 对同一学生，任意连续三课的 `style_family` 必须互不相同。

即当前课只需检查**前两课**（前一课、前两课），避免与"最近三课不重复"实现错位：
```python
current_style not in {style_of_previous_lesson, style_of_two_lessons_before}
```

### A2 档位 × 风格变量影响矩阵（档位控支架不控审美）

符号：`0`=档位不得改变；`1`=只允许教学子参数；`2`=档位可直接影响。

| 一级变量 | 档位影响 | 允许 | 禁止 |
|---|---|---|---|
| `layout_archetype` | 0 | 无 | 因基础档改成卡通布局 |
| `density_level` | 2 | 内容块数/留白/同时呈现量 | 删除必学内容 |
| `type_profile` | 1 | 字号/行高/标题层级清晰度 | 改变整体字体审美族 |
| `surface_profile` | 0 | 无 | 基础档强制大圆角 |
| `palette_profile` | 0 | 无 | 基础档强制高饱和色 |
| `media_language` | 1 | 图示数量/解释标注/字幕 | 改变照片/手绘审美语言 |
| `motion_profile` | 0 | 主要由课型+可访问性控制 | 基础档强制更多动画 |
| `feedback_profile` | 2 | 提示/重试/反馈详细度 | 改变判题正确性 |

- **基础档**：density=low；即时反馈、可重试、首错出提示、步骤明确；字号较大、行高较宽、关键图带标签。
- **中等档**：density=medium；关键步骤提示、1-2 次重试、错误反馈说明原因。
- **培优档**：density=medium/high；较少过程提示、延迟提示、强调解释与迁移；**不得**降对比度/缩控件/去键盘操作。
- 培优档可减支架但不可破可读可操作底线；基础档不强制卡通/高饱和。

### A3 课型兼容（课型调密度/反馈/动效，不决定审美）

| 课型 | 优先风格族 | 变量倾向 |
|---|---|---|
| TEACH 授课 | 故事/编辑/探索/档案 | 中密度、分段呈现、解释型反馈 |
| PRACTICE 练习 | 模块/任务/档案/路线 | 中密度、即时反馈、清晰进度 |
| REVIEW 复习 | 任务/地图/编辑总结 | 中至高密度、模块汇总 |
| ASSESS 检测 | 极简/稳定模块/档案 | 低动效、弱提示、稳定导航 |

复习/检测**不强锁** S08/S10。

### A4 变量合并顺序（低层不可被覆盖）

```text
style family defaults → topic skin → lesson mode overlay
→ student level overlay（受 A2 白名单限制）→ 可访问性/交互不可变规则
```
最后一层不可被任何风格覆盖。

### A5 选型流程（风格选择器，Agent 不可自行挑选）

```text
输入是否完整？否→ERROR 不允许猜测
→ 过滤不支持所需交互的风格族
→ 按课型过滤/调整兼容度
→ 移除前两课已用风格族（A1 硬约束）
→ 按主题/课型/组件适配 + 历史均衡评分
→ 最少使用 + 稳定哈希打破同分
→ 加载默认变量 → 叠加 topic skin → 叠加 lesson mode
→ 仅白名单字段叠加 student level（A2）
→ 应用可访问性不可变规则
→ 输出 style_manifest + 选择记录
```

评分参考：`0.35 语义 + 0.25 课型 + 0.15 交互 + 0.10 资产可行性 + 0.10 使用均衡 + 0.05 受控新颖`（初始值，教师约 20 课评价后校准）。

### A6 库存不足时放宽顺序（禁止第一步退回默认模板）

1. 扩大同课型兼容风格族 → 2. 允许同主题非典型但教学兼容风格 → 3. 复用较早风格族但**改变结构子型 + 至少三个外观轴** → 4. 记录 override_reason。

复用同一 `style_family` 时，以下五轴至少三项不同且必含版式子型或组件形态：`layout subtype / type profile / surface profile / media language / feedback-motion`。**只换 palette_profile 不算有效复用。**

### A7 工具落地（四层）

1. **09 规范附录**（本附录）：人类可读制度来源；
2. **`style_catalog.json`**：机器可读目录（每风格族：name/supported_modes/semantic_tags/interaction_fit/defaults/mode_overlays，令牌组织可借鉴 DTCG）；
3. **`style_picker.py`**：唯一权威选择器（读课程元数据→扫历史 manifest→计算候选→去重→输出 manifest+备选+理由+picker_version，支持 `--dry-run`）；
4. **命令文件**：只调用 `python style_picker.py --student X --lesson L27 --mode TEACH --topic ... --level FOUNDATION`，禁止在命令里复制选型规则表。

### A8 STYLE-005 验证口径（相邻三课重复）

- **选型器中**：硬约束（生成前强制，从源头防趋同）；
- **交付验证器中**：**WARN**（STYLE-005 是治理规则，不是可读/可操作/交互/数据底线，不因风格重复阻止功能正常课件交付）。
- 验证器输出：`STYLE-005 WARN 当前 S03 前一课 S03 建议重新运行 style_picker 或提交重复理由`。
