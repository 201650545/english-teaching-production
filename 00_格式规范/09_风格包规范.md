# 09 · 课件风格包规范（Style Pack · 2026-08-06 V1.0）

> **目的**：解决课件视觉趋同（千篇一律、橙红/蓝绿统一模板）问题。让执行 Agent **按知识点自主选风格**，验证器**硬规则保留、视觉层放开**。
> **真源**：本文件为课件视觉风格唯一真源，取代旧"默认红金/单模板"约定（见 §4）。

---

## 一、核心原则

1. **风格由知识点决定**，不由模板决定。每课开工前，Agent 先读课程概要，按「主题语义场 + 课型 + 学生档位」从风格包中选一套（或组合），在课程设计卡中声明。
2. **验证器守住工程底线，放开审美表达**：
   - **硬规则**（不可放开）：体积 ≥150KB、页数 40-45、div 开合平衡、JS 语法、每题唯一 data-correct、答案分布 ≤40%、`CW-INTERACTION-CONTRACT:1`、题容器元数据、IndexedDB 数据采集、交互真实（VIS-613 反换皮）。
   - **视觉层放开**（不再死磕单一模板）：封面布局/主色/组件形态/页面版式由风格包决定，verify_v2 的视觉软检查（WARN）与 CSS-I001 类标记缺失**不作为交付否决项**；创新导致的结构性视觉偏离，回报中书面说明理由即放行。
3. **风格不重样**：同一学生相邻 3 课避免用同一风格包；全课不出现"默认红金全套"。

---

## 三、验证器口径（与硬规则分离）

| 层 | 内容 | 口径 |
|---|---|---|
| 工程硬规则 | 体积/页数/div/JS/data-correct/答案分布/合同/数据采集/交互真实 | **ERROR=0 必须** |
| 视觉软检查 | 字号/颜色数/圆角/CSS 杂项 WARN | 记录即可，**不否决** |
| 视觉合同标记 | CW-VISUAL-CONTRACT / CSS_EXTRA 标记 | 创新结构可缺，书面说明即放行 |
| 封面/版式 | cover-* 类名顺序、order 布局 | 由风格包决定，**不按单模板校验** |

- verify_v2 / verify_interaction_v1 的**视觉 ERROR**：若来自"风格包创新打破默认类名"，回报附书面理由即放行；若来自**交互/契约/数据**硬伤，必须修。
- Agent 在回报中必须声明：本课用哪个风格包、主色值、封面/版式创新点。
