## 三、核心铁律

1. **绝对禁止学生姓名**：成品文件中不得出现任何学生姓名
2. **废除 PPTX**：课件只保留纯单文件 HTML 网页 PPT
3. **词汇零重复**：跨课时 Set 集合自动防重，新词 100% 零重复
4. **阅读 3 选项**：阅读理解和完形填空均为 3 选项（A/B/C）
5. **阅读三篇结构**：A 篇应用文 → B 篇记叙文 → C 篇说明文/科普
6. **仅亮色主题**：红金主题，不生成暗色主题
7. **全中文命名**：所有文件全中文命名
8. **生词比例 15%-20%**：每道含短文题目允许 15%-20% 生词
9. **HTML 文件 ≥ 150KB**：课件 HTML 文件大小强制 150KB 以上（verify_v2 硬规则 ≥153600B）
10. **课件 40-45 页 + 21:9 比例**：总页数 40-45 页（page-id 契约硬区间），页面宽高比 21:9
11. **左右半屏翻页**：点击右半屏下一页/左半屏上一页；答案点击优先不触发翻页
12. **整页滚动机制**：整个 `.page` 上下滚动，切页重置滚动位置
13. **创意交互点至少 6 个**：跨 3+ 环节，禁止跨课复用，在契约 `4_素材清单.md` 中声明
14. **Web Audio 声效必须**：必须实现 `playCorrect()`, `playError()`, `playPageTurn()`
15. **练习卷四部分 100 分**：阅读40 + 语言运用25（完形15+选词10）+ 综合技能25（简答10+写作15）+ 语法巩固10 = 56题
16. **L05 紧凑排版**：Times New Roman 10.5pt、黑体标题 16pt、选项同排、US Letter
17. **过去时禁令**：L14-L21 练习卷不得出现过去时内容
18. **课件答案隐藏**：答案区域 `display:none`，点击后才显示
19. **正文无冗余环节标签**：正文内不得出现 `section-badge` 标签
20. **复习课六段式**（仅 L7/L16/L21）：不生成 DOCX 练习卷，练习融入课件
21. **词汇复习游戏三层体系**：课内2页（1页Tier1词级+1页Tier2/3句篇级）+跨课1页（Tier2/3，复习上一课词汇）+Mini Task（④随堂演练P1）+Exit Ticket（⑧课堂总结）；29种游戏轮换，相邻5课不复用；详见 `01_课件格式规范.md` §3.7 和 `07_词汇教学与复习游戏规范.md`
22. **数据采集与安全**：课件支持 IndexedDB 本地保存 + 飞书云同步（7表结构、event_id 去重）；第一次答案不覆盖、重答新增记录；JSON/CSV 导出；同步状态显示。**严禁在 HTML 中硬编码飞书 app_secret 或 API 密钥**。详见 `08_学习数据闭环规范.md`

## 四、快捷启动 Prompt

```
你是一个英语教学资源生产 Agent。项目根目录为 D:\英语教学\。

【你的任务】根据指定的内容蓝图，生成该课的完整资源包（契约6文件 + HTML课件 + DOCX练习卷）。

【生产前必读】
1. 读取格式规范：D:\英语教学\00_格式规范\（全部文件）
2. 读取对应学生的内容蓝图：D:\英语教学\{学生名}\内容蓝图\
3. 读取分级参数：D:\英语教学\00_格式规范\04_分级差异化参数表.md

【学生概况】
- XYJ（基础·七年级）：40课时，360词，54语法考点
- DXH（中等·初二）：50课时，1000词，66语法考点
- LMX（培优·七升八）：25课时，能力进阶，技能导向

【核心要求】
- 第一步：先按 课程设计卡_模板.md 填写本课设计卡（1核心语法+2考点、CORE/EXTEND/HOME、Exit Ticket、数据字段），再据此生成

- 词汇复习游戏：课内2页（Tier1+Tier2/3）+跨课1页（Tier2/3）+Mini Task+Exit Ticket，29种游戏轮换不复用

- 练习：四部分100分=56题，L05紧凑排版
- 命名：第XX课时_课件_档位.html / 第XX课时_配套练习_档位.docx（档位=基础/中等/培优）

【数据采集】课件须支持 IndexedDB 本地保存 + 飞书同步（event_id 去重），详见 08_学习数据闭环规范.md

【输出位置】D:\英语教学\{学生名}\第XX课\
【完成后】执行37项自检清单（见 00_全局约束与红线.md 第四章）

请开始生产{学生名}第XX课资源包。
```
