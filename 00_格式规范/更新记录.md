# 2026-07-31 · 答题反馈视觉与解析规范（新增）

## 一、新增 `01_课件格式规范.md` §3.3.1 答题反馈视觉与解析规范

**硬性要求**：所有课件练习题必须实现"答对显绿、答错显红、每题带解析"完整闭环。

1. **答对 → 绿色**：选项/输入区变绿（`--success`），播放 `playCorrect()`。
2. **答错 → 红色**：选项/输入区变红（`--error`），播放 `playError()`，并**高亮正确答案**。
3. **每题必带解析**：答题区下方有解析（`.quiz-explanation` / `.fill-explanation`）：
   - 答对：显示考点/规律/为什么对。
   - 答错：显示"正确答案：xxx" + 简要解析。
   - 解析须有教学价值，不得只写"答案错了"。
4. **交互优先**：答题元素 `event.stopPropagation()`，不触发翻页。
5. **统一状态类**：`.correct`（绿）/ `.wrong`（红）/ `.disabled`（禁用）；填空题用 `.fill-input-box` + 对错类。
6. **禁止只判分不给解析**：仅有对错变色而无解析视为不合格。

## 二、`00_全局约束与红线.md` 自检清单扩展：36 → 37 项

新增第 37 项：**校验答题反馈与解析**——所有练习题"答对显绿、答错显红、每题带解析"；答错须高亮正确答案；任何题目仅有对错变色而无解析视为不合格。详见 `01_课件格式规范.md` §3.3.1。
