## 二、核心规则

- **格式规范**：三人共用 `00_格式规范\`，课件和练习的排版格式完全一致
- **教学内容**：各学生独立，存放在各自文件夹的 `内容蓝图\` 中
- **课时产出**：直接放在学生文件夹下的 `第N课\` 中，不再按级别分子目录
- **学生档案**：每个学生文件夹下有一个 `学生档案.md`
- **等级体系**：基础（许颖嘉）/ 中等（邓兴华）/ 培优（李民宪）三级，难度参数不同，格式完全一致

## 四、课件硬性指标（三级统一）

| 指标 | 标准 |
|------|------|
| 文件大小 | HTML ≥ 150KB（V2 铁律，verify_v2 硬规则 ≥153600B） |
| 创意交互点 | 至少 6 个真实教学交互，跨 3+ 环节（质量门槛见下） |
| 翻页方式 | 左半屏上一页 / 右半屏下一页 |
| 答案交互 | 点击显示答案时 stopPropagation，不触发翻页 |
| 页面比例 | 21:9 |
| 总页数 | 40-45 页（新 page-id 契约；旧 slide 契约 25-30 已冻结） |
| 主题 | 红金亮色主题 |
| 声效 | playCorrect / playError / playPageTurn |

### 创意交互点质量门槛（2026-08-02 补充，依据 C3 决议）

「至少 6 个」必须同时满足以下条件才计入数量，**禁止为凑数硬塞装饰动画**：

1. 关联明确知识点（词汇 / 语法 / 阅读 / 拼读等）；
2. 学生必须进行真实认知操作（选择 / 提取 / 纠错 / 排序 / 配对等），不能纯观看；
3. 有正确与错误反馈（含错因提示 / 解析）；
4. 能记录至少 1 个有效事件（答对 / 答错 / 用时 / 重答 / 提示等）；
5. 分布在至少 3 个不同教学环节；
6. 不是同一组件换颜色重复计数。

> 口径：**至少 6 个真实教学交互、跨 3 个以上环节**；装饰动画 / 纯视觉特效不计入。每页另有 `PAGE_META` 运行层元数据（priority: CORE/EXTEND/HOME + estimated_minutes），供课堂按时长选做，不改变 page-id 契约。

### 课件结构契约（2026-08-02 教师决定：后续统一新结构）

- **新结构（page-id 契约，唯一标准）**：`<div class="page" id="pageN">` + `<button class="quiz-opt" data-correct="0|1">字母. …` + `checkOpt(this)`。即 `courseware_engine.py` / `gen_l1_l13_v2.py` 产物。页数硬规则 **40-45 页**、体积 ≥150KB。
- **旧结构（slide 契约）冻结**：邓兴华 L01–L15 旧课件（`<div class="slide">` + `checkQuiz`）保持现状，不再返工。页数 25-60 为软区间。
- **适用**：许颖嘉、邓兴华（L16 起）、李民宪所有后续课件一律按 page-id 契约生成与验收。

## 五、学习数据闭环指标（三级统一）

| 指标 | 标准 |
|------|------|
| 本地保存 | HTML 课件支持 IndexedDB 写入，刷新后数据保留 |
| 云同步 | 飞书多维表格 7 表结构，event_id 去重 |
| 导出 | JSON + CSV 导出 |
| 同步状态 | pending / synced / failed，失败可重试 |
| 答题记录 | 第一次答案不覆盖，重答新增记录 |
| 数据安全 | 不得硬编码飞书 app_secret，未成年人数据用学生编号 |
| 独立掌握 | 区分 `independent_correct / hinted_correct / revealed_then_correct / transfer_correct / delayed_retest_correct`，提示后答对不得直接升级 |
| 教师周报 | 首页 8 项以内核心指标，每周处理 ≤30 分钟，只显示能触发行动的指标 |
| 错题闭环 | M14 错误分五类（E1—E5），原题一次＋变式，优先级保留分项原因 |
| AI建议 | "建议＋证据＋动作＋用时"卡片，数据充分性低/中/高，可接受/编辑/拒绝，不嵌入学生HTML |
| 规范文件 | `08_学习数据闭环规范.md` |
