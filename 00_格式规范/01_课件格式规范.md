## 3.1 基础排版与视觉控制器

1. **课件总页数硬性区间 (40 ~ 45 页)**：强制在 40 ~ 45 页之间（至少 40 页，推荐 40-42 页）。页面视口继承 邓兴华 L11 整体流动布局模式。将各个语法、词汇模块、练习题与阅读理解充分拆分展开，避免挤压。
2. **【交互点②】双向拖拽分类归纳箱 (Drag & Drop Vocab Sorter)**：
   - 第 10 页 20 词分类归纳箱**必须采用原生拖拽 / 触摸拖拽 (Drag & Drop)** 交互；
   - 学生可将词汇卡片自由**拖动放入三大分类框框中**（动作词/描述词/场景词）；
   - **拉错了可以随时拉回来**：支持将放入框框中的词卡随时拖回底盘词汇池，或拖动换到其他框框中，支持实时正误反馈与音效。
3. **阅读理解【左文右题双栏对比排版 + 屏幕手划批注工具】**：
   - 以后所有阅读理解统一采用**左文右题双栏对比排版**；
   - **内置屏幕划线批注画笔**：提供悬浮画笔控制栏（包含 ✏️ 细红笔、🖍️ 离屏双缓冲透光荧光笔、🧹 橡皮擦、🗑️ 清空标注、🎨 颜色切换），支持学生阅读长文时在原文上直接圈画划线、标记关键词以辅助解题；
   - **左栏**：展示 📜 阅读原文（字号 17.5px，`line-height: 1.8`）与长难句拆解，暖金红边卡片包装；
   - **右栏**：集中展示 📝 配套 4 道阅读理解诊断题（`.quiz-q`），左右对照，一目了然！
   - **右栏题目须置于「可滚动答题框」内**（`.read-right` 定高 + `.read-qs-scroll` 内部 `overflow-y:auto`）：框带红边圆角、顶部标题条；框高约一屏可视高度，题目超出时在框内独立上下滑动；左栏长文随页面滚动，右框 `position:sticky` 跟随视口保持可见——做到「读第几段，就把第几题滑到眼前」，边读边选。
3. **培优级阅读短文词数下限 (≥ 200 词/篇)**：培优级（李民宪）阅读理解 A/B/C 三篇短文**单篇词数强制 ≥ 200 词**（A篇 225 词，B篇 245 词，C篇 265 词）。
4. **整体页面无障碍上下滑动 (Whole Page Vertical Scroll)**：`.page-container` 设为 `position: fixed; top: 54px; bottom: 50px; left: 0; right: 0;`，每个 `.page` 设为 `position: absolute; top: 0; left: 0; width: 100%; height: 100%; overflow-y: scroll !important; -webkit-overflow-scrolling: touch; padding: 24px 44px 40px;`。**整个页面可无障碍上下平滑滑动**。
5. **练习题单列纵向排列 (1列4题)**：4 道练习题依次作为 `.quiz-q` 卡片纵向堆叠，跟随整个页面平滑上下滑动切换与阅读。
6. **双击红色错题撤销复原**：当学生点击选项答错显红后，**双击该红色选项（或双击该题卡片）必须立即撤销回答并复原**，重置为未作答初始状态，隐藏解析。
7. **答题正误气泡提醒规范 (Answer Feedback Popup Bubbles)**：
   - **答题错误**：当练习答题出现错误时，必须立即跳出一个醒目的**红色气泡框**（内置大大的叉 ✖️ 与大号“错误”字样及红色边框动画），明确提醒学习者回答有误；
   - **答题正确**：当答题正确时，展示带有**大拇指 👍 与绿色“正确”字样**的绿色气泡框，给予极佳的正向激励！
8. **顶端 54px 导航时间轴（居中 8-Pill 可点击）**：取消左上角大标题，顶部导航栏直接居中显示 8 大环节标签（`①导入`, `②新词20`, `③语法精讲`, `④随堂演练`, `⑤阅读理解`, `⑥自然拼读`, `⑦综合提升`, `⑧Exit Ticket`），支持鼠标/手指点击直接跳转至对应环节。
9. **自然拼读环节（Phonics Module）硬性贯穿规范**：自然拼读作为贯穿整个教学体系的核心环节，**必须在顶栏导航 Pill (`⑥自然拼读`) 与 P33-P37 专页中全量保留展现**（包含 1 页拼读发音规则表/30词图谱 + 4 页分类判断/对比辨析/拆拼应用诊断题），绝不允许漏掉或剔除自然拼读环节！
   - **互动练习形式（2026-08-02 落地，courseware_engine.py `phonics_practice_pages`）**：展示页 1 页（组合发音卡 + 词族 + 拼读儿歌）＋ 互动闯关 4 形态（`quiz-opt`/`checkOpt` 正误反馈，离线可用）：**①辨音选词**（音→词，读音标选词）**②解码高手**（词→组合，blue→bl）**③词族归类**（找同组合同发音词，避同音歧义）**④拼写补全**（缺字母组合，b__ue→bl）。词池 `PHONICS_POOL` 引擎内置扩充，缺词自动回退 `phonics_bank` 词族；各课按本课 `组合/发音/词族` 自动生成，无需逐课手配。
6. **禁止出现“黄金大师”文案**：彻底删除课件标题、导航栏及所有卡片中的“黄金大师”/“英语黄金大师”字样。
7. **切页交互与无形热区**：
   - 左右半屏设置无形切页热区（左半屏上一页，右半屏下一页）。点击热区时**绝对禁止出现任何外框、阴影、背景色变化、涟漪或形状视觉反应**（`outline: none`, `-webkit-tap-highlight-color: transparent`, `background: transparent`），实现直接静默切页。
   - **底部 HUD 取消“上一页 / 下一页”按钮**：仅保留进度条、页码卡（如 `页码: 1 / 28`）与数据导出按钮。
8. **课件文件大小硬性下限 (≥ 150KB)**：纯单文件 HTML 体积强制 **≥ 150KB**。
   - **各段页数区间（含词汇复习游戏调整）**：
     - ①复习/导入（2页）：P1 语法回顾 + P2 **跨课词汇复习游戏（Tier2/3，复习上一课词汇）**
     - ②新词20（5~6页）：4页词卡教学 + **2页课内词汇复习游戏（1页 Tier1 词级 + 1页 Tier2/3 句篇级）**
     - ③语法3考点（5~6页）
     - ④随堂演练（2页）
     - ⑤阅读理解（2~3页）
     - ⑥句子练习（2~3页）
     - ⑦自然拼读（3~4页）：从原4~5页压缩1页，为词汇复习游戏腾出页面空间
     - ⑧课堂总结（1页）
3. **默认 UI 风格：青春活力亮色主题**：亮色主题，不同阶段品牌色区分。
   - 复习课统一红金主题（`--brand: #E63946`, `--accent: #FFD700`，背景 `#FFF8F0 → #FFE8D6`）。

## 3.2 创意交互点与自主创造规范

1. **数量与分布硬性要求**：
   - 每课 HTML 课件**必须包含至少 6 个创意交互点**。
   - 须分布在**至少 3 个不同教学环节**中（如复习导入、新词教授、语法教授、随堂练习、阅读理解等）。
   - **严禁跨课复用同一交互模式**，每个创意交互点须为本课专属。
   - **6 大创意交互点示例（第 01 课完整落地）**：
     1. `[交互点①]` **假期场景动态模拟器 (Holiday Scene Simulator)**（导入环节）：动态切换场景、展示例句与配音。
     2. `[交互点②]` **七年级 20 词分类归纳箱 (Vocab Sorting Bin Game)**（词汇复习环节）：点击词汇归类至动作/描述/场景箱。
     3. `[交互点③]` **五大句型结构分类天平 (Sentence Pattern Categorizer)**（语法环节）：拖拽/点击句子归类 SV/SVO/SP/SVOO/SVOC。
     4. `[交互点④]` **一般过去时不规则动词变色转盘 (Irregular Verb Transformer)**（语法环节）：点击原形动词触发卡片翻转与过去式变形。
     5. `[交互点⑤]` **复合不定代词闪卡闯关小游戏 (Indefinite Pronoun Flash Quiz)**（语法与练习环节）：倒计时倒数、得分累加与即时判定。
     6. `[交互点⑥]` **"My Dream Vacation" 词块动态合成器 (Mini Task Phrase Assembler)**（综合表达环节）：点击四大词块合成完整短文。
2. **交互形式「选择制 + 自主创新」原则（禁止写死）**：
   - **禁止把交互形式写死**：任何一课不得指定「必须用某一种固定交互」；交互形式由生成 Agent **从候选交互类型菜单中选择**，且菜单本身是开放的。
   - **候选交互类型（供选择，可混用）**：翻牌自检（flash / recall）｜选择判断（quiz-opt）｜双向拖拽分类归纳箱（Drag & Drop）｜连线配对（match）｜拖拽排序（drag-sort）｜深色闯关面板（game-board）｜听音选词｜改错「选一选」｜易错点选择题｜流程图 / 结构图呈现｜卡片簇（ext-card）｜思维导图互动等。
   - **按本课学习内容选择**：Agent 结合本课语法考点、词汇主题、阅读篇章、拼读内容，选择**最契合内容呈现与练习的形式**；同一课可混用多种形式；每个交互点的选择须在契约 `4_素材清单.md` 声明并说明选择理由。
   - **允许基于内容的创新**：候选菜单绝非上限。允许 Agent 根据本课学习内容创新全新交互形式，创新时须说明设计意图，并在契约中声明。
3. **契约声明**：
   - 所有创意交互点须在契约 `4_素材清单.md` 中逐一声明，注明：所属环节、交互函数名、创意描述。

## 3.3 声效系统硬性要求

每课 HTML 必须基于 Web Audio API 实现完整声效系统，硬性包含三大核心函数：
- `playCorrect()`：答对/交互成功时的正向提示音
- `playError()`：答错时的纠错提示音
- `playPageTurn()`：翻页时的页面切换音效

## 3.3.1 答题反馈视觉与解析规范（硬性要求）

所有课件的**每一道练习题**（选择题 / 填空 / 拼写 / 完形 / 判断）必须实现"答对显绿、答错显红、每题带解析"的完整反馈闭环：

1. **答对 → 绿色反馈**：选中/输入的选项或区域变为绿色（`#06D6A0` 或 `--success`），播放 `playCorrect()`。
2. **答错 → 红色反馈**：选中/输入变为红色（`#F25F5C` 或 `--error`），播放 `playError()`，并**高亮显示正确答案**（答错时正确答案以绿色标出）。
3. **每题必须带解析**：每题下方须有解析区域（如 `.quiz-explanation` / `.fill-explanation`），答对答错均显示：
   - 答对：显示该题的考点/规律/为什么对（如"主谓宾：The boy(主) likes(谓)"）。
   - 答错：显示"正确答案：xxx" + 简要解析。
   - 解析须**有教学价值**（讲清考点或规律），不得只写"答案错了"。
4. **交互反馈优先级**：答题元素须调用 `event.stopPropagation()`，不触发翻页（同 §3.4 答案优先级）。
5. **反馈状态类统一**：建议使用 `.correct`（绿）、`.wrong`（红）、`.disabled`（禁用）三个状态类；填空题输入框用 `.fill-input-box` + `.correct/.wrong`。
6. **禁止只判分不给解析**：任何一道题若仅有对错变色而无解析，视为不合格。

## 3.4 课件设计质量与翻页交互规范

1. **设计质量优先级**：每页精心设计视觉层次（卡片、阴影、渐变、图表），将抽象规则直观化。
2. **左右半屏点击翻页与答案优先级**：点击右半屏下一页，点击左半屏上一页；答案点击（`.answer-mask`、`.q-opt`、`.interact-btn`）调用 `event.stopPropagation()`，优先级最高不误触翻页。
3. **整页滚动机制**：整个 `.page` 作为整体上下滚动（`overflow-y:auto`），切页自动重置滚动位置到顶部（`scrollTop=0`）。正文不得重复出现 `section-badge` 冗余环节标签。
4. **课件 HTML 文件大小硬性下限**：文件大小强制 **≥ 100KB**。

## 3.5 复习课六段式课件标准

> **适用课次**：L7、L16、L21（语法系统复习课）。

1. **六段式结构**：
   - ① 语法全景导览（2-3页）
   - ② 主题分组精讲（12-15页）
   - ③ 螺旋链追踪（2-3页）
   - ④ 易错点对照（3-4页）
   - ⑤ 综合运用演练（4-5页）
   - ⑥ 知识图谱总结（2-3页）
2. **语法主题分组体系**：各级别语法考点按类别归纳为主题分组（T1-T14），复习课按分组组织内容。
3. **复习课不生成 DOCX 练习卷**：练习融入课件⑤环节（综合运用演练），不生成独立测试卷。
4. **其他规范**：技术契约统一为 page-id 契约、页数 40-45 页（2026-08-03 修订，取代旧 25-30 页）、21:9 比例、左右半屏翻页、整页滚动、创意交互至少 6 个、声效系统等均与授课课一致。

## 3.6 课件答案隐藏规范（硬性要求）

所有课件练习题目的答案**必须默认隐藏**，仅通过点击交互显示。具体规则：

1. **CSS 隐藏机制**：答案区域使用 `display:none` 默认隐藏，通过添加 `.show` class 显示。
2. **JavaScript 交互**：学生点击选项/检查按钮后，才触发答案显示。
3. **题目文本中不得包含任何形式的答案**：
   - 语法参考标注只标注考点编号和类别名称（如"（T4·G32 量词表达）"）。
   - 不得附带答案词汇（如 ~~"（T4·G32 量词表达，bowls）"~~ 是错误的）。
4. **中文提示不得包含英文答案**：如需中文提示，用中文表述（如"（喝）"而非"（to drink）"）。

## 3.7 词汇复习游戏三层体系规范

> **核心目标**：将词汇复习从"孤词记忆"升级为"语境运用"。学完20个新词后立即通过多样化游戏巩固，下一课通过语境化游戏螺旋复习上一课词汇。
>
> **文档分工**：本节仅保留课件页面结构层面的硬规则（页面配置、CSS类名、翻页交互等）。所有教学逻辑、游戏设计要求、提示梯度、评分规范、一对一适配、错词分类等详见 `07_词汇教学与复习游戏规范.md`。

### 3.7.1 三层体系定义

词汇复习游戏按语境深度分为三个层级，每课须按"词级→句级/篇章级"递进设计：

| 层级 | 名称 | 语境深度 | 课内使用 | 跨课使用 | 设计目标 |
|------|------|---------|---------|---------|---------|
| Tier 1 | 词级游戏 | 单词层面 | 可用（课内P①） | **禁止** | 快速反应、音形义关联 |
| Tier 2 | 句级游戏 | 句子语境 | 可用（课内P②） | 可用 | 词汇在句子中的运用 |
| Tier 3 | 篇章级游戏 | 对话/语篇/情景 | 可用（课内P②） | **推荐** | 词汇在真实语境中的理解与产出 |

### 3.7.2 游戏类型目录（29种）

> 完整游戏目录（29种=18原有+11新增）、训练目标标注、设计要求、升级路径、一对一适配方案详见 `07_词汇教学与复习游戏规范.md` 第十三章。本表为摘要。

**Tier 1 词级游戏（10种，课内专用）**：

| 编号 | 名称 | 训练目标 | 交互方式 | 描述 |
|------|------|---------|---------|------|
| T1-A | 英中速配选择 | REC | 点击选择 | 英文单词+音标 → 3-4个中文选项 |

### 3.7.3 页面配置规则

1. **课内词汇复习游戏（2页，位于新词20之后、语法之前）**：

   - 第2页（P②）：Tier 2 句级 或 Tier 3 篇章级游戏，须覆盖语境应用(CTX)训练目标

   - 须为 Tier 2 句级 或 Tier 3 篇章级，**禁止使用 Tier 1 词级**
   - 复习上一课的核心词汇（基础10词/中等15词/培优20词）
   - 词汇须嵌入句子/对话/语篇语境，不得以孤词形式呈现
   - 数据来源：自动读取上一课契约 `1_课程概要.md` 中的"20新词硬契约"表格

3. **Mini Task 落位**：④随堂演练 P1 须为 Mini Task 综合表达任务（Tier 3 表达类），使用本课核心产出词完成情境任务。Mini Task 须标注任务情境、交际目标、必用词、句型支架、完成标准。详见 `07_词汇教学与复习游戏规范.md` 第十章。

4. **Exit Ticket 落位**：⑧课堂总结页须包含3-5分钟退出检测，覆盖词义识别(REC)+主动提取(RET)+表达任务(EXP)+学生自评。分级题量：基础4题/中等5题/培优6题。详见 `07_词汇教学与复习游戏规范.md` 第二十五章。

5. **页面预算调整**：
   - 课内新增1页（从1页扩展到2页），通过压缩⑦自然拼读1页（4-5页→3-4页）平衡
   - 总页数区间不变（25-30页），仅内部重分配

## 3.8 学习数据采集与交互规范

> **关联文件**：`08_学习数据闭环规范.md`（完整数据闭环架构，本节约简要求）
> **适用范围**：三级共用，所有课件须满足。

### 3.8.1 数据采集最低要求

课件 HTML 必须支持：
- IndexedDB 写入答题记录；
- 每次提交答案后**先写本地数据库**，再显示反馈；
- 刷新后数据仍然存在；
- 支持 JSON 和 CSV 导出；
- 显示同步状态（`pending` / `synced` / `failed`）；
- 同步失败可重试。

### 3.8.2 自动跳题与历史回看

学生提交答案后：
1. 保存第一次答案；
2. 显示正确或错误；
3. 错题提供简短提示；
4. 自动进入下一题；
5. 上一题收起；
6. 题号导航保留状态（`1 ✓  2 ✓  3 ×  4 ✓  5 当前  6 未答`）；
7. 学生可返回查看已做题目；
8. 练习模式允许重答；
9. 测试模式默认不允许修改首次答案；
10. 修改时新增尝试记录，第一次答案不被覆盖；
11. **答错后双击撤销（容错交互）**：学生答错（或误触选错）后，**双击该题可撤销本次作答**，回到未作答状态并允许重新选择，避免误触操作导致错误；
12. **撤销提示小字**：学生答错后，题目旁显示一行小字提醒"答错后双击可撤销回答"，低透明度浅色显示，帮助学生发现这一容错操作。

回看时显示：第一次答案、正确答案、是否使用提示、第一次用时、后续改正、错误原因。

### 3.8.3 题目 ID 命名规则

- 每道题必须有稳定唯一 `question_id`；
- **同一课内 `data-qid` 必须全课唯一**（2026-08-03 强化）：生成器 `make_quiz_item` 已按调用序自动重排题号为全课唯一（修复旧版 Q17–24 撞号——两题同 qid 会导致 event_id 冲突、题号重复显示）。手工或脚本生成题目时，严禁两题共用同一 `data-qid`。
- `event_id = student_id + session_id + question_id + attempt_no`；
- 示例：`stu_001_20260808AM_L03_VOC007_A1`。

### 3.8.4 安全红线

- 课件 HTML 中不得硬编码飞书 `app_secret` 或任何 API 密钥；
- 前端代码可被查看，密钥暴露后可能被越权读取或修改。

## 3.9 课堂收尾 · 思维导图环节（硬性要求）

1. **每课必须设置思维导图收尾环节**：作为课件**最后一个环节**（独立页），把本课知识系统收拢成一张图，供课堂复盘使用。
2. **必须包含上节课复习内容**：思维导图须把「上节课复习（语法 + 词汇）」纳入其中，不能只画本课新知识。
2b. **必须呈现完整内容（禁止只画概括性要点）**：思维导图是**本课全部知识的总复盘**，不是图框摘要。每个模块必须呈现该模块的**完整内容**——
   - **词汇**：列出**全部新词**（英文 + 中文释义，密集课时含音标 / 词性），不能只写「三餐组 / 水果组」等组名；
   - **语法**：每个语法点列出**结构构成 + 例句**（如祈使句：肯定动词原形 / 否定 Don't + 原形 / 提议 Let's + 原形 + 例句），不能只写考点名称；
   - **阅读**：各篇题型与对应解题策略；
   - **拼读**：各组合 + 代表词；
   - **上节课复习**：全部复习语法点构成 + 全部复习词汇（逐词列出）；
   - **易错**：易错规则 + 正确写法。
   - **实现方式**：形式上可「总览页 + 完整内容页」组合——总览页用分支/节点交互呈现全貌，完整内容页把词汇全表、语法全表、复习全表逐项铺开；也可在单页分支展开面板内呈现完整内容。内容量大时思维导图环节**可占多页**（不超过 40–45 页总预算）。
3. **思维导图形式「选择制 + 自主创新」（禁止定死一种形式）**：
   - 禁止把思维导图固定成某一种形式；生成 Agent **根据本课学习内容选择最合适的形式**。
   - **候选形式（供选择，按内容取舍）**：
     - **A. 中心辐射式**：本课主题在圆心，各知识模块作彩色主枝向外辐射，节点可点击展开要点。适合知识模块均衡的综合课。
     - **B. 左侧横向树状**：根节点在左，主干向右逐层分叉。适合阅读 / 方法 / 流程导向、层级分明的课。
     - **C. 上下层级结构（组织图式）**：本课在最上，向下分「复习 / 本课知识 / 方法」再展开。适合结构递进的课。
     - **D. 彩色卡片簇**：每模块一张大卡，卡内列要点。适合词汇量大、需要信息密度、分类明确的课。
   - **按内容选择示例**：词汇量大的课（如培优 30 词）宜用 D 卡片簇；阅读 / 题型策略为主的课宜用 B 横向树状；知识模块均衡的综合课宜用 A 中心辐射式。
   - **允许基于内容的创新**：候选形式绝非上限，允许 Agent 根据本课内容创新其他形式（如时间线、环形图、路线图等），创新时须说明设计意图。
4. **交互要求**：思维导图应可交互（点击分支 / 节点展开要点），点击不得触发翻页（遵守组件点击优先级规范）。

## 3.10 页面运行优先级 CORE / EXTEND / HOME（硬性要求）

> 来源：C3 兼容修订版总文档 §5/§6（2026-08-02）。**不改变九环节、不改变页面编号、不删任何页面**；优先级只作为课堂运行选择依据。

1. **每页必须有运行元数据**：`PAGE_META` 运行层（`{"priority": "CORE|EXTEND|HOME", "estimated_minutes": N}`）或页面 `data-priority` + `data-estimated-minutes` 属性，二选一即可，随 `page` 结构同步生成。
2. **三档定义**：
   - **CORE**（课堂必做）：核心词汇、核心语法主题、真题、随堂演练、Exit Ticket；
   - **EXTEND**（时间充足时做）：进阶练习、扩展语篇、课堂游戏（选做）；
   - **HOME**（课后完成 / 下节课抽查）：阅读 C 篇、长写作、拓展发音等。
3. **三篇阅读固定优先级**：Passage A = CORE（课堂精读必完成）、Passage B = EXTEND、Passage C = HOME。三篇**全部保留在 HTML 中并计入 40–45 页**，不得删除 B/C、不得因优先级降低页数。
4. **优先级徽标**：每页顶部显示徽标（`CORE · 课堂必做` / `EXTEND · 时间充足时做` / `HOME · 课后完成`），仅标注不删篇。
5. **导航可按优先级筛选**：课件导航时间轴支持按 CORE / EXTEND / HOME 筛选跳转；默认展示全部。
6. **HOME 页面必须完整可用**：HOME 页面功能完整（可答题、有反馈、有数据采集），只是默认不在课堂必做范围；课后学生独立完成时数据照常采集。
7. **课时运行模式映射**（60 / 90 / 120 分钟为同一课件的不同运行方式，不是不同版本）：

| 课时 | 完成范围 |
|------|---------|
| 60 分钟 | 全部 CORE（核心词汇、核心语法、真题、Exit Ticket） |
| 90 分钟 | 全部 CORE + 1–2 个 EXTEND |
| 120 分钟 | 全部 CORE + 大部分 EXTEND |
| 课后 | HOME |

8. **不修改验证器**：优先级仅运行层，不影响 verify_v2 硬规则（页数 / 体积 / div 平衡 / 答案分布等）。

## 3.11 视觉升级约束（A类报告 2026-08-03 落地）

> 依据：`00_总规划\深度调研报告_A类_2026-08-03.md`（前端精美化）。实施路径仅 `CSS_EXTRA` / `js_extra` / 生成器模板更新，**不改 CORE_CSS/CORE_JS**。生成器已内置 X26 视觉层（实体卡 / 触屏按压态 / 键盘焦点 / 减弱动画），本节约束生成侧长期遵守。

### 3.11.1 MUST

1. **实体表面替代大面积玻璃**：普通内容卡（正文 `.body-text`、笔记 `.note-panel`、词汇卡）用实体纸卡——低透明白底 + 1px 半透明边框 + 双层轻阴影；不得整页大面积 `backdrop-filter` 玻璃拟态。
2. **玻璃拟态仅限局部**：封面背景、弹层、浮动工具条可保留小块半透明；**阅读、真题、错题页面禁用玻璃材质**。
3. **每页一个主操作 / 主视觉焦点**；视觉强调色每页不超过两类。
4. **解析默认折叠**：正确 → 依据 → 迁移题按顺序展开；不得默认铺满整页解析。
5. **阅读页安静**：阅读/真题/错题页面背景与动效必须比游戏页安静，禁用装饰性持续动画。
6. **触屏与键盘无障碍**：按钮/选项必须有点按按压态（`:active`）与键盘焦点可见（`:focus-visible`）；重要操作不得只藏在 hover。
7. **动效全局可关**：支持 `prefers-reduced-motion`；页面离开后暂停离屏动画（生成器 X26 JS 已实现）。

### 3.11.2 SHOULD

1. 标题层级采用「小标签 + 主标题 + 辅助行 + 数字」（如 `CORE · GRAMMAR` / 当前任务 / 一句操作说明 / `03 · 08`）。
2. 数字/时间/进度用等宽数字（`font-variant-numeric: tabular-nums`）。
3. 动效遵守 Token（`courseware_engine.py` X26 层 `--x26-motion-*`）：按压 100–150ms、卡片 180–240ms、切换 220–300ms、反馈 180–240ms，位移 ≤12px。
4. 诊断、真题、Exit Ticket 用一题一屏；同类型 2–4 道短题可同页。
5. 预计时间只在任务开始处展示，不持续倒计时。

### 3.11.3 MAY

1. 章节过渡页可用较强视觉；游戏模块适量插画；总结页可用成长动画。
2. 封面保留局部渐变背景；可保留小块玻璃（不整卡模糊）。

### 3.11.4 MUST NOT

1. 不得用闪烁 / 呼吸光提示重点；不得同时突出三处以上内容。
2. 不得自动播放声音；不得为美观拆散必须同时比较的内容；不得每页不同视觉风格。
3. 不得动画化 `width/height/top/left` 等触发布局属性；不得让动画阻塞答题。
4. 不引入 WebGL / Three.js / 在线字体 / Lottie CDN / 全屏粒子 / 自动滚动 / 隐藏导航。

## 3.12 六色卡排版与记忆分级（2026-08-03 教师反馈落地）

> 六色要点卡必须体现「重点记忆 / 难点 / 理解即可」分级，禁止六卡等权平铺、禁止标题与正文同权重。生成器已内置（`courseware_engine.py` / `gen_l1_l13_v2.py`），新课自动生效。

- 徽标三档：`key`＝★ 重点记忆（金色）、`warn`＝▲ 难点（白底红字）、`hint`＝○ 理解即可（半透明白）。

### 3.12.2 默认分级映射（六色语义）

### 3.12.3 约束

### 3.12.4 正文内容结构化（2026-08-03 教师反馈落地：正文不得逐行平铺）

正文区 `rc-text` 必须按内容结构渲染、突出重点（生成器 `courseware_engine.fmt_six_body()` 自动实现，新课自动生效；已重出的 L17/L18 亦采用）：

1. **易错对 → 红/绿行**：正文含 `❌ … → ✅ …`（含 `/` 并列多组）时，错句渲染为红底 `rc-err-row`（✕ 圆标 + 左红条），对句渲染为绿底 `rc-fix-row`（✓ 圆标 + 左绿条）；禁止把易错对当普通文本排。
2. **序列 / 公式 → 胶囊块**：`>` 频度链、`+` 结构公式、`→` 变换链、`/` 英文列表 → 每个元素渲染为 `rc-chip` 胶囊（圆角浅底），箭头 `rc-arw` 品牌色。
3. **纯英例句 → 引用样式**：整段纯英文例句渲染为 `rc-example`（斜体 + 品牌色左条 + 浅底），与规则/说明区分。
4. **中文说明 → 关键词高亮**：正文中的英文关键词渲染为 `rc-kw`（品牌色加粗），跳过高频功能词（a/an/the/and/...）。
5. **误伤保护**：`/` 列表仅当各段以英文为主（英文字母占比 >55%）才切胶囊，防止中文句中斜杠误切；`>`/`+`/`→` 需分段数 ≥2 才生效。

## 3.14 单页排版规则 V1.0（2026-08-04 · 依据 GPT《页面排版与练习形式设计研究答复》落地）

> 来源：GPT 研究答复（依据 WCAG 2.2 / USWDS / GOV.UK / Apple HIG / 提取练习研究）。本规则回应"页面难看、字体过小、无层级、示例词未整理、重点不突出"类问题。字号/卡片数等 V1.0 参数为项目初始值，8–12 周课堂校准。

### 3.14.1 字体与层级（MUST）

- 正文 ≥20px（不得低于 18px）；注释 ≥16px；示例词/目标句/结构公式**不得比正文小**；正文行距 ≥1.45。
- 字号 Token（CSS 变量）：`--cw-fs-title clamp(34px,3.2vw,52px)` / `--cw-fs-heading clamp(26px,2.2vw,36px)` / `--cw-fs-body clamp(20px,1.55vw,26px)` / `--cw-fs-example clamp(22px,1.8vw,30px)` / `--cw-fs-note clamp(16px,1.15vw,20px)`。
- 超量内容**拆页/折叠/删减**，禁止缩字号硬塞。

### 3.14.2 一页一任务 · 单页容量（MUST）

- 每页**一个主任务**、一个主焦点、一个主操作区；首屏核心信息块 ≤3 个。
- 规则页只讲**一条核心规则**：1 结构公式/对照 + 1–2 组例句 + 1 立即检查。
- **例词每卡首屏 3 个、最多 6 个分两行**，每行 ≤3 个；禁止逗号长串（4 音素 × 6 词必须拆 ≥2 页）。
- 同构短选择题每页 2–4 题；输入/改错/排序题每页 1–2 题。
- 真题、诊断题、完整解析题**一题一屏**；长解析默认折叠。

### 3.14.3 重点突出（MUST）

- 重点/易错/正误**不只靠颜色**：至少叠加 粗体/下划线/边框/图标/标签/背景形状 之一。
- 拼读例词只高亮目标字母组合（如 `c<span class="target-sound">oo</span>k`），不整词涂高饱和色；红橙色只用于易错提醒。

### 3.14.4 对齐、行长与可访问（MUST）

- 阅读正文 60ch–72ch，中文解释 28em–34em；正文左对齐，居中只用于封面/短标题/≤2 行提示。
- 触屏主控件项目目标 ≥44×44 CSS px；200% 缩放不得丢内容/裁切/遮挡；拖拽/hover 必须有点击或键盘替代。
- 阅读/规则/错题页**不做持续动画**（粒子/漂浮/背景 Canvas），避免装饰干扰（§3.11 MUST 5 同源）。

### 3.14.5 排版"不许"（MUST NOT）

1. 不缩字号解决内容超量；2. 不把 24 个例词塞一行；3. 不让标题/规则/例子/注释同层级；4. 不只用颜色表正误；5. 不让装饰动画与阅读正文同时持续运动；6. 不把 V1.0 参数当普遍科学定律（8–12 周课堂校准）。

### 3.14.6 verify 软检查（新增候选）

GPT 提出 14 项软检查候选（字号<18px / 例词长串 / 信息块过多 / 题目过多 / 解析默认展开 / 阅读过宽 / 缺层级 / 重点只靠颜色 / 选择题过量 / 缺提取题 / 缺迁移题 / 触屏过小 / 长文居中 / 装饰干扰），仅警告不阻塞。待第二轮 GPT 答复（CSS 架构 + 视觉验收自动化）后定稿为 verify_v2 视觉软检查 V1.0。
