## 第一章：规范目标与定位

本规范用于约束英语课件中的词汇教学与复习游戏设计，避免课件只呈现"英文—中文"词表或只做机械配对。目标词汇应经历完整的"呈现→识别→提取→搭配→句子→对话→短文→输出→间隔复习"链条。

课件目标不是让学生"看过单词"，而是让学生逐步做到：看见英文能理解；看见中文、图片或释义能说出英文；听到单词能辨认；能拼写核心词；能识别常见词形变化；能在句子、对话和短文中理解；能在受控任务中使用；能在下一课和后续课程中再次提取。

## 第三章：术语定义

| 术语 | 定义 |
|------|------|
| **目标词** | 本课计划学习或重点复习的单词、固定搭配和高频词块 |
| **核心产出词** | 要求学生能够主动说出、拼写并用于句子或表达的词汇 |
| **理解词** | 本阶段主要要求学生在听力或阅读中辨认和理解，不强制立即独立产出 |
| **即时巩固** | 完成一组新词教学后，在同一课内立即安排的主动回忆、辨认、搭配和语境运用活动 |
| **延迟复习** | 在下一课或后续课程中，经过时间间隔再次提取此前词汇 |
| **训练目标代码** | REC=词义识别, RET=主动提取, SPL=拼写/词形, COL=词块搭配, CTX=语境应用, EXP=综合表达 |

## 第四章：核心原则

### 4.1 单词不得只以孤立词条出现

每个核心产出词至少进入以下三个层级：
- 单词或图片层；
- 词块或句子层；
- 对话、短文或任务层。

重点词宜尽量形成完整链条：`单词 → 词块 → 句子 → 对话 → 短文 → 表达任务`

### 4.2 "再次展示"不能代替"主动提取"

学习完一组词后，课件必须让学生在暂时看不到答案的情况下尝试回忆，再给予反馈。反复播放同一词卡不算完整巩固。

### 4.3 识别与产出必须同时存在

同一组词至少包含：
- 英文选中文、图片选词等识别任务；
- 中文说英文、看图说词、补全拼写等产出任务。

仅做选择题不足以证明学生能够主动使用词汇。

### 4.4 形式变化与搭配优先于冷僻释义

初中阶段词汇页应优先处理：词性；常见复数；动词过去式或第三人称形式；常见搭配；教材语境中的高频含义；易混词辨析。不得为了"内容丰富"大量加入低频释义和超纲搭配。

### 4.5 语境必须自然、可理解、符合学生年级

例句、对话和短文应：语义自然；主题统一；句法难度可控；尽可能复现本课词汇；不为塞词而制造生硬句子；避免加入过多未学词造成额外负荷。

### 4.6 一页只承担一个清晰任务

不得在同一页堆放大量词义、音标、词形、搭配、例句、图片和练习。页面应按"看、听、说、选、写、读"等学习动作拆分。

### 4.7 游戏必须服务学习目标

游戏不是独立娱乐环节，而是具有明确训练目标的学习任务。每个游戏必须回答四个问题：复习哪些词？训练哪种能力？学生需要做出什么可观察反应？教师或课件如何反馈并记录结果？

## 第五章：词汇学习链（9步）

目标词汇应经历以下9步链条，不得跳步：

```
1.清晰呈现 → 2.理解辨认 → 3.主动提取 → 4.词块搭配 → 5.句子运用
→ 6.对话交流 → 7.短文复现 → 8.口头或书面输出 → 9.后续间隔复习
```

### 5.1 课件页面结构建议（15步词汇模块）

一个完整词汇模块可按以下顺序组织：

1. 本课主题与学习目标
2. 旧词热身
3. 第一小组新词
4. 第一小组快速回忆
5. 第二小组新词
6. 第二小组快速回忆
7. 全组词义识别
8. 全组主动提取
9. 拼写与词形
10. 词块和句子
11. 情境对话
12. 短文复现
13. Mini Task
14. Exit Ticket
15. 家庭复习说明

### 5.2 与课件八段式结构的映射

| 词汇模块步骤 | 对应八段式环节 | 课件页面 |
|-------------|--------------|---------|
| 步骤1-2（主题+热身） | ①复习导入 P1 | 复习导入页 |
| 步骤3-6（分组新词+分段回忆） | ②新词20 P1-P4 | 词卡教学页 |
| 步骤7-9（识别+提取+拼写） | ②新词20 P5（课内游戏①Tier1） | 课内词汇游戏① |
| 步骤10-12（词块+对话+短文） | ②新词20 P6（课内游戏②Tier2/3） | 课内词汇游戏② |
| 步骤13（Mini Task） | ④随堂演练 P1 | Mini Task综合表达页 |
| 步骤14（Exit Ticket） | ⑧课堂总结 | 退出检测页 |
| 步骤15（家庭复习） | ⑧课堂总结 | 总结页底部 |

## 第六章：每组新词标准教学流程

以下流程适用于一组约8—20个目标词，具体数量由学生参数决定。

### 阶段A：主题预热

可采用：主题图片观察；2—3个引导问题；情境预测；已学词快速联想；简短师生对话。要求：预热不提前完整展示全部答案。

### 阶段B：新词呈现

每个词按需要呈现：英文；音标或发音提示；中文核心义；词性；图片或情境；一个高频词块；一个可理解例句。核心产出词必须提供词块或例句；理解词可适当简化。

### 阶段C：分段回忆

若一课学习词汇较多，不得等全部结束后才第一次复习。建议每学习5—7个词进行一次短回忆：遮住中文说词义；看图说词；听音指词；快速配对；随机抽问。

### 阶段D：整组即时巩固

学习完一组词后，必须立即进入巩固模块，不得直接切换到无关语法或阅读。建议顺序：`识别 → 提取 → 拼写 → 搭配 → 句子 → 对话/短文 → 小输出`

## 第七章：即时巩固模块最低配置

一组目标词学完后，至少包含以下四类活动，缺一不可。

### 7.1 词义识别（REC）

- 英文选中文；中文选英文；图片选词；单词分类；找出不同类；词义配对。
- 限制：识别题不宜占据整个巩固模块。

### 7.2 主动提取（RET）

必须至少有一项：中文说英文；看图说英文；根据释义猜词；遮挡答案口头回忆；首字母提示补词；单词消失后回忆。

### 7.3 拼写或词形（SPL）

根据学生水平选择：缺字母补全；字母排序；听写；词形转换；单复数；动词形式；词性匹配。理解词不必全部要求完整拼写；核心产出词应有拼写检查。

### 7.4 语境运用（CTX）

必须至少有一项：选词填句；词块配对；补全对话；句子排序；看图造句；短文选词填空；依据情境回答问题。

## 第八章：对话设计规范

### 8.1 对话用途

对话应承担以下一个或多个目标：复现核心词；复现目标句型；提供真实交际目的；为学生模仿表达提供支架；为角色扮演或替换练习服务。

### 8.2 编写要求

场景明确；人物关系自然；每轮话语有回应关系；不把所有目标词硬塞进一个对话；重点词可分散到两到三个小对话；对话后必须安排理解或表达动作。

### 8.3 对话后的活动

至少选择一种：角色朗读；信息替换；遮词复述；补全对话；看提示自由对话；改编人物、地点、时间或活动。

---

## 第九章：短文设计规范

### 9.1 短文功能

短文用于让目标词在连续语篇中再次出现，并训练：根据上下文理解；信息提取；句间关系；词汇复现；口头复述或简短写作。

### 9.2 文本长度

由学生年级和水平决定，不得机械固定。一般可分为：初级微文本40—70词；常规文本70—120词；培优文本可适当增加长度和推理要求。

### 9.3 目标词复现

核心产出词应优先复现；一篇短文不必强行包含全部目标词；目标词较多时可使用两篇短文本；每篇围绕单一主题；允许词形变化，但应与已学语法匹配。

### 9.4 文本后的任务

至少包含两种不同层次：
1. 基础理解：判断、选择、信息定位；
2. 语言加工：圈词块、替换、句型仿写；
3. 输出任务：复述、口头回答、续写或短写作。

## 第十章：Mini Task综合语言任务

每组重点词结束前，应设计一个 Mini Task，使学生将词汇用于有目的的表达。

### 10.1 可选形式

制作个人计划；描述人物或地点；介绍一次经历；完成调查并汇报；设计菜单、海报、路线或日程；两人信息差；情境角色扮演；根据图片讲述；50—80词短写作；使用指定词完成故事。

### 10.2 必须标注

- 任务情境；
- 交际目标；
- 必用词或建议词；
- 句型支架；
- 完成标准。

不得只写"请用这些单词造句"作为唯一综合任务。

### 10.3 落位规则

Mini Task 须落在④随堂演练 P1，使用本课核心产出词完成情境任务。属于 Tier 3 表达类活动，计入"3+1"组合中的"+1"综合挑战。

## 第十一章：延迟复习规范

每节课开头必须回收上一课或近期课程中的目标词。建议安排5—10分钟，具体时长依课堂长度调整。

### 11.1 复习内容构成

1. 上一课核心词；
2. 前两至四课错词；
3. 少量更早课程的长期复习词。

### 11.2 同词异式原则

复习活动应避免与上次完全相同。推荐轮换对照：

| 上一课末尾活动 | 下一课开头建议 |
|---|---|
| 英文选中文 | 看中文说英文 |
| 图片选词 | 图片说词并造句 |
| 缺字母 | 听音写词 |
| 选词填句 | 对话补全 |
| 对话朗读 | 遮词复述 |
| 短文填空 | 信息问答或复述 |
| Bingo | 分类赛或错句侦探 |
| 故事接龙 | 图片讲述或短写作 |

不得连续两课仅更换背景和颜色，实质仍是同一种选择题。下一课复习不能只检查中文释义，还要抽查词块、拼写和语境使用。

### 11.3 落位规则

延迟复习须落在①复习导入 P2，采用 Tier 2 句级或 Tier 3 篇章级游戏，禁止使用 Tier 1 词级。

---

## 第十二章：推荐复习节点

项目可采用以下默认节点，并根据课程频率调整：

- 第一次：新词教学后数分钟内；
- 第二次：本课结束前；
- 第三次：下一课开头；
- 第四次：约一周后；
- 第五次：单元复习时；
- 第六次：阶段测评前后。

Agent 生成课件时，应标明"本课新学词、当堂复习词、跨课复习词"。

## 第十三章：游戏类型扩展目录（29种）

> 游戏按双轴分类：结构层级（Tier 1/2/3）× 训练目标（REC/RET/SPL/COL/CTX/EXP）。
> 18种原有游戏保留编号不变，11种新增游戏编号接续。

### Tier 1 词级游戏（10种，课内专用）

| 编号 | 名称 | 训练目标 | 交互方式 | 描述 |
|------|------|---------|---------|------|
| T1-A | 英中速配选择 | REC | 点击选择 | 英文单词+音标 → 3-4个中文选项 |
| T1-B | 音标辨识配对 | REC | 点击连线 | 音标 → 英文单词配对 |
| T1-C | 语义场分类 | REC | 拖拽分类 | 单词拖入3-4个语义类别框；可含"找出不同类"变体 |
| T1-D | 拼写拼图重组 | SPL | 拖拽字母 | 打乱字母 → 拼出单词；可含缺字母挑战、字母重组变体 |
| T1-E | 词义消消乐 | REC | 连续点击 | 网格中英中词对点击消除；可含Bingo变体 |
| T1-F | 图片词义匹配 | REC | 点击配对 | 图片 → 单词配对 |
| **T1-G** | **中文选英文** | **RET** | **点击选择** | **中文释义 → 3-4个英文选项，从意义到英文的提取** |
| **T1-H** | **图片闪现** | **RET** | **口头/点击** | **图片短暂出现后隐藏，学生说出或写出英文；可设首字母提示** |
| **T1-I** | **单词消失术** | **RET** | **口头/点击** | **多个词展示后随机消失，学生回忆并说出；最后用其中一个词造句** |
| **T1-J** | **听音选词** | **REC** | **点击选择** | **听单词发音 → 从干扰项（辅音/元音/重音相近）中选出正确词** |

### Tier 2 句级游戏（9种，课内+跨课）

| 编号 | 名称 | 训练目标 | 交互方式 | 描述 |
|------|------|---------|---------|------|
| T2-A | 语境填空选择 | CTX | 点击选择 | 含目标词的句子 + 3-4选项；句子提供充分线索 |
| T2-B | 句意判断对错 | CTX | 点击对/错 | 含目标词的句子 + 判断句意 |
| T2-C | 句子重组排列 | CTX | 拖拽排序 | 打乱词序 → 排成正确句子 |
| T2-D | 英汉句子配对 | CTX | 点击连线 | 英文句（含目标词）→ 中文翻译 |
| T2-E | 词义辨析选择 | CTX | 点击选择 | 近义词/易混词在句中辨析 |
| T2-F | 句型转换填空 | CTX | 输入/选择 | 句子转换后填入目标词 |
| **T2-G** | **词块搭配赛** | **COL** | **点击连线** | **词块两半配对（如 take—photos, be good—at）；完成后用词块造句** |
| **T2-H** | **错句侦探** | **COL/CTX** | **点击纠错** | **含词义/搭配/词形错误的句子，学生找出并改正** |
| **T2-I** | **猜词禁语** | **EXP** | **口头描述** | **用英文描述目标词（禁用该词本身），同伴猜测；可设难度梯度** |

### Tier 3 篇章级游戏（10种，课内+跨课推荐）

| 编号 | 名称 | 训练目标 | 交互方式 | 描述 |
|------|------|---------|---------|------|
| T3-A | 对话补全选择 | CTX | 点击选择 | 对话留空 + 选项补全 |
| T3-B | 语篇重建排列 | CTX | 拖拽排序 | 打乱句子 → 排成连贯语篇 |
| T3-C | 情景匹配选择 | CTX | 点击匹配 | 情景描述 → 最佳回应句 |
| T3-D | 角色对话填词 | CTX | 点击/输入 | 双角色对话 + 目标词填空 |
| T3-E | 短文完形选择 | CTX | 点击选择 | 80-100词迷你完形（5-6空）；可设多余词/无词库高阶版 |
| T3-F | 语境推断判断 | CTX | 点击判断 | 短文片段 → 词义推断 |
| **T3-G** | **对话拼图** | **CTX** | **拖拽排序** | **打乱对话轮次 → 排成逻辑连贯对话；完成后朗读/替换/遮词复述** |
| **T3-H** | **信息差任务** | **EXP** | **互动交流** | **A/B掌握不同信息，禁止互看答案，通过交流补全；须提供句型支架** |
| **T3-I** | **采访调查任务** | **EXP** | **问答交流** | **Find Someone Who变体；一对一课堂改为"采访教师""人物卡采访""虚拟班级调查"** |
| **T3-J** | **故事接龙/图片讲述** | **EXP** | **连续表达** | **用必用词+图片/时间词/人物卡讲述故事或描述图片；可含一分钟表达变体** |

> **说明**：加粗行为新增游戏（11种）。原有18种游戏编号和定义保持不变，确保向后兼容。

## 第十四章："3+1"标准游戏组合

一组新词学完后，建议采用"3+1"组合，而不是连续堆叠许多相似小游戏。

### 游戏1：快速识别（REC）

目标：确认学生已建立基本词义联系。可选：英文选中文(T1-A)、图片选词(T1-F)、词义配对(T1-E)、分类挑战(T1-C)、听音选词(T1-J)。

### 游戏2：主动提取（RET）

目标：在不直接看到答案时回忆英文。可选：中文说英文(T1-G)、看图说词(T1-H)、消失的单词(T1-I)、首字母猜词、听音写词(T1-D变体)。

### 游戏3：语境应用（CTX）

目标：将词放入词块、句子或对话。可选：选词填句(T2-A)、情境选择(T3-C)、对话补全(T3-A)、句子接龙(T2-C)、词块搭配(T2-G)。

### "+1"：综合挑战（EXP）

目标：将多个词用于有意义的任务。可选：情境角色扮演(T3-D)、信息差(T3-H)、故事链(T3-J)、一分钟表达(T3-J变体)、小短文挖空(T3-E)、图片讲述(T3-J)。

### 与课内2页+跨课1页的映射

| 组合位 | 训练目标 | 对应课件页面 | 层级要求 |
|--------|---------|-------------|---------|
| 识别+提取 | REC+RET+SPL | ②新词20 P5（课内游戏①） | Tier 1 词级 |
| 语境应用 | CTX | ②新词20 P6（课内游戏②） | Tier 2 句级 或 Tier 3 篇章级 |
| 综合挑战 | EXP | ④随堂演练 P1（Mini Task） | Tier 3 表达类 |
| 跨课复习 | CTX/EXP | ①复习导入 P2（跨课游戏） | Tier 2 或 Tier 3 |

## 第十五章：游戏设计基本原则

### 15.1 一个游戏对应一个主要训练目标

主要目标可以是：词义识别(REC)；主动提取(RET)；听音辨词；拼写(SPL)；词形(SPL)；词块搭配(COL)；句子生成(CTX)；对话交流(CTX)；语篇理解(CTX)；综合表达(EXP)。

### 15.2 游戏必须产生学习证据

游戏结束后应能判断：哪些词已经掌握；哪些词只会识别；哪些词不会拼；哪些词不会用于句子；哪些词需要进入错词池。若游戏无法产生可观察结果，不应作为核心复习活动。

### 15.3 先保证提取，再追求速度

抢答、计时和积分不能使学生只猜答案。必要时先给个人思考时间，再进入抢答或竞争。

### 15.4 竞争强度适中

不公开羞辱低分学生；不让一名反应快的学生包办；允许轮流回答；可以设置团队合作；错误后提供再答机会；评分应奖励准确性、解释和改正，而不仅是速度。

### 15.5 即时反馈

学生作答后，课件或教师应立即呈现：正确答案；发音；简短解释；常见搭配；必要时的纠错。不能只显示"错误"而不告诉学生为什么。

### 15.6 游戏形式轮换，学习目标连续

下一课可以换游戏，但仍应回收同一批重点词。避免学生只熟悉游戏规则，却没有真正掌握词汇。

## 第十六章：游戏难度参数与提示梯度

### 16.1 提示梯度8级系统

建议按以下顺序逐步减少提示：

| 级别 | 提示内容 | 适用级别 |
|------|---------|---------|
| L1 | 图片+首字母+选项 | 基础起始 |
| L2 | 图片+选项 | 基础/中等起始 |
| L3 | 中文+首字母 | 中等/培优起始 |
| L4 | 中文或英文释义 | 通用 |
| L5 | 句子语境 | 基础终止 |
| L6 | 无提示主动说词 | 中等终止 |
| L7 | 无提示拼写 | 培优过渡 |
| L8 | 在新情境中使用 | 培优终止 |

弱基础学生可保留较多支架；培优学生应逐步进入后四级。提示不得直接泄露答案。

### 16.2 Agent 应从学生文件夹读取的参数

年级；词汇基础；本课目标词数量；核心产出词比例；是否要求完整拼写；是否加入词形变化；是否要求句子或段落输出；允许提示类型；时间限制；单人/双人/小组形式；课堂与作业难度。

## 第十七章：下一课复习游戏规范

下一课开头应采用"同词异式"（见第十一章§11.2对照表）。不得连续两课仅更换背景和颜色，实质仍是同一种选择题。

跨课复习游戏须为 Tier 2 句级或 Tier 3 篇章级，禁止使用 Tier 1 词级。词汇须嵌入句子/对话/语篇语境，不得以孤词形式呈现。数据来源：自动读取上一课契约 `1_课程概要.md` 中的"20新词硬契约"表格。

## 第十九章：一对一课堂游戏改编

一对一教学应避免依赖多人竞争。可改为：

- 学生对教师；
- 学生挑战自己的上次成绩；
- 计时但不公开排名；
- 虚拟人物卡；
- 教师故意犯错，学生纠错；
- 单人闯关；
- 两轮对比进步；
- 口头与书面交替；
- 选择不同难度关卡。

一对一课堂更应重视完整表达，不能退化成连续点选。

## 第二十章：评分与反馈规范

### 20.1 推荐评分维度

词义准确；发音；拼写；词形；搭配；句子完整；表达流畅；使用目标词数量；自我纠错。

### 20.2 部分得分

一个词可分层评分：认得词义1分；能正确说出1分；能正确拼写1分；能用于句子1分。

### 20.3 错误反馈流程

```
学生作答 → 判断 → 提示或纠错 → 学生再次回答 → 正确形式复现 → 进入后续复习池
```

教师直接说出答案后立即进入下一题，不算完成纠错。

## 第二十三章：错词ABCD分类与回收机制

### 23.1 四分类标准

| 类别 | 标准 | 处理规则 |
|------|------|---------|
| A类 | 能理解、能说、能拼、能用 | 降低出现频率，但仍进入周期复习 |
| B类 | 能理解但产出不稳 | 增加中文到英文、看图说词和句子补全 |
| C类 | 词义或拼写错误 | 增加短间隔提取和拼写 |
| D类 | 多次错误或容易混淆 | 单独进入易错词页，与近义词/形近词/搭配一起处理 |

### 23.2 回收规则

不得让已掌握词与反复错误词长期以相同频率出现。每次检测后须更新分类，动态调整复习池比例。

### 23.3 分级处理深度

| 级别 | ABCD分类处理深度 |
|------|----------------|
| 基础 | A/B类为主，C类简单复练 |
| 中等 | 全分类，C类短间隔提取 |
| 培优 | 全分类，D类单独易错词页 |

## 第二十四章：作业衔接原则

作业难度由学生文件夹决定，但公共结构建议包含：当日词汇快速复习；主动回忆；拼写或词形；句子或短文语境；少量表达任务；错词订正。

作业不能只有机械抄写。抄写如被采用，应作为辅助，而非核心学习证据。

## 第二十五章：Exit Ticket退出检测规范

每课结束前设置3—5分钟退出检测，至少覆盖：

- 2—3个快速词义或听音题（REC）；
- 2—3个主动提取题（RET）；
- 1个句子或口头表达任务（EXP）；
- 学生自评：最稳、最容易错、需要再练的词。

Exit Ticket 结果应进入下一课复习词池。

### 分级题量

| 级别 | Exit Ticket题量 |
|------|----------------|
| 基础 | 4题（2识别+1提取+1表达） |
| 中等 | 5题（2识别+2提取+1表达） |
| 培优 | 6题（2识别+2提取+1表达+1自评） |

## 第二十六章：Agent生成规则

### 26.1 课件生成流程

Agent 生成词汇课件时必须：
1. 读取项目级规范（本文件）；
2. 读取学生个人参数；
3. 输出本课目标词清单；
4. 标记核心产出词与理解词；
5. 检查目标词是否进入语境；
6. 在新词后立即生成巩固活动；
7. 生成至少一个对话或短文；
8. 生成一个 Mini Task；
9. 安排上一课词汇复习；
10. 生成 Exit Ticket；
11. 检查难度是否符合学生参数；
12. 输出"规范自检结果"。

### 26.2 游戏选择逻辑

Agent 应按以下流程选游戏：
1. 确定本次复习词汇；
2. 读取学生能力和难度参数；
3. 判断本轮主要训练目标；
4. 查看上一课使用过的活动；
5. 避免连续重复同一题型；
6. 从活动库选择1个主要游戏；
7. 根据需要增加1个语境活动；
8. 设置提示梯度；
9. 生成答案与即时反馈；
10. 指定如何记录错词；
11. 输出选择理由。

示例：
```
主要目标：中文到英文主动提取
近期已使用：英文选中文、图片配词
本次选择：图片闪现(T1-H)+首字母提示
后续语境：使用其中5个词完成微对话
错词处理：进入下一课听音写词
```

## 第二十七章：禁止事项

- 连续展示大量词卡后直接结束；
- 只有英文—中文配对；
- 只使用选择题；
- 所有目标词只出现一次；
- 例句语义生硬；
- 对话只是词汇堆砌；
- 短文加入过多生词；
- 游戏与学习目标无关；
- 答错后没有反馈；
- 只复习上一课，不回收长期错词；
- 所有学生使用相同难度和作业量；
- 将具体学生姓名写入项目级规范；
- 无明确学习目标的游戏；
- 只有速度，没有准确性；
- 只有少数学生参与；
- 错误后不反馈；
- 用大量无关动画掩盖内容；
- 选项答案过于明显；
- 所有词都只做英汉配对；
- 游戏结束后不回收错词；
- 竞争造成羞辱或焦虑；
- 为了塞进全部词而生成生硬对话；
- 一节课连续使用多个同质游戏；
- 将游戏难度固定为所有学生相同。

## 第二十九章：核心条款速查

> 每组新词学完后，必须立即安排主动提取与语境化巩固，不得直接进入下一教学板块。

> 词汇巩固必须同时覆盖词义识别(REC)、主动回忆(RET)、拼写或词形(SPL)、词块或句子运用(CTX)四类学习动作。

> 核心产出词不得只以"英文—中文"形式出现，至少进入词块或句子，并优先进入对话、短文或综合任务。

> 每节课开头必须回收上一课词汇和近期错词；复习题型应轮换，不能长期只做同一种中英配对。

> 每组重点词结束前必须设计一个有情境、有目的、有输出要求的 Mini Task。

> 游戏、对话和短文均须服务明确的词汇学习目标，不得仅作为装饰或课堂娱乐。

> Agent 必须先读取项目级公共规范，再读取学生个人画像、课时要求、学习内容和作业难度参数。

> 新词学完后的游戏组合至少包括一次快速识别(REC)、一次无答案主动提取(RET)和一次句子、对话或短文中的语境使用(CTX)。

> 下一课必须复习上一课重点词，但应采用"同词异式"的活动，避免连续重复相同题型。

> 游戏结束后必须提供即时反馈，并把错误词汇加入后续滚动复习池。

> 竞争、计时、积分和动画只能作为激励机制，不得代替准确性、解释、纠错和语言输出。

> 游戏难度、提示强度、题量、时间限制和输出要求从学生个人参数读取；游戏设计原则由项目级规范统一约束。

## 第三十章：研究依据

本规范主要依据以下研究结论：主动提取通常比单纯重复模仿更有利于外语词汇理解和产出；同一学习时段内的多次成功提取有助于词汇保持；把复习分散到不同时间节点通常优于只在一次课中集中重复；复习活动应具有适当挑战，并在延迟后再次提取。游戏化通常能够改善外语课堂参与和学习体验，但其效果依赖任务设计、反馈、学习目标和实施方式。

## 第二十六章：游戏化机制分级（B2 研究落地 2026-08-03）

> 依据《深度调研报告_B类第一批_2026-08-03.md》B2。用于 29 种游戏与后续组件的取舍。

### 高证据、建议保留
明确目标、即时反馈、适度挑战、失败可恢复（提示/重试/修正/迁移）、掌握进度（反映知识掌握与个人进步）、自主选择。

### 有条件使用
- 积分：仅当前小游戏内部反馈、不进长期能力标签、不公开排名；绑定有效提取/修正错误/迁移，不绑点击次数/答题速度/连续猜中。
- 徽章：只授予真实学习里程碑（跨日复测成功、首次独立拼写、新语境正确、完成错误修正）。
- 连胜：可显示"连续 3 题独立完成"，不因一错清零、不逼选简单题。
- 叙事：仅短模块（错句医生/单词修复站/阅读侦探），不淹没题目。

### 仅用于短时调节
30—90 秒限时配对、课堂中段快速分类、课末抽签、简单角色动画、局部庆祝；目的=恢复注意而非证明掌握；结束后回到"练了什么/哪里不稳/下一步"。

### 不推荐作为常规机制
公开排行榜、班级末位显示、每题金币、连胜失败全清零、随机宝箱、强制角色养成、重复抽卡、每课同一奖励体系、以速度为主要分数、无知识目标的跑酷/射击外壳。

| T2-I 猜词禁语 | 公开口头表现和倒计时可能使学生紧张 | 嘲笑失败、强制连续表达、按外向程度给分 | 私下准备＋句型支架＋允许提示/跳过；只评价目标义是否表达 |

### 31.5 统一改造条款

**MUST**

1. 所有游戏记录到统一答题数据系统，不另建第二数据库。
2. 首次独立正确、提示后正确、答案展示后正确必须分开。
3. 识别型游戏只能作为M1或复习入口，不能单独升级M2—M4。
4. 游戏结束必须显示：练了什么、哪里不稳、下一步复习。
5. 竞争不得公开排名；积分不得进入长期能力标签。
6. 所有拖拽操作必须有点击或键盘替代。

**SHOULD**

1. 每个识别游戏后连接一次无提示提取或新语境任务。
2. 每个错误反馈包含正误、错误位置或原因、下一步。
3. 口头游戏提供书面输入替代，并只记录必要的学习证据。
4. 30—90秒限时只用于注意调节，不用于掌握判定。

**MUST NOT**

1. 不允许无限点击直到猜中。
2. 不以速度、点击数、连胜或故事趣味性直接判掌握。
3. 不使用巨大红叉、刺耳失败音或羞辱性文案。
4. 不因一次错误清空已获得的学习进度。
