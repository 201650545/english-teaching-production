# 课程设计卡 · 模板

> **用途**：每一课**生成前必须填写**本卡。它是该课一切产出的源头：课件大纲 §1/§2 变量、配套练习大纲、Exit Ticket、数据采集字段均从此卡取值。
> **来源**：C3 兼容修订版总文档 §14（2026-08-02）；效力等级第 4 级，与 01/02 课件·练习格式规范、07 词汇游戏规范、exam_spec 冲突时以第 1–3 级为准。
> **填写人**：执行 Agent（教师确认后）。**归档**：学生文件夹 `内容蓝图\单课\`，与本课课件/练习大纲同目录。
> **约束**：① 语法 = 1 核心主题 + 2 直接相关考点（同属一个主题，不得无关拼接）；② 语篇仅真题母本改编或教师授权原创，必须填「阅读母本 ID」；③ 未成年人数据用 student_id，不写姓名进课件。

## 填写校验清单（填完对照）

- [ ] 语法 = 1 核心 + 2 相关，同一主题
- [ ] 新词/巩固词数量符合学生参数
- [ ] 阅读语篇有母本 ID 或原创授权标记
- [ ] 三篇阅读标记 CORE / EXTEND / HOME（A=CORE，B=EXTEND，C=HOME）
- [ ] 至少 6 个真实交互、跨 ≥3 环节
- [ ] Exit Ticket 5 题构成正确（2+2+1）
- [ ] 真题标注来源类型 + 溯源 ID
- [ ] 数据字段含第一阶段 6 项
